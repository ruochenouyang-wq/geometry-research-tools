## 数学依据与独立重放

首版固定单位球面、坐标轴、指数 `-1/2 < alpha < 0`、常数偏移和完整函数空间，只有幅度 `a` 在严格负的闭区间变化。算子形式为 `E[u] + a V[u] + b M[u]`，其中 `V[u]=integral(abs(z)^alpha * u^2)`。由于势在 L² 中，球面 H¹ 到 L⁴ 的嵌入保证所有幅度拥有共同的 H¹ 形式域。

归一化后的最低谱值是关于 a 的仿射 Rayleigh 表达式的下确界，因此是凹函数。两端完整基线证书的下端 `L0,L1` 给出整个区间的弦线下界：

`L(a) = ((a1-a)*L0 + (a-a0)*L1)/(a1-a0)`。

每个已验证端点证书都保存完整空间 m=0 的实际试函数。新实现从这些幂次和系数独立计算质量 M、动能 E 和势系数 V，得到仿射上界 `Ri(a)=E_i/M_i + a*V_i/M_i + b`；还核对它在对应端点的值与完整证书中的原 Rayleigh 值严格相同。这里没有把一般证书的上端盲目当作某个试函数的能量。

所以每一点满足 `L(a) <= lambda1(a) <= min(R0(a),R1(a))`。宽度是两条仿射函数的最小值再减一条仿射函数；它在每个线性交界区间上都是仿射函数，其最大值只可能在两端或两条上界直线的内部交点。所有临界点、上下界与最大宽度均使用精确有理数，浮点数仅用于计时。

若统一宽度不达标，准备过程细分最大宽度单元并完整求解、验证新中点；最终相邻样本必须无洞地覆盖全部闭区间。任何单元不达标时不签发参数银行（`bank=None`）。最多 65 个样本，准备默认 30 秒合作预算，外部评估器负责硬期限。每个端点尝试、完整区间失败和最终重放均保存在 `attempts`。

`verify_family` 重放每个端点的完整原题证书，再独立重建仿射能量、弦线、交点、单元覆盖及统一宽度；原函数、空间、全部数学布尔字段和目标精度不能用声明替代证明。全部角向/径向尾部由端点完整基线证书承担，凹性把其下界扩展到整个参数区间，试函数变分上界同样针对完整空间。

## 接口

固定比较的 family spec 为：

```json
{"profile":"abs_power","exponent":"-1/4","axis":2,"amplitude_interval":["-1/2","-49/100"],"offset":"0","mean_zero":false,"tolerance":"1/1000000"}
```

- `prepare_family(spec, preparation_seconds=30)`：返回 `{status, bank, attempts, preparation_wall_seconds, preparation_cpu_seconds, ...}`；失败不会提供 bank。
- `verify_family(bank, expected_spec=None)`：返回含严格布尔 `certificate_valid/target_met` 的判断及完整验证时间。
- `prepare_context(bank)`：先复制为自有的 JSON 快照，再验证同一快照。返回对象的 `setup_wall_seconds/setup_cpu_seconds` 包括完整首次验证；不会因调用方在检查和复制之间改写证据而保存未验证对象。
- `context.query(task)`：评估精确界并返回完整、自足的查询证书。`context.verify(cert, task)` 用自有证据快照绑定银行和任务，不重复端点数学重放。
- `query(bank, task)`：便捷的冷查询，完整银行验证也计入总时间。
- `verify(cert, task)`：自足的完整独立重放，支持查询证书和基线证书，返回判断与验证时间。

查询任务沿用基线格式，证书顶层有 `function/mean_zero/lower/upper/exact_width/tolerance`，并嵌入完整 `family_certificate`。更严格的请求精度不会被替换成银行精度：该点区间若不够窄，会返回有效但未达标的 `certified_open`。区间外幅度、指数、轴、偏移或空间变化均拒绝。首版不支持均值零银行、多指数盒或多谱值。
