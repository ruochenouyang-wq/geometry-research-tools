# V7：修正函数系数，突破误差估计的量化平台

有限维浮点特征向量被 V2 量化为 44 位二进制有理数。增加模式数后，尾部残差可能已经很小，空间内部的残差却不再下降。本版在相同空间内，对归一化的有限特征方程执行有理 Newton 修正，再量化到用户指定的 48–224 位。它修正的是试探函数，不只是特征值端点。

固定绝对值最大的系数为 1，将其余 N−1 个系数与特征值一起作为 N 个未知数。Newton 方程的矩阵为 `[A−μM 的自由列, −Mc]`，右端是 `−(Ac−μMc)`。解方程使用精确分数；步长结果仍只是候选。最终重新计算真实 Rayleigh 商与**全部**残差，包括乘势函数后落在截断空间以外的模式。

设试探函数归一化后 Rayleigh 商为 μ、完整残差平方为 ρ²，且已有独立证据 `μ<γ≤λ₂`，则 Temple 区间为

\[
\mu-\rho^2/(\gamma-\mu)\le\lambda_1\le\mu.
\]

若势与试探函数都严格为偶函数，可使用偶子空间的第二特征值；球面 Schrödinger 算子的正、简单基态位于该空间。否则检查完整空间的第二特征值。分离证明由范围 min–max 界或经过复核的 Schur 证书提供。背景见 [Harrell 的 Temple 不等式论文](https://www.researchgate.net/publication/243059969_Generalizations_of_Temple%27s_Inequality)。本版仍只认证最低特征值和对应函数的误差。

没有假定 Newton 必定收敛：奇异系统、缺少分离条件会报告失败；各步均独立认证，返回已经得到的最窄区间。有理数运算和更长系数会增加成本，空间外的残差也不会凭空消失。

运行 `python3 bench_v07.py` 比较同一空间中的 0、1、2 次修正；0 次保留原始 44 位候选。计时包括候选生成、分离证明与全部复核。`linear_low_space` 是保留的失败方向：修正系数无法解决空间太小的问题。`python3 -m unittest test_v07 -v` 检查高精度收益、已知精确解、空间误差和证书篡改。
