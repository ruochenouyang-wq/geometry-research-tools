## 1. 数学方案

令 `V(t)=|t|^(-1/4)`，固定共同形式域中的非零函数 `u`，并记其归一化能量为

\[
R_a(u)=\frac{E[u]+a\int V|u|^2+bM[u]}{M[u]}.
\]

对固定 `u`，它关于幅度 `a` 是仿射函数。单位球面上 `V∈L²`，而 `H¹` 函数属于 `L⁴`，故势项在共同 `H¹` 形式域上有意义。这里“形式域”是使质量、动能和势能均有意义的允许函数空间。

计划区间 `[-1/2,-49/100]` 中，共同形式域还有直接的闭性与下有界依据。沿用基线的归一化球面测度及 `||u||₄²≤E[u]+M[u]`，`V` 的均值为 `4/3`、方差为 `2/9`。于是 `||a(V-4/3)||₂²≤1/18<1/16`，统一取相对形式系数 `1/4<1`，得到

\[
Q_a[u]\ge \tfrac34 E[u]+(b-\tfrac{11}{12})M[u].
\]

因此整个计划区间使用同一个闭且下有界的 `H¹` 形式族，不需要声称端点强算子定义域完全相同。该论证依赖基线球面嵌入估计；本次审查没有重做整个基线的数学审计。

最低谱值是这些仿射函数的下确界，因而是凹函数。设端点为 `a0<a1`，已验证 `L0≤λ1(a0)`、`L1≤λ1(a1)`；令 `θ=(a-a0)/(a1-a0)`。对区间内每个 `a`，

\[
\lambda_1(a)\ge(1-\theta)\lambda_1(a_0)+\theta\lambda_1(a_1)
\ge (1-\theta)L_0+\theta L_1.
\]

因此端点下界的弦给出整段下界。该推导限定于固定允许空间中的**最低**谱值，不能不加证明推广到任意第 k 个谱值；均值约束也不能随参数更换。

取任一经过定义域检查的固定试函数 `ui`，从原函数和原试函数精确计算 `ei=E[ui]/M[ui]+b`、`vi=∫V|ui|²/M[ui]`，即可得到 `Ui(a)=ei+a vi≥λ1(a)`。端点证书的 `upper` 可能来自与该候选不同的来源，不能直接把它当作这条试函数直线的端点值。

两条直线的最小值仍是合法上界。设弦下界为 `L(a)`，则 `W(a)=min(U0(a),U1(a))-L(a)` 为分段仿射函数。闭区间上的最大值由两端点以及落在区间内的两条上界直线交点完全决定；平行或重合时只需端点。所有交点与比较须用精确有理算术。若使用更多上界直线，应覆盖所有可能成为下包络转折点的交点；抽样不能替代这项证明。

## 2. 实现审查结果

1. **源题绑定通过。** `_sample` 用原指数、轴、偏移、对应幅度及严格的 `mean_zero=False` 重新调用完整基线验证。`_rayleigh_affine` 从端点原始幂次和系数独立积分质量、动能与势能，核对质量及实际 Rayleigh 值，没有误用端点 `upper`。
2. **覆盖与最大值通过。** `_bank` 要求样本幅度有序、互异、首尾恰为声明端点，并对每对相邻样本构建闭单元。因此仅在共享端点重合，不留洞。`_cell` 精确检查两端及区间内交点；`verify_family` 重建全部单元后做规范 JSON 全量比较，额外或遗漏单元、边界和临界点均不能混过验证。
3. **精度绑定通过。** 银行自身的容差和外部 `expected_spec` 均严格绑定。查询可以请求更紧容差，但必须按该点实际宽度重新判定；检查中的 `10^-12` 请求返回 `certificate_valid=True`、`target_met=False`、`certified_open`，没有继承银行原来的达标状态。
4. **准备上下文通过修复后复核。** 初版 `PreparedContext` 先验证调用方对象、再复制，存在验证与复制之间对象变化的竞态。实现者改为先序列化并解析出私有快照，只验证该快照，再保留同一不可变字符串及其摘要。独立故障注入复现了“验证结束时调用方改写证据”的时机，修复后上下文仍只使用已验证内容；输入对象和返回对象的后续修改也不污染上下文。
5. **快验证与冷重放的边界清楚。** `context.verify` 在私有银行已完整验证的前提下检查摘要并重建精确查询；摘要用于绑定内容，不代替数学证明。查询证书嵌入完整银行，`verify(cert, task)` 会重新验证银行及全部端点，可独立 JSON 重放。这个信任边界针对外部证书数据，不承诺抵抗同一 Python 进程中任意修改验证器代码或内部属性的恶意代码。
6. **预算和费用边界可接受。** 准备计时包含端点求解、端点复核、建库及最终整库复核；`prepare_context` 的首次完整验证另有计时；冷 `query` 总计时包含上下文创建。零查询预算不签发证书。内部预算仍是合作式检查，硬期限必须由外部进程控制。输出编码、模块导入、进程启动及外部独立重放需要统一评估器额外计入，不能把内部计时当作完整端到端费用。
