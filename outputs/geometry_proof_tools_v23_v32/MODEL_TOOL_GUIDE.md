# 给调用模型的工具说明

目标：把可明确建模的球面基态不等式交给程序求证，并解释证书与原题的对应关系。

先检查原题是否确实是固定单位二球面、势只依赖 t=cos(theta)、要求最低特征值或全体函数的能量下界。第一非零特征值、任意曲面、依赖方位角的势和未列入接口的函数约束，不能悄悄改成此模型。

把参数顺序、函数空间、全部参数域、势、二次代价及待证明阈值写成 README 中的 JSON。使用有理常数，保留原题的量词。自然语言到该表示的正确性仍是调用者的责任；工具验证器不会知道某个未写入 JSON 的假设。

调用 `python3 run.py solve goal.json --output result.json` 后，调用 `python3 run.py verify result.json`。读入结果的 status、lower_bound、upper_bound、reductions 和 terminal。解释实际采用的数学转换及其适用条件，不把方法排序或搜索日志当成证明。

proved 只证明 JSON 中的目标；refuted 需要展示原始参数域中的反例和精确能量；unresolved 说明当前估计或预算不足，不等于原命题为假。数值误差小不意味着不等式符号已经确定。不要把工具称作 Lean 等形式化内核。

若同一类方向会重复出现，可以调用 lemma 生成族引理，将证书存成列表，通过 --library 复用。每次仍检查适用方向、参数映射和剩余势范围。不要把单题答案放入库后将命中缓存算成研究能力提高。

输出给研究者时，明确区分：原始数学问题、交给工具的表示、已核验的结论、仍未覆盖的部分。当前工具本身没有模型调用，也没有“5.6 超过 Astra”的实测结论。
