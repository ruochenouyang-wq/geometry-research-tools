# A：多谱值、严格负谱计数与负谱和

这是与原求解器并列的扩展。新增任务是单位球面轴对称 Schrödinger 算子在全空间或零均值空间中的**严格负特征值个数**，以及可选的**有符号负特征值之和**。常势没有快捷分支，所有势都经过同一原函数精确矩、径向尾与惯性认证。

## 接口与含义

`variant.solve(task)` 返回结果；`variant.verify(certificate, task)` 返回字典，独立重建数学证据，不重新搜索候选。已有 `spectrum` / `approximation` 任务委托冻结后的共同基线，标记 `fallback: true`；这部分不是 A 的新能力。

新增任务示例：

```json
{
  "kind": "negative_spectrum",
  "function": {
    "kind": "axis_profile",
    "profile": "step",
    "axis": 2,
    "amplitude": "-1",
    "offset": "-4"
  },
  "mean_zero": false,
  "tolerance": "1/1000000",
  "budget": {"wall_seconds": 10}
}
```

只接受上述字段及可选 `id`。`mean_zero` 必须为布尔值；函数和容差接受精确整数或有理字符串，不接受浮点函数数据。`tolerance` 专指谱和区间宽度，不是计数误差；没有 `sum_tolerance` 或 `options` 别名。

| 输出 | 含义 |
|---|---|
| `certificate_valid` | 原题绑定及全部证据通过重放 |
| `count_lower`, `count_upper` | 完整无限维严格负谱计数的整数区间 |
| `count_certified`, `negative_count` | 两端相等时才有确切计数；否则 count 为 null |
| `sum_certified` | 每个负谱方向均有独立端点证据，得到完整谱和区间 |
| `sum_lower`, `sum_upper`, `sum_width` | 对 **Σ_{λ<0} λ≤0** 的包围；未认证时为 null |
| `abs_negative_sum_lower/upper` | 同一区间取负号反转，仅是 Tr(H)₋ 的表示 |
| `sum_target_met` | 已认证谱和宽度不超过外部 task 的 tolerance |
| `target_met` | 计数确切并且谱和达标；不是只要计数通过就算成功 |
| `attempts` | 每一已启动阶段的计数、谱和宽度、失败或预算退出 |

例如 q=−7，全空间计数 9、有符号和 −27；零均值计数 8、有符号和 −20。绝对负谱和分别为 27、20。q=−6 的五维零谱不计入严格负谱，全空间计数 4、和 −18；零均值计数 3、和 −12。

## 证明结构

对于一个真实径向角频率分量 m，设 R(x) 为有限 Ritz 矩阵 A−xM，L(x) 为已有 Kernel 的完整 Schur 补下比较矩阵。严格尾界 β_tail>x 时：

    n₋(R(x)) ≤ N_m((−∞,x)) ≤ n₋(L(x))。

计数在 x=0 使用纯负惯性，不把零惯性加进去。若上下界一致，就得到完整径向计数。若不一致，保留整数区间，绝不把不确定方向强行归类。

对于已确定的 k 个负特征值，j=1,…,k 的下端点由 n₋(L(lower))≤j−1 证明，上端点由 n₋(R(upper))+n₀(R(upper))≥j 证明。区间允许重叠，不要求特征值简单。严格负计数已单独证明，所以端点 upper=0 仍是合法的非严格上界。所有端点逐一精确重放。

完整球面的 m=0 权重为 1，m≥1 的 cos/sin 实分量权重为 2。必须逐个覆盖 m=0,…,M−1。由全局形式界 H≥ρ(−Δ)+κ、ρ>0，m≥M 的能量≥ρM(M+1)+κ；此值**允许等于零**，足以排除严格负谱。它与径向 Schur 尾的严格正条件不同。

零均值条件只在 m=0 删除 l=0，并在完整残差 Gram 中去掉常数方向。不会从全空间最终计数随意减 1，也不会把全空间基态的 m=0 约化误用于整个负谱。

形式、原函数 q/q² 矩、径向尾、全部惯性、特征值序号、连续 m 列表、空间、重数、符号与容差全部重新计算并比较。摘要不是验收依据。依赖的 Kernel 和有理惯性仍属于共同信任基础，尚非证明助手形式化。

## 有界搜索与已知不足

默认径向阶段为 8、12、16 模式，另计 16 个近尾模式，端点二分 28 次；角频率最多到 m=12。支持共同基线的阶跃势和 q² 可积的幂势；强负幂的形式可调用已验证 R03 L³ᐟ² 界。若原形式不可用、角尾预算不够、径向尾不正或计数不能闭合，明确保留失败。

计算预留时间给最终重放；内部预算是协作式，外部评估器仍须实施 10 秒硬期限，并计入导入、编码与重放。默认二分位数及 Schur/Ritz 包围会留下精度下限；增加小数位并不能消除试验子空间误差。

本阶段**完成了负谱计数能力，但没有普遍达到 10⁻⁶ 的负谱和精度**。公开开发记录在 `DEV_RESULTS.json`，不作为独立性能评测：

| 原函数及空间 | 确切计数 | 谱和区间宽度（约） | 10⁻⁶ 谱和目标 |
|---|---:|---:|---|
| q=−1_{z≥0}，全空间 | 1 | 1.399e−5 | 未达标 |
| q=−4−1_{z≥0}，全空间 | 4 | 5.306e−5 | 未达标 |
| q=−6−(1/5)|z|^(−1/4)，零均值 | 8 | 2.899e−5 | 未达标 |

下一步若要改善谱和，应扩展多向量残差/子空间认证，而不应把上述有效计数当成窄谱和证书。该方向尚未实现。

## 开发验证

`test_variant.py` 共 14 个测试方法：最初 13 项整套通过，随后新增的近零未决测试独立通过。包含常势 c=5.99、6、6.01、7 两空间的 8 个精确校准，非恒定阶跃的独立点值夹逼计数，负幂两空间，17 类证书篡改，外部任务约束，禁用搜索的验证，零预算和原任务委托。

特别保留：q=−3/2−1_{z≥0} 的零均值一模式试验给出恰为零的 Ritz 值。完整比较只认证计数 [0,3]，谱和为 null、目标不通过。这检验“数值零”不能代替“没有负谱”。

在本目录使用 bundled Python 3.12 可复跑：

```text
python3 -B -m unittest test_variant -v
```

`negative_spectrum(task, modes=(8,12,16), near_tail=16, bits=28)` 是公开的有界开发接口；`radial_evidence`、`endpoint`、`assemble` 是构造辅助函数，不能替代 `verify`。本实现没有调用模型，`actual_model_calls=0`、`actual_model_tokens=null` 不表示研发免费，也不支持跨模型效率结论。
