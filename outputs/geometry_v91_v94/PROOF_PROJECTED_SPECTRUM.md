# 全球面零均值投影谱：V91–V94 数学设计与独立核对

日期：2026-09-11。本文说明已有谱理论如何支持有限有理证书；不提出新的数学定理，也不声称在形式化证明助手内核验。对象限定为单位球面、实轴对称多项式势 `q(t)`（`t=cos(theta)`，次数不超过 6）。

## 1. 被证明的算子和量词

令 `H=-Delta_S2+q`，令 `Pi u=u-(4*pi)^(-1) integral_S2 u`。零均值算子是在闭二次型域 `H^1(S2) intersect 1^perp` 上由

    h[u] = integral_S2 (|grad u|^2 + q |u|^2) dσ

定义的自伴算子，记作 `Pi H Pi`。对非恒定 q，`1^perp` 通常不是 H 的不变子空间；这里是压缩算子，不能通过简单删除普通 H 的第一特征值获得其谱。其基态值是上述约束 Rayleigh 商的下确界。

`weighted_poincare(q, threshold)` 证明的是固定 q 的线性二次型不等式

    对每个实 u∈H^1(S2)，若 integral u = 0，则
    integral (|grad u|^2+q u^2) >= threshold * integral u^2。

这不是 Gagliardo–Nirenberg 最优常数证书，也不是仅对轴对称试探函数的陈述。面积测度与概率测度同时缩放分子分母，故这里的谱阈值无需额外乘除 `4*pi`。

## 2. 角向分解与投影

因为 q 只依赖 t，算子保持复 Fourier 扇区 `exp(i*m*phi)`。在固定非负 m 内，径向表达式为

    -d/dt((1-t^2) d/dt) + m^2/(1-t^2) + q(t)。

使用球面上自然的正则性/二次型域；不能给 m=0 另加端点 Dirichlet 条件。完整球谐次数为 `l=m,m+1,...`。在零均值空间，m=0 必须删去 l=0，因此 `start=1`；m>=1 自然零均值，因此 `start=m`。无零均值约束时 m=0 从 l=0 开始。

实空间的 m>=1 对应 cos 和 sin 两份相同径向谱，亦即 m 与 -m 简并。求基态时取各非负 m 的最小值即可；若以后实现全谱计数，必须将 m>=1 的重数乘二。固定 m 扇区的第 k 个特征值不是普通全 S2 算子的第 k 个特征值；尤其投影 m=0 基态不是普通第二特征值。

## 3. 完全有理的 associated Legendre 形式矩阵

取未归一化基底

    P_l^m(t)=(-1)^m (1-t^2)^(m/2) (d/dt)^m P_l(t)。

其质量为

    h_l = integral_-1^1 (P_l^m)^2 dt
        = 2(l+m)! / ((2l+1)(l-m)!)。

正交关系见 NIST DLMF [14.17.6](https://dlmf.nist.gov/14.17.E6)。所用相邻次数递推属于 DLMF [14.10](https://dlmf.nist.gov/14.10)：

    t P_l^m = (l-m+1)/(2l+1) P_(l+1)^m
              + (l+m)/(2l+1) P_(l-1)^m，

其中 l=m 时不存在的下项为零。因而次数 d 的 q 乘法矩阵带宽为 d。必须先计算整个 `q P_l^m` 再压缩；对 q=t^2，先投影 t 再平方会错误地丢失经过 l=0 的路径。

保留次数 `I={start,...,L-1}`，其中 `L=start+N`。定义

    M_ij=h_i delta_ij，
    A_ij=i(i+1) h_i delta_ij + integral q P_i^m P_j^m dt。

所有项为有理数。独立重放还可直接展开 `(1-t^2)^m (D^m P_i)(D^m P_j)q`，使用偶次单项式积分 `2/(k+1)`、奇次积分零来核验。共同的 phi 积分因子被约去。

与无限尾部的非零耦合只可能出现在 `J={L,...,L+d-1}`，定义 `B_i,l=integral q P_i^m P_l^m dt`。d=0 时 J 为空。B 只有有限列不等于把尾部截断为有限维：尾算子仍包含所有 l>=L。

## 4. 无限尾部 Schur 上下比较

先独立证明并绑定当前 q 的范围 `qlo<=q(t)<=qhi`（t∈[-1,1]）。令 `e_l=l(l+1)`，在正交归一化尾部中有二次型序

    Dlo=diag(e_l+qlo) <= T_exact <= Dhi=diag(e_l+qhi)。

对严格满足 `x<beta=L(L+1)+qlo` 的候选端点，三者减 x 均严格正，因此逆序为

    (Dhi-x)^(-1) <= (T_exact-x)^(-1) <= (Dlo-x)^(-1)。

在保留的未归一化坐标中，正确的有理比较矩阵是

    S_lower(x)_ij = A_ij - x M_ij
      - sum_(l∈J) B_i,l B_j,l / [h_l (e_l+qlo-x)]，

    S_upper(x)_ij = A_ij - x M_ij
      - sum_(l∈J) B_i,l B_j,l / [h_l (e_l+qhi-x)]。

因此 `S_lower <= S_exact <= S_upper`。分母中的尾质量 h_l 不可遗漏。等价做法是把尾基底正交归一化，同时令耦合除以 sqrt(h_l)，最终乘积仍为有理数。

无限维 Schur 补由闭二次型和有界有限秩耦合解释。尾部在 x 处严格正，其负惯性与零惯性贡献为零；有限 Schur 矩阵的负惯性数等于该扇区原无限维算子在 x 以下的特征值数。设 `n_-(S)`、`n_0(S)` 为精确惯性：

* 若 `n_-(S_lower(x)) < k`，则 `lambda_k >= x`。
* 若 `n_-(S_upper(x))+n_0(S_upper(x)) >= k`，则 `lambda_k <= x`。

使用零惯性项使等号正确。上界亦可单独使用 Ritz 矩阵 `A-xM` 的非正惯性数，这不要求 x<beta。Schur 上界与下界则必须检查严格尾正性。搜索、二分、浮点建议均不是证明；接受条件是有理矩阵的精确惯性重放。

## 5. 全 S2 的遗漏角向尾部

设已经完整枚举连续扇区 `m=0,...,M`，每个扇区基态有 `[lower_m, upper_m]`。所有遗漏扇区满足

    lambda_(m,1) >= m(m+1)+qlo
                  >= (M+1)(M+2)+qlo = angular_floor。

由此对完整函数空间的可靠区间是

    lower = min(lower_0,...,lower_M, angular_floor)，
    upper = min(upper_0,...,upper_M)。

当 `angular_floor >= upper` 时，已枚举扇区至少有一个取得全局最低谱值。等号仍可能有未枚举扇区并列；要排除所有并列遗漏扇区，需严格大于。即使未闭合或达到资源上限，上述 lower 仍有效，必须返回真实区间及 `certified_bound_open_gap`，不能仅用有限扇区的 lower。

对 weighted Poincare 陈述，`lower>=threshold` 才是 proved，`upper<threshold` 才是 refuted。后者由离散谱的变分原理给出反例函数的存在性；若未构造函数，应明示此事。其余情况为 undetermined。有效但宽的谱区间本身不是失败证书。

## 6. 可复现的校准和区分例

q=0 时，全零均值基态为 2：m=0 一份，m=1 两份。q=c 时为 2+c。无投影普通 m=0 基态则为 c。

对于 `q=a*t`，正规化 t 耦合满足 `|<0,0|t|1,0>|^2=1/3`、`|<2,0|t|1,0>|^2=4/15`、`|<2,1|t|1,1>|^2=1/5`。在各固定扇区内用孤立简单特征值的二阶扰动（t↦-t 使谱关于 a 为偶函数）：

    ordinary_axisymmetric_lambda_2 = 2 + a^2/10 + O(a^4)，
    projected_m0_ground            = 2 - a^2/15 + O(a^4)，
    m1_ground                      = 2 - a^2/20 + O(a^4)。

第一式的系数为 `(1/3)/(2-0)+(4/15)/(2-6)=1/10`；投影后删去 l=0 项。这说明对充分小的非零 a，全零均值基态来自 m=0，与投影 m=0 基态相同，而非三个数互不相同。普通全 S2 的第二特征值则属于 m=±1，不能把它与旧轴对称求解器的 k=2 混淆。这里不作任意 a 的扇区次序断言。

以下是独立直接积分、Fraction Schur 惯性计算得到的粗区间，可作为新实现的精确回归端点。每个扇区 N=6，耦合尾列数 d，普通轴对称 k=2 从 l=0 开始，投影 m=0 从 l=1 开始，m=1 从 l=1 开始。核验每个下端的 S_lower 负惯性少于 k、每个上端的 S_upper 非正惯性至少 k 即可；无需信任小数近似。

| 势与精确范围 | 普通轴对称 k=2 | 投影 m=0 基态 | m=1 基态 |
|---|---|---|---|
| q=t，[-1,1] | [548077/262144, 68511/32768] | [506981/262144, 31687/16384] | [127815/65536, 511271/262144] |
| q=t+t^2，[-1/4,2] | [347469/131072, 694949/262144] | [663027/262144, 331519/131072] | [70469/32768, 563763/262144] |

q=t 的三个区间约为 2.09077、1.93400、1.95032；遗漏 m>=2 下界 5，所以全零均值基态确实来自 m=0。q=t+t² 的三个区间约为 2.65100、2.52927、2.15056；遗漏 m>=2 下界 23/4，所以全零均值基态来自 m=1，和前两者均不同。第二个例子提供旧轴对称 k=2、投影 m=0 基态、全零均值基态三者互异的测试。表中独立计算是测试设计依据；正式交付仍应以保存并重放的新证书为准。

## 7. 证书约束及实现审查清单

证书必须绑定单位 S2、原 q 的规范有理系数、投影布尔值、固定 m、由投影自动推得的 start、N、k、严格尾正性阈值、势范围证据和所有端点。验证器重新组装质量和势矩阵，不能信任证书给出的矩阵或范围数值。全空间证书必须逐项绑定相同 q、相同投影、k=1，以及连续的 m=0,...,M；重新计算遗漏角向下界、区间和 status。调用者可提供 expected_q、expected_mean_zero、expected_threshold 绑定外部问题，防止用另一份真实证书替换目标。

应拒绝的篡改包括删去中间 m、把投影 m=0 改回 l=0、遗失尾质量、只保留部分耦合尾列、反转 Schur 方向、尾正性取等号、篡改势范围及 scope。输入高于六次或非轴对称势不在本设计范围内。

证明的信任基础是球谐完备性与 associated Legendre 恒等式、自伴闭二次型/紧预解式、变分原理、正算子逆序、Schur 惯性原理，以及底层精确有理算术/范围验证器。它们不是由有限采样推出，也没有被本程序重新形式化证明。
