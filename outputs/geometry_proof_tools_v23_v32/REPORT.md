# V23–V32：让数学工具减少搜索，并生成可复用的证明

本轮完成了十个新增版本。最有价值的变化是：程序现在能从明确的数学表达式出发，检查约化条件、消去冗余变量、生成覆盖全部实参数的引理，并把结论逐步核验回原题。它不再只能对每个参数点分别做谱估计。

这为“让 5.6 借助工具完成更难的研究任务”增加了可运行的部件，但**尚未进行 5.6 与 Astra 的对照，也没有证明半小时超过八小时的目标**。现阶段的题目是开发者给定的结构化算例；难度没有经过强模型基线验证。

## 十版的实际变化

| 版本 | 算法做什么 | 对研究的作用 |
| --- | --- | --- |
| V23 | 把受限数学表达式精确编译为势、参数域和代价 | 检查输入属于哪个数学模型，保留原目标 |
| V24 | 证明轴对称势的完整球面基态可精确约化 | 让轴对称计算能支持完整球面函数空间的结论 |
| V25 | 吸收常数势，消去无谱作用的变量 | 在开始区域搜索前删除不必要的维度 |
| V26 | 检查反射条件，把参数域折半 | 减少需覆盖的区域 |
| V27 | 按势的实际参数秩压缩维度 | 多个参数只通过少数组合起作用时，精确降维 |
| V28 | 直接搜索足以证明或否证指定阈值的证据 | 不必先把最优值计算到无关的高精度 |
| V29 | 解 Poisson 方程，构造正函数，生成参数族谱引理 | 一次证明覆盖所有实参数 |
| V30 | 将全参数矩阵条件转成一维多项式最值 | 为引理系数给出全局上下界和误差证书 |
| V31 | 检查仿射参数匹配和势的单调性，迁移已有引理 | 同一段证明可以用于多个相关目标 |
| V32 | 搜索约化路线，选择引理或数值方法，复核整条证明链 | 把上述部件组织成模型可以调用的入口 |

逐版数学论证与适用条件见 [PROOF_V23_V32.md](PROOF_V23_V32.md)，使用方法见 [README.md](README.md)。这些是现有数学方法的程序化组合，不声称发现了十个新数学定理。

## 同一目标下的耗时对照

每组顺序运行三次，取中位数；包括适用的表达式编译、转换、求解及证明重建，不含主表结果文件保存。环境为 Python 3.9.6、macOS ARM64。绝对耗时较短，比例只代表这些构造算例。

| 改动与算例结构 | 关闭该改动 | 启用该改动 | 本例耗时改善 |
| --- | ---: | ---: | ---: |
| V25：四参数中三个只影响二次代价，先消元 | 3.031632 秒 | 0.017502 秒 | 约 173 倍 |
| V26：利用反射对称，把参数盒折半 | 0.057311 秒 | 0.037411 秒 | 约 1.53 倍 |
| V27：四参数势实际只依赖一个线性组合 | 0.606039 秒 | 0.027497 秒 | 约 22 倍 |
| V28：同一否证任务，直接围绕目标阈值搜索 | 0.236356 秒 | 0.023724 秒 | 约 9.96 倍 |

V25 的参数点记录从 195 减到 3，但旧工具已有缓存，真实谱求解调用是 6→3；主要收益还包括区域覆盖和证书处理的减少。V27 的参数点记录是 27→3，谱求解调用是 24→4。不能把参数点记录数当成实际求解次数。

V28 的基线先尝试把优化误差缩到百万分之一，再判断同一个不等式；新版找到有效反例就停止。这说明围绕目标分配计算有价值，但并不代表在同样精度的最值计算上快十倍。

这些结构可能被一个强模型自行识别。**173 倍是该程序对照的耗时差，不是 5.6 相对 Astra 的研究能力倍数。** 完整 26 项结果、失败与原始重复时间见 [BENCHMARKS.md](BENCHMARKS.md) 和 `results/benchmark.json`。

## 比普通提速更重要的结果：生成全参数证明

设 t 为单位球面的高度坐标，λ₁ 表示完整球面上的最低特征值。V29 自动构造正函数，生成

\[
\lambda_1(-\Delta+a t)\ge -a^2/4\qquad\forall a\in\mathbb R.
\]

它还对方向 `t²−1/3` 生成系数 `1/36` 的同类界。V30 则自动生成双参数结论

\[
\lambda_1\!\left(-\Delta+a t+b(t^2-1/3)\right)
\ge -(a^2+b^2)/4\qquad\forall(a,b)\in\mathbb R^2.
\]

在当前每次最多 32 个区域叶节点的对照中：

| 统一非负性目标 | 关闭引理合成 | 启用引理合成 |
| --- | --- | --- |
| 线性势族加代价 a²/4 | 0.563285 秒，未解决 | 0.001046 秒，已证明 |
| 双方向势族加代价 (a²+b²)/4 | 1.759342 秒，未解决 | 0.002757 秒，已证明 |

这里的区别是**在给定预算下能否完成证明**。不能用“未解决”的耗时计算精确加速比，也不能据此断言数值方法增加预算后永远无法完成。

此前区域搜索面对边界等号时，下界即使很接近零，只要仍为负数，就不能证明目标。新方法通过恒等式和一维全局范围证书，直接给出对全部实参数成立的结论，绕过了这一类参数网格搜索。这是本轮最接近用户所需工具价值的进展。

V30 仍不等于求出了原谱问题的最优常数：它控制的是**选定正函数形式、选定矩阵权重下**最小放大系数的误差。权重本身的全局优化和原问题的锐利常数还没有解决。

## 复用效果与保留的失败

复用一个已核验的线性族引理，程序完成了 16 个通过改参、参数平移及增加非负六次势构造的目标，全部无需谱搜索。引理生成中位耗时约 0.000200 秒，16 题在线批次中位耗时约 0.041045 秒。最后一轮批次还包括保存证明文件，原始三轮时间均保留。

这 16 题用于验证已声明的迁移规律，**不是按题族隔离的盲测**，不能作为跨未知几何问题的成绩。

结果也并非总有收益：一个一般非对称算例启用引理尝试后为 0.035093 秒，关闭时为 0.033509 秒，两者均由数值方法完成；额外尝试略有开销。另一个代价为 a²/5 的盒域目标，引理不够强，数值预算耗尽后仍明确返回 `unresolved`。系数优化预算不足的案例也保留 `scale_gap_open`，没有标成最优系数已求出。

## 可运行性与证据强度

- **168 项测试通过**：78 项新增测试，90 项原有回归测试，覆盖代数恒等式、条件拒绝、错误作用域、伪造证书、反例参数提升等。
- **42 份保存结果全部通过复核**：包含整题证明、反例、未解决但有效的界，以及编译和引理组件证书；并非 42 道难题已解决。
- Python 3.9+ 标准库即可运行，无需模型密钥。命令行可编译、求解、生成引理和重放核验；附示例输入和模型调用说明。
- 核验使用精确有理数；谱惯性和多项式范围部分采用不同计算路径复核，但部分代数代码共享。解析规则尚未由 Lean 等形式化内核检查。

当前范围是固定单位二球面、轴对称六次以内多项式势、至多四个仿射参数及二次代价、最低特征值。工具支持其中符合各后端条件的目标，不支持任意几何或任意自然语言数学问题。V32 的路线选择也是有预算的启发式，不保证找到所有方法中的最佳路线。

下一阶段应冻结这一工具版本，建立按题族隔离的几何分析题库，实际测量同一 5.6 加工具前后的成功率，再开展 Astra 对照。当前已获得可运行、可检查的证明工具；显著的模型能力提升仍需要这一步实验证据。
