# 精确临界点极值证书

本模块 `exact_extrema.py` 在有理闭区间上，为次数不超过 32 的一元有理多项式
给出全局最大值的有理上下界。`verify` 从证书中重算全部有理代数、Sturm 根数、
临界值区间、端点值和误差状态，不运行搜索程序。旧 `family_v29.maximum`、
`family_v29.verify_range` 和既有几何证书均未修改。

这里的“精确”首先指接受证书只使用 `Fraction` 算术，并非每次都算出最大值的
闭式表达式。`enclosed` 是达到所请求绝对误差，`exact` 是有理上下界相等，
`open` 是尚未完成隔离或精度任务，但已经输出的上下界依然有效。

## 接口与适用范围

```python
from fractions import Fraction as F
from exact_extrema import maximize, verify

c = maximize([0, 1, 0, -1], interval=(-1, 1),
             tolerance=F(1, 10**12), max_nodes=32)
assert verify(c)
lower, upper = F(c['maximum_lower']), F(c['maximum_upper'])
assert upper-lower == F(c['error_bound'])
```

- 系数按常数项在前排列；输入为 `int`、`Fraction` 或有理数字符串。
  系数、区间、容差不接受浮点数或布尔值。去除尾零前最多 33 个系数。
- 闭区间端点可相等；此时直接精确求值。常数、一次多项式均可处理。
- `tolerance` 是任意严格正有理数。不是相对误差或经过浮点取整的阈值。
- `max_nodes` 为 0 到 4096 的整数，计算新增区间边界数，即非退化分区的
  `partition_cells - 1`。一次 Newton 收缩最多新增两个边界，分别计费。
  它不限制代数运算次数、输入位数、内存或运行时间。
- `suggestions` 是至多 256 个**原变量 x 坐标**建议。有限浮点建议先转成分母
  不超过 `2**30` 的有理数；非有限和区间外建议忽略。建议可以引导分点，但
  只有精确代入平方自由导数为零才能成为精确临界根证据。
- 系数位长不另作统一限制。任意精度算术、Sturm 系数增长和 Python 整数
  字符串转换的资源限制仍适用。这是有界次数/细分次数的数学模块，不是针对
  恶意超大整数输入的隔离服务，也没有硬实时保证。
- 求最小值时，对 `-p` 调用 `maximize`：若得到 `[L,U]`，则原多项式最小值
  在 `[-U,-L]` 中；返回的证书仍然绑定到 `-p`。

## 1. 变量约化与驻点候选完整性

设原多项式为 `P(x)`，原区间为 `[a,b]`。

若 `P(x)=Q(x²)` 非常数，则连续映射 `x -> x²` 将 `[a,b]` **满射**到

```text
[A,B] = [0, max(a²,b²)]                    当 a <= 0 <= b；
[A,B] = [min(a²,b²), max(a²,b²)]            其他情况。
```

因此 `max_[a,b] P = max_[A,B] Q`。其余情况令 `Q=P`、`[A,B]=[a,b]`。
后文所有导数、临界根及根重数都指工作变量中的 `Q`。

这也解释了证书中的 `coordinate`。当其为 `x_squared`，
`sample_witness.at` 表示平方坐标 `u`，不一定是有理原坐标 `x`；
但是满射性保证原区间上存在对应取值点。不能把这个字段直接解释成原变量。
原点处由 `P'(x)=2x Q'(x²)` 产生的驻点被包含在工作区间端点 `u=0`。

连续性保证最大值存在。若工作区间不退化，Fermat 定理保证最大值在端点，
或在 `D=Q'` 的内点实根上。常数多项式单独处理，不声称零多项式导数只有
有限个根。

## 2. 平方自由化与重数

当 `D` 非常数时，计算

```text
G = monic(gcd(D,D')),
S = monic(D/G).
```

Euclid 除法在 Q[x] 内完成并检查余数为零。若某根在 `D` 中重数为 `m`，
它在 `gcd(D,D')` 中重数为 `m-1`，所以在 `S` 中重数为一。
因此 `S` 的不同实根正好是 `D` 的全部不同实根，重复根不会丢失。

对非零常数 `D`，采用 `S=G=1`；对 `D=0` 采用空根问题约定 `S=1,G=0`，
并单独标记 `constant_polynomial=true`。后者不表达恒等式 `D=G*S` 的可逆商。
有理临界点重数通过连续精确求导，找到第一个非零值而直接核实。

## 3. Sturm 链与端点规则

对平方自由非常数 `S` 构造

```text
S0 = S,
S1 = S',
S(k+1) = -remainder(S(k-1), Sk).
```

每一步只允许除以该多项式首项系数的**绝对值**进行归一化，因此不改变符号。
将负首项强制首一化会改变 Sturm 变号数，这里没有这样做。
平方自由性保证最终到达非零常数。

对于任意链多项式 `H`，若 `H(t)=0`，找到最小 `j` 使 `H^(j)(t) != 0`。
它在 `t+` 一侧的符号为该导数符号，在 `t-` 一侧再乘 `(-1)^j`。
因此即使分点恰为某个链多项式的根，也可计算严格左右极限的符号变号数。

Sturm 定理给出

```text
# { r in (l,h) : S(r)=0 } = V(l+) - V(h-).
```

采用开区间计数是为了不把恰在分区边界的根重复算入相邻区间。所有分区边界
都另外精确代入 `D`；为零者加入有理临界点表。全局还重算 `(A,B)` 根数，
检查“每个分区开区间根数之和 + 内部分界点根数”与其一致。

## 4. 完整分区与根隔离

`partition` 必须从 `A` 连续覆盖到 `B`，各区间严格正长度、按序相接，不允许
缺口、重叠、倒序、遗漏端点或多余区间。退化工作区间只允许空分区。

每个分区的不同导数根数由 Sturm 链重算：

- 0 根记作 `empty`；
- 1 根记作 `isolated`；
- 多根记作 `cluster`。

因此 `cluster` 也有完整覆盖证明，只是不能当作已经隔离的单个代数根。
生成器优先分裂根簇，然后收缩上界最大的非精确单根区间。若分点正好为根，
它从开区间中移到精确分界点根表，不会丢失。平方自由多项式的不同根间距
严格正，持续二分最终能分开所有不同根；有限预算不承诺已经做到。

## 5. 三种临界值界及精确有理根

设某分区 `[l,h]` 至少包含一个临界根 `r`。对全部这样的 `r`，分别计算：

**Bernstein 界。** 将 `Q(l+(h-l)t)` 精确转为 `[0,1]` 上的 Bernstein 基。
基函数非负且和为 1，所以所有值均位于 Bernstein 系数的最小值和最大值间。
这既包围整个分区，也当然包围分区内的临界值。

**驻点 Taylor 界。** 令 `m=(l+h)/2`、`rho=(h-l)/2`，并精确展开
`Q(m+z)=sum a_k z^k`。若 `Q'(m+z)=0`，乘以 `z` 并代回可得

```text
Q(m+z) = a_0 - sum_(k>=2) (k-1) a_k z^k.
```

对于偶数 `k`，`z^k` 在 `[0,rho^k]`；对于奇数 `k`，它在
`[-rho^k,rho^k]`。按系数符号作有理区间加法得到一对界。
该恒等式严格消除了误差的一次项，不需要相信近似导数根或浮点残差。

**临界余式界。** 精确除法 `Q=T*S+R` 给出 `Q(r)=R(r)`。
对 `R` 再用 Bernstein 界，可在临界集合上降次；当 `R` 为常数时特别有效。
这项界只用于有临界根的区间，不用于声称整个区间的 `Q` 值域等于 `R` 值域。

取三种区间的交集，即“下界最大、上界最小”，仍包含全部临界值。
如果单根区间另给出有理 `r`，验证器必须检查 `l<r<h`、`S(r)=0` 和 Sturm
根数恰为 1；才允许与精确区间 `[Q(r),Q(r)]` 再取交集。
精确根建议永远不会替代完整根数证明。

## 6. 全局上下界与误差

全局上界 `U` 为下列有限集合中的最大值：

1. 两个工作区间端点的精确值；
2. 所有精确临界根的精确值，包括分界点根；
3. 每个有根区间的临界值上界。

由候选完整性，所有可能达到全局最大值的位置都已覆盖，因此真实最大值
`M <= U`。没有根的分区无需用 Bernstein 包围整个多项式，这减少了不必要的
值域细分。

下界 `L` 首先来自区间端点、分区中点、分界点及已知有理根的精确取值。
此外，每个有根区间的临界值下界也是 `M` 的下界：至少存在一个临界根，且该
区间内所有临界值都不低于它。取这些下界的最大值得到 `L <= M`。
`lower_source` 明确记录最后取用的是可达的工作坐标值还是有根区间的存在性界。

于是证书严格保证

```text
L <= M <= U,
error_bound = U-L.
```

`target_met` 当且仅当 `U-L <= tolerance`；`isolation_complete` 当且仅当
不存在根簇。两个条件同时成立才是 `enclosed`，再加 `L=U` 才是 `exact`。
即使误差已满足、但根仍未隔离，状态也保持 `open`。一个 `exact` 最大值证书
不承诺已经识别所有达到最大值的位置。

## 7. 区间 Newton 收缩为何安全

已知单根区间中的根为 `r`，在中点 `m` 用均值定理可得

```text
r = m - S(m)/S'(xi),       xi 位于 m 与 r 之间。
```

若 `S'([l,h])` 的 Bernstein 包围 `[d0,d1]` 不含零，则右侧位于
两个端值 `m-S(m)/d0` 与 `m-S(m)/d1` 之间。
先与原区间相交，再将左端向下、右端向上取二进有理数，仍不会排除根。
二进网格精度最多 512 位，这是提议精度的上限；无法有效收缩时回退到二分，
并不限制证书最终二分坐标的精度。

生成器只接受区间宽度至少减半的收缩提议，并按新增边界数扣减节点预算。
更重要的是，Newton 步骤不是验证器的信任前提：验证器只看到最后的分区，
重新精确证明每个分区根数、边界根和全局根覆盖。因此提议中的实现错误如果
造成根的位置判断错误，也不能通过省略根来伪造可接受的上界。

## 8. 重放、预算与未证明事项

验证器重算证书的规范形式并进行递归的严格类型和值比较：`True` 不能冒充
整数 1，`8.0` 不能冒充节点预算 8，多余字段也会被拒绝。它不调用 `maximize`，
不重新执行自适应规划，不需要原浮点建议或外部文件。

“独立重放”意味着独立于搜索历史和候选来源；生成器和验证器仍共享经过测试的
有理代数函数。这里没有声称拥有第二套独立实现或机器形式化证明，字段
`formal_assistant_checked` 固定为 `false`。

`refinement_nodes` 是最终分区新增边界数，可由证书直接验证，并非不可重放的
历史计时。预算足够时的合理收缩会逐渐缩小临界值区间；预算耗尽即输出有效
`open`。对极近根、高位长输入或极小容差，不承诺固定预算内达到目标。

本模块证明的只是有理多项式在有理闭区间上的全局极值包围。它不自行证明
几何谱问题的 Barta 前提、矩阵正定性、模型选择或几何常数最优性。几何层若
采用 `maximum_upper`，必须先通过本格式的 `verify`，再核对它绑定的
`polynomial` 与 `interval` 正是所需多项式与区间。旧 `verify_range` 不接受
本格式；不得仅替换旧证书字段而假装原验证器已支持。

## 9. 验证与实际对照

执行 `python3 -m unittest test_exact_extrema -v`：20 项测试通过。覆盖常数、
单点区间、仿射、多峰、偶函数的多种区间位置、端点根、驻点拐点、极近根、
非有理临界点、24/32 次平坦峰、32 次单调多项式、20 组已知有理临界点随机
样例、浮点建议、零预算、逐步精度、区间 Newton、独立重放及多种篡改。

以下结果由 `test_exact_extrema.comparison_rows()` 直接计算，双方证书均重放。
同一绝对容差 `1/10^12`、最多 32 个新增分区边界；旧方法设 `max_leaves=33`。
双方可提前达到阈值，故实际消耗节点不必相同。**这里只比较节点和界宽，
不是运行时间基准，也不意味着所有输入都更快或更精确。**

| 样例 | 旧节点 | 新节点 | 旧精确界宽 | 新精确界宽 | 新状态 |
|---|---:|---:|---|---|---|
| `x-x³` | 20 | 8 | `82667/108086391056891904` | `46114501/590295810358705651712` | enclosed |
| `-(x-1/3)^8` | 6 | 0 | `3641/205195258022068224` | `0` | exact |

非对称双峰用导数 `-(x+4/5)(x+1/4)(x-2/3)` 积分、常数项取零构造。
本组新证书的误差均严格小于旧证书，但这只是四个可复现实例。
旧方法本来也对低次和部分偶多项式采用精确求极值，本对照没有把这些已有
