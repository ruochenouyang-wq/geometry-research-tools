# 八个新增版本：V3–V10

现有两版作为基线，不计入这八次。每项只有在代码、数学条件、正确性检查与实验都完成后才标为完成。路线可能随实验证据调整，不能把失败方案包装成普遍改进。

| 版本 | 研究问题与预定实质改动 | 状态 |
| --- | --- | --- |
| V3 | 各尾部模式分别估计，并让尾部同时参与上下界；支持一般谱编号 | 已完成：[依据](V03.md)、9 项测试、results/v03 |
| V4 | 浮点只提出端点，有理检查决定接受；减少昂贵二分并保留高精度回退 | 已完成：[依据](V04.md)、6 项测试、results/v04 |
| V5 | 自适应全域多项式范围认证，减少势函数界过宽带来的损失 | 已完成：[依据](V05.md)、6 项测试、results/v05 |
| V6 | 对整个谱做奇偶分块认证，减少消元成本且保持全局谱编号 | 已完成：[依据](V06.md)、4 项测试、results/v06 |
| V7 | 根据残差瓶颈提高试探函数精度，突破固定 44 位系数量化平台 | 已完成：[依据](V07.md)、5 项测试、results/v07 |
| V8 | 认证多个近邻特征函数张成的子空间，避免依赖谱簇内部小间隔 | 已完成：[依据](V08.md)、6 项测试、results/v08；保留 1 维失败和无效界 |
| V9 | 从单个算子推广到一段参数族的统一谱界，检查覆盖与失败点 | 已完成：[依据](V09.md)、6 项测试、results/v09；保留反例与预算失败 |
| V10 | 根据误差来源分配模式数与精度，并比较组合策略的成本和失败情况 | 已完成：[依据](V10.md)、6 项测试、results/v10；另有 results/final 跨代对照 |

共用模型仍是单位球面轴对称子空间中的 `-Δ+q(cos θ)`。新版本不得暗中把结论扩大到任意曲面或一般开放问题。

八版自身共 48 项测试；另有 49 项基线回归测试和 5 项统一接口测试。最终审查加入了“下界比较矩阵不得用于证明上端点”的拒绝条件。每版保留独立入口、实验记录和推导；实验中的负收益不作为未完成处理，也不被隐去。
