# C2 与外部严格特征值界方法的比较

核对日期：2026-09-22。本轮实际联网阅读作者论文正文与期刊页面，选择三篇已发表论文及两篇直接相关的 2026 年预印本。未运行外部算法，也未在球面问题上复现它们；以下明确区分论文已证明的范围、本项目已实现的范围和迁移设想。

**结论：C2 是经典谱认证机制之上的需求驱动调度器，目前尚无证据证明它胜过外部同类算法。** 它的价值在于把指定精度转换为“辅助界需要算到哪里”，并在有限候选中改善证书。C1 已有这一调度方向，C2 扩充了尝试范围。值得保留的是可回放证书和部分困难输入的成功率；下一步应比较互补证明机制，而不只是继续微调同一个 Temple 公式。

## 1. 先统一问题，避免比较不同任务

本项目研究单位球面 S²（半径为 1 的二维球面）上的 H=−Δₛ+q：−Δₛ 描述沿球面的变化，势 q 是一个乘法项。轴对称指 q 只依赖高度 z。目标势包括两半球分段常数的 step，以及 q(z)=b+a|z|^α、−1/2<α<0 的赤道奇异势。

最低谱值是能量商的最小值。完整空间允许所有合适函数；平均零空间要求 ∫ₛ₂u=0。后者必须把能量问题限制在这个子空间，等价地使用压缩算子 P₀HP₀，其中 P₀ 将函数减去它的平均值；**当 q 不是常数时，它通常不是把完整空间的第一个特征值删掉。** 轴对称势允许按方位振荡次数 m 分块，但求全局最低值还要覆盖其他块及无限尾部。

认证上下界 [L,U] 的意思是证明真值落在区间内，不能只检查高精度小数相符。Rayleigh–Ritz 是把能量最小化限制在有限试验空间的方法，可给上界；真正困难通常在下界和遗漏谱的排除。

C1/C2 的典型单块步骤是 Temple 残差界：对归一化候选 u，令 μ=〈Hu,u〉、v=‖Hu−μu‖²。若已证明同一问题的第二特征值至少为 β，且 μ<β，则最低值位于

\[
[\mu-v/(\beta-\mu),\;\mu].
\]

残差衡量候选不满足方程的程度；这里是完整函数空间中的残差，不是小矩阵内已接近零的残差。C 把精度 ε 换成 β 大约需要超过 μ+v/ε 的需求，再验证该需求。这个代数重排与候选调度，不构成新的特征值包围定理。[本地 C2 报告](../../c_demand_extension_20260922/REPORT.md)、[C1 说明](../../geometry_parallel_v1_20260921/c_adaptive/README.md)。

## 2. 五个最有判别力的一手来源

## 3. 两篇新稿究竟能否处理本项目的奇异势

以下是根据已核对假设做的适用性推断，不是声称已完成新的迁移定理。

**赤道是一条奇异曲线，不能当作三维空间中的单个奇异点。** 球面高度坐标满足 dS=dz dφ，所以在赤道附近

\[
\int |z|^{p\alpha}\,dS<\infty\quad\Longleftrightarrow\quad p\alpha>-1.
\]

在当前 −1/2<α<0 范围，取 p=2 即可。因此，对光滑且有界的试验函数，q u∈L²，C 的强残差及 S3 的二次矩阵积分有合理入口；仍要逐个检查实际试验函数的算子定义域和界面条件。到 α=−1/2 时，赤道不消失的常见试验函数使 q²|u|² 积分发散，卡住的是这一证书路线，而不意味着能量问题不存在。

S5 二维假设中的门槛是某个 p>1，弱于强残差所需的平方可积。因而 α=−1/2 仍可选 1<p<2 满足上述局部条件。**这给出了超出 C 当前证书边界的具体机制线索**：控制 ∫q|u|² 这样的能量项及其扰动，而不是一定控制 ‖qu‖²。要迁到 S²，还需推导球面的显式嵌入/局部误差常数、势近似误差、曲面或坐标误差，以及平均零空间的投影；仅检查可积性远远不够。[S5 假设与构造](https://arxiv.org/html/2605.05177v1)。

S4 的现成有界势公式不能直接处理 a<0 时 q→−∞ 的情况：任何有限常数平移都不能使 q 逐点非负，有限有界函数也不能在整个赤道邻域逐点位于 q 下方。**这不排除用有限平移把总能量变成正定**；后者利用梯度能量对奇异负项的控制，是另一件事。S4 注 4.18 所预告的方式依赖三维 Hardy 不等式，即用梯度控制特定奇异加权积分；作者明确限制了维数，并把完整实现留给后续论文。当前没有可照搬到二维球面赤道的显式常数。[S4 注 4.18](https://arxiv.org/html/2607.04247v1)。

对 step，有界势迁移障碍较少，但仍非现成替换：球面算子的高度坐标系数在两极退化，不能把它直接当成普通均匀椭圆的一维区间问题。可选择球谐函数推导投影常数，或严格控制曲面有限元的几何误差；两条路线都要实现约束、其他方位块与谱尾的证明。

## 4. 对 C2 的具体评价与公平比较方式

**已实现的优势较窄，但真实存在。** 本地 22 个公开开发/回归任务中，C2 全部重复均成功 21 个，C1 为 20 个；在共同成功的 20 题上，C2 总时间比 C1 多 5.65%。C2 的证据支持“用一部分额外开销换来一个困难输入的成功”，不支持“普遍提速”，更不支持超过某篇外部算法或降低了真实模型 token。[本地结果](../../c_demand_extension_20260922/REPORT.md)。

剩余 E18 失败还暴露出与认证定理无关的调度缺陷：控制总宽度的是 m=0 块，C1/C2 却继续压低已不决定答案的 m=1 残差。这表明进一步研发首先要识别决定最终区间宽度的组成部分；换用一个更强的单块定理，也不能自动修复资源投错位置的问题。

建议只推进三个有明确胜负条件的外部对照：

1. **粗下界 + 精细后验界。** 先在 step 上迁移无邻谱先验的投影/非协调下界，用它证明足够的 β，再接现有 Temple 或成组的 Kato/LG。比较达到同一全局区间宽度的总时间与证书回放成本；若粗界开销长期高于 C 当前辅助认证，则保留为失败回退。组合思路已有 S1 先例，创新点只能来自球面迁移、显式常数或调度效果。
2. **能量误差路线。** 以奇异势特别是接近 α=−1/2 的任务检验 S5 式弱形式能否避免 q² 的限制。弱形式是把微分方程转成对试验函数的积分关系。必须把势的近似、几何、代数和舍入误差全部纳入证书。若只是让候选算得更准，却没有可算的全局下界，应判为未完成能力扩展。
3. **二次投影作独立交叉检查。** 先验证它对已有可处理势能否低成本发现谱位置或捕获错误 β；必须补上最低谱序号定位。若二次方程的认证成本抵消收益，就不作为主求解器。

公平实测必须使用相同算子、完整/平均零约束、容差和失败计入规则；将装配、奇异积分、几何/谱尾控制及最终证书回放全部计时。未知数更少、区间更窄和模型 token 更少是三个不同指标。尤其 S4 的一维示例明确做了区间矩阵认证，但其注 5.1 说明二维表下界把公式应使用的复合离散特征值替换为普通 Ritz 上估计，并称最终认证数字需后续计算确认；不能把该表的未知数比例作为本项目已面对的完整严格性能纪录。S5 则明确把完整浮点舍入验证留作后续工作。[S4 数值状态](https://arxiv.org/html/2607.04247v1)、[S5 实现限制](https://arxiv.org/html/2605.05177v1)。
