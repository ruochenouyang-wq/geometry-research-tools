# C 与外部算法的比较评估

日期：2026-09-22。本报告以最新 C2 为主要对象，C1 指扩展前的 C。论文和软件资料经过本轮联网核对；此前的项目内部成绩与本轮外部组件实验分开报告。

**结论：C 是有实际用途的专用认证求解原型，核心数学方法已有成熟先例。实测支持保留 C 的原题认证，并尝试接入成熟数值库；现有证据不足以称 C 领先外部完整算法。** 本文的判断不把软件名气、版本数量或内部通过率当作外部排名。

## 1. 先明确比较的是什么

C 目前处理的是单位球面 S²——半径为 1 的球的表面——上特定势函数的**最低谱值**，可以理解为某个能量表达式能够取得的最低值。势函数描述不同位置对能量的额外影响。给出一个近似数值与证明真实数值落在足够窄的区间内，是不同的完成标准。

**离散化**是用有限个系数近似函数问题。**Galerkin 方法**选择一些基本函数，以它们的线性组合构成候选空间，再把问题写成有限矩阵方程。这里需要区分三层工作：

| 层级 | 需要完成的工作 | 能否直接代表解完 C 的原题 |
|---|---|---|
| 数值候选 | 求有限矩阵的近似特征值和向量 | 不能，仍有表示及舍入误差 |
| 矩阵认证 | 证明有限矩阵的真实特征值处于某个范围 | 不能，仍须连接到原始函数空间 |
| 原题认证 | 同时控制无限维余项、积分、空间约束和最终误差 | 才能与 C 的完整证书比较 |

**证书**是包含计算结果及验证所需信息的数据；C 使用确切有理数保存证据，并由原题验证器重算。其数学推导和实现接受过审查，但尚未全部交给形式化证明助手——按严格逻辑规则逐步检查证明的程序——验证。区间软件也不自动替使用者证明从有限矩阵到原问题的每一步。

因此，“普通数值库没有自动给出球面原题证书”不能证明 C 比它优秀；“普通数值库算完矩阵非常快”也不能直接证明 C 的整个认证流程多余。

## 2. 与哪些已有算法最接近

### 2.1 LAPACK、ARPACK、SLEPc：成熟的特征值计算

**LAPACK** 是线性代数计算库；NumPy 的 `eigh` 接口调用它，处理具有对称结构的矩阵特征值问题。**ARPACK** 是迭代求解少量特征值的软件，SciPy 的 `eigsh` 已提供精度阈值和移位逆变换；后者通过求解带选定移位的线性方程，更快接近需要的特征值。**SLEPc** 是面向大规模特征值问题的工具框架，已有残差收敛、自定义停止和谱变换接口。[NumPy 官方说明](https://numpy.org/doc/stable/reference/generated/numpy.linalg.eigh.html)、[SciPy/ARPACK 官方说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.sparse.linalg.eigsh.html)、[SLEPc 官方手册](https://slepc.upv.es/release/documentation/manual/eps.html)

这说明按精度停止、移位和监控残差不是 C 首创。C 的不同工作在于：把原始函数问题的可证明误差反馈给候选选择，并处理现有软件接口之外的球面数学条件。**残差**是把候选代入方程后剩下的误差；矩阵残差只检查有限个坐标，C 所需的完整残差还包含这些坐标以外的部分。SLEPc 的“真实残差”指未作谱变换的矩阵残差，不应误写成已检查全部函数方向。[SLEPc 残差与收敛说明](https://slepc.upv.es/release/documentation/manual/eps.html)

### 2.2 奇异适配谱方法：少量分数幂不是新的总体思路

**谱方法**使用一组全局基本函数近似解；**奇异适配**让这些函数符合解在奇点附近的行为。Yang、Wang、Li、Sheng 的 Müntz 谱方法已经针对奇异特征值问题和分数幂势设计非标准基，并强调稀疏线性系统的效率。这里的 **Müntz 基**允许使用不同于普通整数次数的幂函数。[作者论文](https://arxiv.org/abs/2303.05020)

C 的球面赤道奇异性与该文球体中的奇异模型不同，需要专门适配。可展示的贡献是本题的基选择、精确积分、全部分量覆盖和证书；仅仅“用分数幂比普通多项式准确”不足以证明超过成熟的奇异适配方法。本轮没有复现该论文完整算法，也没有比较它的最佳基与 C 的基。

### 2.3 严格后验界：理论上比当前 C 更广的参照

**后验误差界**是先计算候选，再根据候选和残差给出真实误差范围。C 使用的 **Temple 不等式**属于经典谱误差工具：若候选的能量 μ 低于已证明的第二谱值下界 β，则可以用完整残差平方 v 给出误差界 v/(β−μ)。公式及谱分离条件都有既有理论来源。[Teschl 作者书稿，定理 4.13](https://www.mat.univie.ac.at/~gerald/ftp/book-schroe/schroe.pdf)

成熟研究不局限于单个简单谱值。Cancès、Dusson、Maday、Stamm、Vohralík 的工作处理**谱簇**，即一组相近或重复的特征值，在与外部谱值分离的条件下给出可靠后验界，并展示有限元与周期平面波离散的实现。**有限元**把几何区域分成小块，在各块内用简单函数近似解。[原论文](https://arxiv.org/abs/2008.04140)

这类方法为 C 处理多个竞争分量提供了更成熟的理论参照。不过，文中的边界条件、空间和势函数前提不能直接替换为本项目的球面赤道奇异势。其理论范围更广，不等于已经在 C 的每道题上更快。

**Lehmann–Goerisch 方法**借助近似梯度等辅助信息构造下界；Vejchodský 的比较研究已经展示先取得粗下界、再用更强后验界收紧的组合。后续局部重建研究还减少了辅助问题的计算成本。因此，“先证明粗界再细化”也有直接先例。相关实例主要是平面区域，球面几何、平均零约束与无界势仍需额外适配。[三种方法的实算比较](https://arxiv.org/abs/1602.08961)、[局部通量重建](https://arxiv.org/abs/1801.02561)

**二次投影法**把算子及其平方相关积分组合成二次矩阵方程，能在不预先给出 β 的情况下得到与真实谱相交的区间。但“区间内存在一个谱值”不自动等于“这个区间包含最低谱值”，仍需定位谱序号；其强算子积分也不会自动消除 C 的平方可积性限制。它值得做另一种谱位置检查，本轮没有复现该算法。[Boulton–Hobiny 原论文](https://arxiv.org/abs/1307.0313)

### 2.4 2026 年的新谱下界研究：值得跟进，但不能只引用摘要排名

Liu 的 2026 年谱 Galerkin 预印本研究通过**投影误差常数**——控制有限表示丢失多少信息的常数——给出特征值下界，旨在减少对相邻特征值先验界的依赖。这直接对应 C 经常遇到的“先证明 β 才能使用残差界”的成本。正文主要路线有非负有界势等明确条件，奇异推广另有条件；它不是当前球面赤道奇异题的现成替换。[预印本正文](https://arxiv.org/html/2607.04247v1)

对该文数字还需按作者说明区分：一维例表声明使用区间矩阵与验证特征值例程；二维表 2、3 的下界末位仍需配套计算确认。本文不把摘要中的自由度优势直接当作已完成的同题认证性能成绩。[正文第 5 节，Remark 5.1](https://arxiv.org/html/2607.04247v1#S5)

同作者另一篇 2026 年奇异势有限元预印本提供了扩大支持范围的线索。它在二维情形使用适当的 Lᵖ 条件；这里 Lᵖ 表示函数绝对值的 p 次方具有有限积分。对于当前赤道附近的势 q=a|z|ᵅ，若只需某个 1<p<2 的条件，便可能处理 α=−1/2，而当前强残差路线在此会遇到 q² 积分发散。这个推断只说明研究方向：仍需证明球面上的能量估计及空间约束条件，且该文实现尚未完成全部浮点舍入认证，不能将它直接计作已解决 C 的失败题。[奇异势预印本正文](https://arxiv.org/html/2605.05177v1)

### 2.5 INTLAB、Arb/FLINT、VSDP：应考虑借用的验证工具

**区间算术**以数值范围代替单点，在每一步覆盖舍入误差。INTLAB 提供包括有限矩阵特征值在内的可靠计算；Arb/FLINT 提供可提高精度的数值包围和代数计算；VSDP 验证已写成有限维锥规划的优化结果。[INTLAB 矩阵示例](https://www.tuhh.de/ti3/intlab/demos/html/dintval.html)、[Arb 算术契约](https://flintlib.org/doc/arb.html)、[VSDP 官方项目](https://github.com/vsdp/vsdp-2020)

它们适合成为 C 的算术底座、有限矩阵验证器或新优化路线的组件。本轮没有核实这些项目拥有直接输入当前球面奇异势并完成全部认证的现成入口；这只是复现状态，不是能力上限判断。另一方面，C 用自写有理运算完成检查，也不意味着比这些库更成熟或更快。

## 3. 本轮实际测了什么

本轮实测的是 NumPy/LAPACK 能否直接替换 C2 的候选计算环节。选择四道已有公开题，每题使用 6、10、16 个原始幂函数的空间，两种候选器各重复三次，共 72 次运行。它们是 12 组题目与空间配置，不能算作 72 道独立题。选择和参数在完整实验前固定，属于组件检查，未使用新的盲测题。

两种候选器共用精确矩阵、相同线性约束、已证明的谱界，以及同一个原题证书生成器和验证器。NumPy 先把广义矩阵问题变成普通对称问题，再调用 LAPACK；这层转换由本项目编写，因此不能把整套包装称为外部作者已经完成的球面求解器。公共准备成本单列，每次候选及认证设 10 秒安全期限。

比较仍有两个重要差异。NumPy 使用 53 位二进制有效精度，C2 在有理运算中将候选向量取整到 112 位；取整是控制数字长度，不能直接换算成最终答案的保证位数。NumPy 求的是 **Ritz 候选**，即有限空间内能量最小的近似解；C2 还尝试进一步减小完整残差。两者候选优化目标与算术精度不同，但原题及最终容差相同。失败只能说明直接替换未成功，不能据此断言 C2 的矩阵算法更先进。

### 3.1 达标和失败

72 次固定运行全部完成，没有准备失败或超时。以下“达标”均指同一原题验证器接受证书，且认证区间宽度不超过题目要求；“有效但未达标”表示证书有效，区间仍太宽。

| 结果 | C2 有理候选 | NumPy/LAPACK 双精度候选 |
|---|---:|---:|
| 达标运行 | 30/36 | 18/36 |
| 有效但未达标 | 6/36 | 6/36 |
| 矩阵分解失败 | 0/36 | 12/36 |
| 三次重复均达标的配置 | 10/12 | 6/12 |
| 至少一种规模达标的题目 | **4/4** | **4/4** |

**四道题在 10 项空间下，两种方法都达标。** 因此，配置通过数的差距不能解释为 C2 多解决了题目。6 项空间下，E16、E19 的两种结果都未达到要求；16 项空间下，NumPy 的四道题、共 12 次运行都在 Cholesky 分解处失败。**Cholesky 分解**把正定质量矩阵写成较容易计算的三角矩阵乘积；这里的失败信息是浮点矩阵未被识别为正定，尚未进入特征值求解。

### 3.2 成本

以下只比较双方都稳定达标的 6 组配置、各 18 次运行，避免把提前失败的用时当作提速。数字是这些运行的累计实耗时间，单位为秒。

| 阶段 | C2 | NumPy/LAPACK |
|---|---:|---:|
| 候选计算 | 0.075974 | 0.013479 |
| 额外浮点表示转换 | 0 | 0.002577 |
| 原题证书生成 | 2.298322 | 2.292600 |
| 原题绑定核验 | 2.263950 | 2.267530 |
| 候选至核验的流程总计，含进程及通信 | **4.707811** | **4.640431** |

只看候选计算，NumPy 的累计耗时约为 C2 的 **1/5.64**；把 NumPy 的额外转换也计入，约为 **1/4.73**。但包括认证后的流程总用时只减少约 **1.43%**。每个配置只有三次重复，这个小差距不足以建立稳定的整体提速结论。对应父子进程合计 CPU 时间——处理器实际执行所用的时间——分别约 4.7024 秒和 4.6318 秒，方向相同。

公共准备另有成本：四题的已验证谱界上下文合计 **2.6328 秒**，12 组精确矩阵准备合计 **0.0975 秒**。这些输入供双方重复使用，未加入上表，也不能重复算进每一行。候选流程中的认证已经包含在总计内，不能再将各行与总计相加。本实验不是每次从启动解释器、构造谱界开始的完整 C 求解计时。

在本轮共同成功的 C2 流程里，候选计算只占约 **1.6%**，证书生成与核验占约 **96.9%**。这说明仅优化候选计算，难以在这组实验上取得数量级加速；更值得先检查认证是否存在可减少的重复计算。该占比不能直接套到此前全部题型的完整 C 流程。

本机环境为 Python 3.12.14、NumPy 2.3.5、Apple Accelerate 的 BLAS/LAPACK 后端，按协议设置单线程。BLAS 是基础矩阵运算接口。实验没有调用模型接口；未测量开发代理的 token、外部软件许可费用或模型使用费用。token 是模型处理文字等输入输出时使用的计量单位。矩阵序列化大小也不能当作峰值内存或 token 消耗。

### 3.3 这些结果说明什么

首先，当前幂函数表示存在数值稳定性问题。16 项空间下，浮点质量矩阵的条件数诊断约为 10¹⁷–10¹⁸；**条件数**衡量输入的小变化可能使结果变化多大。如此大的诊断值与分解失败一致，支持先改善表示或提高精度。不过，这些条件数本身也是浮点估算，不是严格认证的条件数，更不能代表 LAPACK 在合适表示或更高精度下的能力。实验后没有改换基、删去方向或重新调参以修复失败。

其次，C2 并非总能得到更窄的区间。E19 的 10 项结果中，C2 的认证宽度约为 **1.4153×10⁻⁹**，NumPy 约为 **5.2811×10⁻¹¹**，后者约窄 **26.8 倍**；两者都满足 10⁻⁸ 的目标。C2 按目标提前停止，与追求该空间内最好的 Ritz 候选有不同取舍。这不构成 C2 的精度错误，但不能把“目标已满足”宣传成“精度最优”。

最后，12 次分解失败并未被认证器误判成功；其余 60 次都生成了有效原题证书，其中 12 次明确保留为精度未达标。**成熟数值库可以提供有用候选，原题验证则能把可用结果与失败区分开。** 这支持研究“先用快速候选、验证未通过再换表示或升精度”的组合，尚未证明这种新组合已经降低完整求解成本。

本轮不运行 SLEPc、INTLAB、Arb 或论文完整实现，也不把它们的文献成绩与本机秒数混排。

## 4. 对 C 的分项评价

| 维度 | 当前评价 | 判断依据 |
|---|---|---|
| 数学原创性 | 核心原理已有先例，组合贡献有待更严格外部验证 | Temple、移位、残差停止、奇异适配基均有直接来源；尚无新的收敛或复杂度定理 |
| 原题可靠性 | 是当前最有价值的部分，但有支持范围 | 精确积分、完整残差、谱界和全分量证书相连；仍依赖已有数学实现和人工审查 |
| 通用性 | 明显有限 | 主要是单位球面的轴对称特定势；一般曲面、非轴对称、多谱值和边界奇异性需新工作 |
| 数值效率 | 内部已有局部收益，外部领先未建立 | C2 解出旧失败题，但共同成功题比 C1 慢 5.65%；组件实验不能代替整题排名 |
| 自动研究能力 | 有用的数值工具，尚非通用研究系统 | 接收结构化问题并搜索证书；数学表示、证明路线与适用条件仍由开发者设计 |
| 工程成熟度 | 可运行、可追溯的研究原型 | 有失败保留、任务绑定、冻结测试；仍有大量历史模块依赖，缺少广泛外部复现 |

这里没有给出看似精确的总分，因为当前没有统一题库、相同认证标准下的外部完整实现和足够重复实验，无法据此标定“世界第几”或综合评分。

此前 C2 的 21/22 是固定公开数学测试集上的稳定达标率，不能解释为一般数学问题正确率。20 道新公开题仍为 19/20，增加的成功来自旧 E19；E18 则证明只优化预先选定的分量会错过真正瓶颈。[内部固定评测与败因](../c_demand_extension_20260922/REPORT.md)

## 5. 对后续开发的建议

**保留认证和决策逻辑，优先借用成熟数值组件。** 是否更换候选器应以同一原题验证器的结果和完整成本为准。成熟矩阵算法可以负责近似候选，C 负责连接到原题并检查其保证；两者的职责与费用需要明确。

本轮优先级应由成本决定：先分析认证中的重复工作，再评估快速候选与高精度后备的组合。当前候选计算已经很短，只继续优化这个环节，对整体速度的帮助有限；任何认证加速都须保留对原函数、空间、谱界与最终区间的检查。

**把算法从固定分量细化，推进到主导分量识别。** E18 的证据是：m=1 分量的残差已大幅下降，整体区间仍由 m=0 决定。这里 m 表示绕指定轴的角向变化频率。应按各分量区间判断哪个部分需要更多工作，进一步研究谱簇理论或多分量误差预算，而不是统一增加迭代次数。

**把表示和数值稳定性纳入成本选择。** 幂函数很适合表达奇异结构，却可能形成难以可靠求解的质量矩阵。质量矩阵描述候选函数之间的大小与重叠；正交化是把基本函数换成彼此没有内积重叠的组合。适当的正交化或成熟奇异适配基，可能比单纯提高所有运算精度更划算。这是待验证的开发方向，不是本轮已证明的提速结论。

**扩展能力时，优先研究新的误差界。** 对 α=−1/2 一类题，继续加深当前平方残差计算不能消除积分发散。可以研究弱形式路线，即先对方程作积分、在能量层面控制误差；同时研究不依赖相邻谱值先验界的粗下界，减少取得 β 的成本。两条路线都需要新的数学适配，不能只替换数值库。[弱形式的奇异势研究](https://arxiv.org/html/2605.05177v1)、[投影误差下界研究](https://arxiv.org/html/2607.04247v1)

外部完整对照的下一道门槛，应是另一条独立数学路线也对同一批球面原题给出同等宽度的严格区间，成本覆盖表示、组装、求解和认证。只有跨过这一层，才能讨论 C 相对成熟严格求解算法的净优势。

至于“较小模型半小时超过较大模型八小时”的最终目标，目前依然没有直接证据。数值程序的秒数、证书字节数和算法版本数量，都不能替代真实模型的同题对照；开发代理的 token 也未在本轮单独计量。
