# V91–V94：把零均值约束接入全空间谱认证

**本轮完成四项功能增量：正确的零均值投影、非轴对称扇区、两层无限尾部认证，以及固定势不等式的模型接口。** 23 个预先固定的验收算例全部通过，33 份顶层证书全部回放通过。冻结 V90 的 361 个清单文件保持一致。

这次扩展了工具可证明的数学对象。它没有解决 GN 开放猜测，也没有把上轮的二维函数族最优值升级为通用最佳常数。

## 1. 现在能处理什么

给定单位球面上的轴对称有理多项式势 q(x₃)，新工具认证

\[
C(q)=\inf_{0\ne u\in H^1(S^2),\ \int_{S^2}u=0}
\frac{\int_{S^2}(|\nabla u|^2+q(x_3)u^2)\,d\sigma}
{\int_{S^2}u^2\,d\sigma}.
\]

**u 可以是整个球面上的任意零均值函数，不要求轴对称，也不限制在选定的有限维试探空间。** 势 q 仍限制为轴对称、次数不超过 6。这对应投影算子 Π(-Δ+q)Π 在零均值空间中的最低特征值。

此前的普通谱工具不能通过改一个特征值序号就正确表达这个对象。已有正函数方法对无约束基态有全空间意义，但也不能自动处理这里的零均值约束。

| 增量 | 实际变化 |
|---|---|
| V91 | 移除常数模态后构造正确的投影二次型；先完成 q 的乘法，再投影 |
| V92 | 用有理关联 Legendre 基计算 m≥1 扇区，涵盖非轴对称函数 |
| V93 | 每个扇区控制所有遗漏次数，再控制无穷多个遗漏角向扇区 |
| V94 | 直接判定固定势的加权 Poincaré 不等式；简短回执与完整证书分开 |

版本号表示功能增量，不表示四项新数学定理。详见 [迭代记录](ITERATIONS.md)。

## 2. 一个完整、可复核的结果

取 q=2x₃²，得到最佳常数的外包小数区间

\[
\boxed{2.382655406155\ \le C(2x_3^2)\ \le 2.382655406157.}
\]

底层有理证书更窄：固定题集 E20 的宽度约 1.57×10⁻¹³，上面显示时做了向外舍入。

因此工具实际证明了：对所有零均值 u∈H¹(S²)，

\[
\int_{S^2}(|\nabla u|^2+2x_3^2u^2)\,d\sigma
\ge 2.38265540615\int_{S^2}u^2\,d\sigma.
\]

同时，它认证把右侧常数换成 2.4 后不等式不再对所有此类函数成立。这个反驳由谱上界保证违反者存在；接口没有声称已经输出显式反例函数。

本例最低分支为 |m|=1；只算轴对称零均值函数会得到约 3.17212791965，不能将其用于整个函数空间。算法还证明遗漏的 |m|≥2 扇区能量至少为 6，因此不存在被遗漏的更低分支。

这与 [Usov 原论文 Table 1c 的椭球波 m=1 数值](https://arxiv.org/pdf/2307.04124v1)兼容。数表是外部校准；严格区间由本工具的有理证书与无限尾部论证产生，而不是由有限小数表推出。不是新的最佳常数发现。

## 3. 正确区分三个数学问题

| 势 q | 普通轴对称算子的第二特征值 | 轴对称零均值投影的最低值 | 整个球面零均值投影的最低值 |
|---|---:|---:|---:|
| t | 2.09076064836 | 1.93400023355 | 1.93400023355 |
| t+t² | 2.65098846030 | 2.52925611476 | 2.15057831208 |

这些是不同算子的正确数值，不是旧算法算错了。第一行说明“零均值约束=普通第二特征值”的替换不成立；第二行进一步说明仅处理轴对称函数会遗漏更低的非轴对称分支。

因此本轮最有价值的改进是防止模型把正确证书用到错误的数学对象上。不能用不同对象的数值差异宣称精度提高了某个百分比。

## 4. 如何控制无限维误差

固定 m 后，保留有限次数的球谐基。势的全域上下界给出尾算子的双侧比较，再用包含正确质量因子的 Schur 补与精确惯性认证上下端点。这一步涵盖所有遗漏次数，不只是求有限矩阵的特征值。

随后汇总连续的 m=0,…,M 扇区。对遗漏的角向扇区统一使用

\[
\lambda_{m,1}\ge (M+1)(M+2)+\min q.
\]

完整下界取“所有已计算下界”和“遗漏角向下界”的最小值。若预算耗尽，它可能很宽，但仍然有效。

已刻意测试 q=2t²、只允许 m=0 的情况：工具返回约 [2,3.17213]，并明确标记未达到精度；没有将轴对称结果伪装成全空间结论。证明设计及独立直接积分审查见 [数学说明](PROOF_PROJECTED_SPECTRUM.md)。

## 7. 下一处缺口

目前能证明固定多项式势下的全函数空间二次型下界；还不能对任意非线性约束或整个势族作统一认证。因此仍未获得 GN 通用最佳常数的证书，更没有解决其 q→∞ 渐近猜测。

下一步应把这个投影谱模块接到不等式的变分/对偶归约，处理统一参数族和集中函数；同时补上显式违反者构造。一般曲面、非轴对称势及完整高阶谱重数排序也尚未支持。

本轮证明由有理软件验证器回放，仍依赖文中列明的谱理论与球谐恒等式，尚未经形式证明助手内核检查。没有进行 GPT 模型对照实验，也未证明模型总时间或 token 消耗的加速比。
