# 四道未完成原题的重测与改进

用户要求：重新测试未达标的题目，总结败因，迭代。沿用每个题目十项改进的节奏：C12→V195–204，C14→V205–214，C16→V215–224，C18→V225–234。

每组先重测原题、保存失败或范围缺口，再交付十项实际可调用的数学能力、原始运行证据、独立复核。输入格式、日志、测试与版本标签不能单独充当一版。原题坐标、约束、n=64 和 C18 的 1e-8 目标保持一致。算法预算允许增加，但必须记录，并区别精度提升与计算速度提升。

前一版目录不作修改。所有新文件留在本目录；公共只读入口为 support.py。各实现者只修改其负责模块、测试及题目目录。主任务验收后才登记完成。任一开放间隙、误证风险、无收益及不支持的输入必须保留，不用较简单题替换原题。

本轮不用模型 API，不产生模型 token 或模型对照速度结论。
