# 第八轮独立审查

结论：在已声明的多项式试探、二维函数平面及固定编译势诊断范围内，没有发现阻断性的数学认证问题。独立新增 **11 项测试全部通过**，从保存的 JSON 重读并回放 **86 个 GN 证书对象**全部通过；其中含嵌套和重复证书对象，并不代表 86 个不同数学题。记录与实现 SHA256 见 `INDEPENDENT_TESTS.json`，测试位于 `test_gn_review.py`。本审查未修改被审实现。

## 独立数学校准

1. **面积因子 4 正确。** 对 u=t，标准球面面积下的二次、梯度、四次积分分别为 4π/3、8π/3、4π/5，因此 πK=9/40。程序输出完全吻合；把结果错误放大四倍的证书被拒绝。
2. **Euler 残差确实包含完整高频。** 对 u=t，独立得到 r=4t−(20/3)t³=−(8/3)P₃，范数平方为64/63。对 u=t⁵，完整残差为 −20t³+(320/9)t⁵−(700/33)t¹⁵。两项都和实现的有理结果完全相等，截去最高频项的证书被拒绝。
3. **谱投影停止没有被误当驻点。** 对 u=t，次数预算为1时投影残差为零，但完整残差不为零；输出明确报告这个状态，伪造 `full_stationary` 被拒绝。
4. **局部导数不等于有限步长改善。** u=t 的负残差方向导数精确为24/35，但沿同一方向取步长100时 GN 商反而下降。测试确认接口只声称正的局部导数。
5. **平面的全局最优没有升级为全 H¹ 最优。** span(P₁,P₃) 的认证上界约0.27657，而另一个合法的12次集中帽试探给出约0.40976，构成明确的空间外反例。篡改通用 GN 上界标志被拒绝。
6. **射影方向覆盖完整。** 检查了一个系数为零、负系数以及比例10⁶的方向；两图共同覆盖。用第一图替换第二图、改变符号证明的正缩放因子均无法通过复核。
7. **编译势和宽谱证书绑定正确。** u=t 编译得到 q=−(20/3)t²，其 Rayleigh 商为−2、势能为−4/3。替换成另外一个本身有效的宽谱证书、改变投影或原始函数均被拒绝。

## 信任边界与保留限制

完整残差、精确方向导数、平面最大值和固定势谱区间都是有用工具，但不构成通用 GN 最优常数证明。已有必要性推导只允许“发现更低谱则当前试探不是全空间最优者”，不能反向推出最优性。原始运行失败记录只保留失败状态及仍可复核的编译恒等式；其消息本身不能证明一次运行确实发生，也不能产生任何成功的通用 GN 上界。

没有使用浮点输出作为证明依据，也没有把本次测试或内核运行时间当作语言模型 token 或速度比较。
