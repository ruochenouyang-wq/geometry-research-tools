# 三条并列路线：实施与比较计划

2026-09-21。三版都以 geometry_accuracy80_20260921 为只读基线，彼此不继承成果；不按空版本数量记进展。此次是可复核的公开开发实验，不是未见题正式验收，也不进行模型 API 调用。

## 路线

A 用完整径向惯性与角向尾部排除认证负谱个数，并尝试包围负谱和。B 用端点谱证书、最低谱凹性及试函数仿射能量，证明固定指数下整段幅度的统一精度。C 针对最终所需误差直接检查谱间隔阈值，减少固定精度二分。

共同接口接受基线原任务；A、B 暂无专项优化的普通任务可明确回退基线。回退不记为新增数学能力。扩展接口及证书各自独立。

## 比较规则

共同任务预先固定八题，涵盖阶跃、弱/强负幂的完整空间和平均零空间，以及一般有理指数函数逼近；统一目标 1e-8。四个系统（基线与 A/B/C）各做两次新进程运行，轮换顺序。每次外部硬期限5秒，覆盖求解、输出编码和独立证书重放；进程启动也计入冷启动成本。失败、超时与回退全部保留，不按结果换题。

重复参数流采用固定 alpha=-1/4、完整空间、幅度区间[-1/2,-49/100]、offset=0、目标1e-6。取16个预定内部点，分两次新会话运行；B准备最多30秒。每个系统报告相同顺序下的首题/后续查询和累计成本，B完整计入准备与首次验证，不用B温态对基线冷态。报告N=1/4/16的实测总成本，额外完整证书冷重放另列。

A扩展校准用常势穿零与重数，专项任务用非平凡阶跃/负幂，单项期限10秒。计数与负谱和精度分别报告；常势校准不称为研究突破。B必须给整段覆盖证书并拒绝盒外查询，抽样不能替代参数证明。攻击测试修改函数、空间、尾界、计数/重数或证书数据，验证器必须拒绝。

先比较认证成功数量与错误接受，再比较同成功任务的配对成本与精度。只有两次重复，速度结论标为初步；同任务净成本下降20%以上才称值得继续验证。不同扩展能力不合为一个总正确率。
