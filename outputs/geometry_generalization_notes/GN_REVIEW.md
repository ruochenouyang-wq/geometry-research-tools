# GN 试探与集中函数的通用化简报

本次只阅读 V195–V234、核对一手文献和推导方案，没有实施迭代或修改冻结发布。

最值得推进的方向是：**把“某种函数表达式的精确积分器”提升为“携带 H¹ 误差证明的函数与矩接口”**。轴对称、稀疏整数幂、全局多项式都可以逐步放宽；有限能量、完整球面覆盖、均值约束及分母正性仍须有可核验依据。现有二维平面优化核心仍可复用，因为对任意两个真实函数 f、g，f+s g 的质量和能量依然是 s 的二次式，四次矩依然是四次式。

## 1. 目前限制在哪里

`compact_gn.py` 固定 `y=(1+x₃)/2`，使用稀疏整数幂与有理系数；单函数支撑至多64项，指数与卷积有明确预算。完整 Euler 残差仍通过强 Laplace 算子作用于多项式计算。`family_law` 的整数单调性和极限只属于那一族集中帽。原 n=64 问题被处理，并不表示一般 H¹ 函数已经被处理。

V195–V204 的全空间有限矩约束、V225–V234 的非轴对称反射分块，是有用的相邻能力；它们没有把 GN 接口自动扩展到非轴对称、分片或一般弱可导函数。尤其三轴势可分块，不代表任意 GN 试探函数拥有这些反射对称性。

## 2. 哪个范数足够控制三个矩

以下全部使用单位 S² 的概率面积 `dμ=dσ/(4π)`，取实函数 u,v∈H¹(S²)，e=u−v，且有**经过证明的**界

`||e||₂≤δ₀`，`||∇e||₂≤δ₁`。

一个现成的全空间嵌入是

`||w||₄² ≤ ||w||₂² + ||∇w||₂²`，对所有 w∈H¹(S²) 成立。

它不要求轴对称或零均值，是球面插值不等式取 d=2、p=4 的直接特例。[Dolbeault–Esteban–Kowalczyk–Loss，式(1)](https://arxiv.org/pdf/1210.1853)

因此可以取 `δ₄=sqrt(δ₀²+δ₁²)`，得到 `||e||₄≤δ₄`。若 B₀、B₁、B₄ 分别是 v 的 L²、梯度 L²、L⁴ 范数上界，则由 Cauchy–Schwarz、Hölder 和二项式展开可直接推得

- `|M(u)−M(v)| ≤ 2B₀δ₀+δ₀²`；
- `|E(u)−E(v)| ≤ 2B₁δ₁+δ₁²`；
- `|N(u)−N(v)| ≤ 4B₄³δ₄+6B₄²δ₄²+4B₄δ₄³+δ₄⁴`。

这里 M=∫u²、E=∫|∇u|²、N=∫u⁴。这些是本次推导的误差传递式；可将积分自身误差继续加入各项区间。平方根不必当作精确实数输入，使用向外取整的有理上界即可。

一旦得到 `0<M₋≤M≤M₊`、`0<E₋≤E≤E₊`、`0≤N₋≤N≤N₊`，即有

`N₋/(4M₊E₊) ≤ πK(u) ≤ N₊/(4M₋E₋)`。

**不能省略的条件：**必须证明原函数的零均值；均值“数值接近零”不够。中心化 `Pu=u−∫u` 在 H¹ 中不放大误差，但要把中心化定义及其积分误差一起绑定。质量或能量下界碰到零时，上述商的有限上界应返回未判定，而不是强行相除。

## 3. 用已有嵌入控制误差，不构成循环论证

正在寻找的是乘法形式 `N≤C M E` 的最佳常数。上面的已知加法形式 `sqrt(N)≤M+E` 是独立定理，可以作为误差验证基础；不需要假定目标最佳 C。也可以选用独立证明的较宽乘法常数。例如 Ilyin–Zelik 给出的球面零均值 q=4 估计是面积测度下 `K≤1/π`，换成这里的概率矩即 `N≤4ME`。采用其作为安全误差界，不会证明目标尖锐常数等于4，也不会循环。[Ilyin–Zelik，2023，式(2.4)及 Remark 1](https://arxiv.org/abs/2204.12414)

会循环的做法是：先把“候选最佳常数”作为尚未证实的全函数嵌入常数，再用它把候选自己的尾部误差估小，从而宣布候选最佳。

还有一个重要相邻桥梁，已交叉核对主任务的推导：设 p 为已有谱证书的实有界势，q=p+r，`||r||_{L²(μ)}≤η<1`；m是p的已证点态下界，取 `c=max(0,1−m)`。对同一闭约束子空间定义

`b_p(v)=∫(|∇v|²+(p+c)v²)`。

于是 `b_p≥E+M`，并且

`|(b_q−b_p)(v)|≤η||v||₄²≤η b_p(v)`，

从而 `(1−η)b_p≤b_q≤(1+η)b_p`。若第k阶源谱证书给出 `[L,U]`，则新谱位于

`[(1−η)(L+c)−c, (1+η)(U+c)−c]`。

此推导只用已知嵌入和同一函数空间上的 min–max；允许一些跳跃势和无界但 L² 的势。这里 η 是**概率面积** L² 范数，若输入是标准面积 L² 误差，需要除以 `sqrt(4π)`。`η<1` 是这条简单搬运规则的条件，不能删除。

对 GN 编译势也有直接意义：若固定 α 且 q=−αu²、p=−αv²，则

`||q−p||₂ ≤ |α|(2B₄+δ₄)δ₄`。

若 α 本身由不精确的 E、N 构造，还必须加入 α 的区间误差。一般 H¹ 试探不保证 u∈L∞，所以“编译成势”以后不能继续无条件套用要求点态有界势的旧尾部公式。

## 4. 去掉光滑性后，残差应改用弱形式

GN 商在非零零均值 H¹ 函数上仍有意义。对均值零方向 v，定义弱残差

`R_u(v)=∫∇u·∇v+(E/M)∫uv−(2E/N)∫u³v`。

H¹→L⁴ 足以保证最后一项有界，所以 R_u 属于 H⁻¹；但是 `−Δu` 未必是 L² 函数。现有 `v=−r` 的强残差更新不能直接移植到任意 H¹ 输入。

可以采用 H¹ 的 Riesz 方向 w：在零均值空间解

`∫(∇w·∇v+w v)=−R_u(v)` 对所有 v。

这样 `J'(u)[w]=(2J/E)||w||_{H¹}²≥0`；实际近似解仍需弱残差误差界，有限步长仍须重新认证。这里 J=πK。这个方案能接纳连续分片函数、折点和局部基，不要求全局二阶可导。

## 5. 分片函数和局部基怎样保住全局证明

建议优先采用**真实球面上的连续、相容局部基**，并保存以下数学数据：

1. **覆盖与相容性。** 有限球面分片完整覆盖 S²，片间无漏面；相邻边的迹一致。连续分片 H¹ 函数可以有梯度跳跃，但函数值跳跃一般不属于 H¹。
2. **几何与积分。** 每片参数图的 Jacobian、逆度量及积分区间有认证；若使用平面三角网格逼近球面，要把 lift 的面积、梯度畸变算入几何误差。真球面的可验证图可以避免“换了几何却未记账”。
3. **局部到全局。** 对同一个连续误差 e，若各不重叠片有 `∫_K(e²+|∇e|²)≤ε_K²`，则全局 H¹ 误差平方≤Σ ε_K²。若用重叠分区，必须记录重叠数、分区权函数及其梯度，不能直接把局部误差相加。
4. **认证误差来源。** 已知目标函数时，用有余项的局部逼近/区间积分；目标由 PDE 隐式定义时，用后验残差估计或通量重构。仅有网格值和相邻两次计算差值，不能证明误差上界。

曲面有限元的文献明确区分 PDE 误差与几何误差；Bonito–Demlow 的 Theorem 3.1 给出相应可靠性结构。不过该论文使用隐含常数、形状规则性及 C² 曲面的假设，不能直接把一个 `≤Cη` 中未量化的 C 当成软件证书。真正认证还需显式化常数和几何前提。[Bonito–Demlow，§2.4 与 Theorem 3.1](https://arxiv.org/pdf/1802.01625)

仅做一个具体分片试探的 GN 下界时，可以直接认证该函数的三个矩，不必先解 PDE。若要证明它近似另一指定函数，或对全 H¹ 优化作上界，则必须额外提供 H¹ 近似误差或完整尾部论证。

## 6. 最小反例与建议压力题

| 测试 | 应检验的关键条件 |
|---|---|
| `u=sign(x₃)` | 两个半球内部梯度均为0，但跨赤道跳跃，u不属于H¹；必须拒绝把分片梯度积分0当作真实能量。 |
| `u=|x₃|−1/2` | 合法 H¹ 非光滑试探：M=1/12、E=2/3、N=1/80、πK=9/160。强 Laplace 含界面分布，应该走弱残差，不能当作L²强残差。 |
| `u_n=sin(n x₃)/n` | 函数一致趋于0且L²误差趋于0，但能量趋于1/3；只控制函数值或质量不足以控制能量。 |
| 局部坐标中的 `e_ε=ε^{-1/2}φ(x/ε)`，φ为非零光滑紧支撑函数 | 二维下 M约为ε、N约为常数、E约为1/ε；只给L²误差不能控制四次矩。中心化不改变这一结论。 |
| 两个不共轴集中帽 `((1+x₃)/2)^64 + ((1+x₁)/2)^257 − mean` | 首个去轴对称压力题。要保留两个峰的全部二次及四次交叉积分，不能把每个单峰的结果相加。 |
| `u=(x₁−1/2)_+^{3/4}+(x₃−1/3)_+^{3/4}−mean` | 非多项式、非轴对称、带界面但仍H¹的压力题；局部网格与弱残差有用。把3/4改成1/2时，跨界面梯度平方出现对数发散，必须识别为非H¹。 |
| 原集中族n趋于无穷，或双峰尺度独立趋于0 | 不能把某个有限维平面的上界、固定截止次数，升级为全H¹的上界；归一化后M和N可同时趋于0，GN比值仍趋于正数。 |

最后一项需要把集中/逸出有限表示的机制单独分析。Lions 的集中紧性提供方法论来源，但不是已经替本项目证明好的全局尾部定理；具体球面 GN 的尺度、约束与局部极限仍需另行推导。[Lions，1984，局部紧情形 Part 1](https://www.numdam.org/item/AIHPC_1984__1_2_109_0/)

## 建议顺序

先研究“完整非轴对称球谐/xyz 试探 + 有理矩核”，随后研究“相容分片 H¹ 试探 + 弱残差 + 显式 H¹ 误差”，最后才处理“所有尺度集中族的统一上界”。抽象接口应输出真实函数的均值、质量、能量、四次矩及其可信区间，而不强制某一种表达式。任意黑箱采样函数若没有可计算的 H¹ 误差模数或正则性证书，仍不能被声明为已支持的一般 H¹ 输入。
