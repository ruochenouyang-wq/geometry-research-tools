# 阶跃势的 C1 分段候选与完整残差认证

本实现针对公开开发题 H14：单位球面上
`q(z)=−(3/5)·1_{z>0}`，求平均零空间最低谱值。默认 20 项分段候选的认证宽度为约 `1.28695e−13`，低于原目标 `1e−8`，也低于开发目标 `1e−10`。这是一项有限工具任务的改进；不是开放猜想的解决，也不是新的独立隐藏评测成绩。程序和测试没有生成或读取 holdout。

## 数学对象与算子域

只接受原始 `axis_profile / step` 输入，轴为 0、1、2 之一。以该轴坐标记作 z，势为 `q=b+a·1_{z>0}`。原函数在单个赤道上的取值不影响谱问题。候选采用

`u=(1−z²)^(m/2) r(z) cos(mφ)`，其中 `m=1` 用于平均零问题，`m=0` 用于全空间问题。

默认径向基是全局 `1,z` 以及 `z^k·1_{z<0}`、`z^k·1_{z>0}`，`k=2,...,d`。共 `2d` 项；默认 `d=10`。两侧高次项在赤道的值和一阶导均为零，所以任何线性组合的 r、r′ 都连续。程序禁止单侧零次、一次项，也禁止重复项与显式线性依赖。

候选在两极是光滑球面函数，在赤道是 C1 分段多项式。二阶弱导数没有界面 Dirac 项，且势有界，所以候选属于原自伴算子的强定义域。对 m=1，角向积分自动为零；程序从未把一个不满足均值约束的 m=0 候选用于平均零问题。

完整原算子在该表示下为

`D_m r=−(1−z²)r″+2(m+1)zr′+[m(m+1)+q]r`。

每侧势为常数 c，因此

`D_m z^k=[(k+m)(k+m+1)+c]z^k−k(k−1)z^(k−2)`。

径向质量权重为 `(1−z²)^m`。m=0、1 时全部积分均是有理数；角向因子和球面归一化常数在 Rayleigh 商及归一化残差中同时抵消。

## 完整残差和下界

生成端用精确矩阵 `M=<φ_i,φ_j>`、`H=<φ_i,Dφ_j>`、`R=<Dφ_i,Dφ_j>` 计算

`ρ=(vᵀHv)/(vᵀMv)`，`σ²=(vᵀRv)/(vᵀMv)−ρ²`。

R 包含每侧完整强算子作用。它不是 `HM⁻¹H`，也不是投影后的残差。独立验证端先合并候选两侧多项式，再直接积分 `r²`、`rD_mr`、`(D_mr)²`，不读取或重建生成端的 Gram 矩阵。因此，搜索的舍入和矩阵运算不构成接受假设。

默认第二谱值界来自逐点下界 `q≥q_min`：单个实 m=1 径向分量的第二拉普拉斯谱值是 6；全空间 m=0 径向分量的是 2。故默认 β 分别为 `6+q_min`、`2+q_min`。这里统计的是整个径向分量，绝未把 cos/sin 两份简并谱的全局第二特征值当作 Temple 间隙。

也可以传入 `spectral_gap.certified_gap(...)`，其独立验证器必须确认完全相同的原函数、m、均值设置和第二序号。接受要求严格 `ρ<β`；等号或反向一律拒绝。

Temple 给出当前完整径向分量的下界

`L_T=ρ−σ²/(β−ρ)`。

程序将它与旧完整径向下界取最大，再与其他所有已计算 m 分量下界及遗漏角向尾下界取最小，得到全球下界；上界取原 source 上界与候选 Rayleigh 商的较小值。最后还交叉整个空间的解析界 `q_min` 或均值零空间的 `2+q_min`。所有 source 都由冻结 `direct_moments.verify_full` 重放，并绑定原函数和空间。旧 source 即使未达到自身容差，也仍然提供有效区间，可以用于拼合。

因此，全空间结果同样覆盖全部 m；本实现不依赖“只求 m=0 就是全球”的额外简化。平均零结果也没有遗漏 m=0。对常势，若旧 source 提前在 m=0 关闭角向尾，生成端补上 m=1 证据，解析全球下界使常势结果精确。

## 接口

- `solve(function, source=None, gap=None, degree=10, tolerance='1/100000000', mean_zero=True, precision_bits=96, iterations=12)`：返回运行对象，证书在 `result['certificate']`；时间字段包含最终独立复核。
- `solve(task)`：便利入口，读取 `task.function`、`task.mean_zero`、`task.tolerance`，若提供 kind 则必须为 `spectrum`。
- `basis(degree)`、`trial_matrices(function, terms=None, m=1, degree=6)`：返回不可变精确矩阵；`terms` 是 `[side,power]`，side 为 −1、0、1。
- `propose_trial(function, degree=6, m=1, precision_bits=96, iterations=12)`：有理移位逆迭代，只产生建议。
- `trial_statistics(function, terms, coefficients, m=1)`、`trial_certificate(function, terms, coefficients, source, gap=None, tolerance=..., mean_zero=True)`：认证给定有理候选。
- `verify(cert, expected_function=None, expected_source=None, expected_tolerance=None, expected_mean_zero=None)`：独立直接积分，重放原 source 和 gap，逐字段重建整个证书。

证书格式是 `step_c1_strong_residual_temple_v1`；运行格式是 `step_c1_search_v1`。`verify=True` 只表示区间和状态诚实；目标验收还需 `status=='target_met'` 且宽度不超过请求容差。有效但过宽的结果为 `certified_open`。本模块不将异常、无效间隙、缺少全球 source 或不支持的函数伪装成成功。

次数上限 12、项数上限 24、舍入位数 32–192、逆迭代步数 0–32。任意强度阶跃或任意小容差都不保证默认配置达标；其他分量或间隙可能仍是瓶颈。程序未内置强制时间中断，外部控制器应实施总时间预算。
