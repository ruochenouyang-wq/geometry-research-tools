# 工具合同与验收基准

这些合同把论文中的障碍转成可开发模块。T1 已实现；其余是可评审的开发规格，下面的拟验收案例尚未实现或运行。拒绝证书只表示当前证据不足，不能自动判定数学命题为假。

## T1：严格谱区间

**输入：** 固定的球面轴对称模型、有理势函数 q、谱编号 k、模态数 N。**输出：** 有理上下界、解析尾部常数、矩阵惯性证据及结论作用域。

**接受条件：** `lower < beta`；尾部修正矩阵的负惯性小于 k；上端点对应的有限矩阵至少有 k 个非正方向。所有矩阵和尾部常数必须从原始输入重算。推导见 [PROOF.md](PROOF.md)。

**已运行基准：** 已知球面谱、常势平移、独立积分装配核对、错误谱编号与作用域、遗漏尾部造成的假下界、强耦合搜索起点。19 项测试通过，五个实验结果见 [EXPERIMENTS.md](EXPERIMENTS.md)。

**失败输出：** 输入超出模型；证书未通过；或区间虽有效但过宽。最后一种情况应增加模态数或改进尾部估计，不得扩大结论措辞。

## T2：证明条件与依赖记录器

**输入：** 经人工确认的结构化定理条目和证明依赖图。条目至少含维数、基域、范畴、嵌入/浸入、边界、紧性、量词、常数依赖及结论类型。**输出：** 可匹配的定理、未满足或未知的前提、来源版本和未完成证明义务。

**接受条件：** 仅当已支持的类型规则能验证前提蕴含时才允许连接两个步骤；否则返回“未知”。自然语言提取与数学有效性检查分开，GPT 提取的字段需要确认。记录器本身不会证明引用的定理。

**拟验收：** 在条件完全相同的条目间允许引用；阻止“同胚 → 微分同胚”“三维 → 四维”“等参极小超曲面 → 任意极小超曲面”“试探函数上界 → 谱下界”。删除一个必要条件后，系统应定位缺失条件，而不是笼统评价文字可信度。

**指标：** 错误升级的检出率、合法依赖的通过率、返回未知的比例。基准由明确的类型规则生成，再由数学审阅确认；不能用模型自评分替代验收。

## T3：单调量候选与导数证书

**输入：** 已支持的几何流、精确张量恒等式、积分约定、边界条件及有限候选函数族。**输出：** 候选量的缩放次数、沿流导数、分部积分记录及非负/非正分解；无法处理的项单独列出。

**接受条件：** 所有变换可由规则库重放；边界项确实消失或有已证明的符号；使用的曲率条件在所声明时间区间成立。导数符号只在光滑流存在期间给出相应单调结论，跨奇点延拓须另给证明。

**拟验收：** 闭平面曲线的曲率流中重建 `dL/dt = -∫κ² ds`；对光滑简单闭曲线重建面积变化公式，并明确其定向约定。改成带端点曲线时必须保留边界项。输入若仅包含采样轨迹而无符号证明，应输出“观察”而非“定理”。

**指标：** 在固定候选族中恢复已知恒等式所需搜索量、未消去项数量、对边界和缩放错误的检出率。进一步进入 Ricci 流时需要专门张量库，不能把平面曲线基准通过当作支持 Ricci 流。

## T4：堆积对偶证书

**输入：** 维数、最小点间距 r、满足所用界定理的函数族、明确的 Fourier 变换归一化，以及精确系数或有验证包络的系数。**输出：** 函数符号证书、适用的密度上界、与某个构型下界之间的差值。

**接受条件：** 例如在经典两点线性规划框架中，检查函数的正则性与衰减、`f(x)≤0` 对所有 `|x|≥r`、`f̂(y)≥0` 对所有 y、`f̂(0)>0`；采用与这些条件一致的密度界。有限采样不满足“所有”的要求，尾部必须单独认证。转到三点界需更换证书合同，不能沿用两点条件。

**拟验收：** 先验证可解析处理的多项式乘 Gaussian 函数；删除无界区域的符号证据必须拒绝；Fourier 归一化改变后，旧证书必须失效。八维、二十四维已知辅助函数作为后续较大复现基准，必须锁定论文和辅助文件版本。

**版本说明：** [二十四维原论文](https://arxiv.org/abs/1603.06518)截至本次核查为 v4，修订于 2026-09-06；页面说明辅助文件有细节修正。本轮未执行这些辅助计算，引用的是已发表的定理及方法框架。

**指标：** 可认证的上界质量、尾部验证成本、虚假符号证书检出率。构型优化得分与证书分开报告。

## T5a：保持约束的凸体变形

**输入：** 有理多面体顶点、面关联、对称性、指定运动方向和变形参数。**输出：** 满足线性化条件的速度空间、纯仿射子空间，以及经过精确检查的非零参数区间。

**接受条件：** 除瞬时条件外，还需验证整个输出区间内的凸性、面共面性、对称性、非退化性及极体所需的原点内点条件。线性化可行不能自动升级为有限变形可行。去除纯仿射方向时须说明其对目标体积积的作用。

**拟验收：** 从有理中心对称多边形开始，恢复平移或线性变换的已知方向，保留合法的非仿射方向；当一个行列式变号、面结构改变或原点退出内部时，应在事件点截断参数区间。再扩展到三维，重现已知变形引理的局部计算，暂不要求复现整个 Mahler 证明。

**指标：** 合法非仿射方向的发现率、可认证参数区间长度、结构改变事件的定位误差。目标函数下降只是工具的用途之一，不能替代约束验证。

## T5b：受限代数循环构造

**输入：** 一个具体射影簇、可计算系数域、精确表示的目标类、次数/Hilbert 多项式约束及搜索预算。**输出：** 候选循环理想、可复核的代数计算、目标类表示证据，或尚未发现候选的搜索记录。

**接受条件：** 理想确实定义所需循环，支持集位于原簇中，余维正确；类的比较使用已证明完备的表示或配对方法。只匹配有限个交数，在没有完备性定理时不足以认定两个一般上同调类相同。周期近似必须标成数值证据。

**拟验收：** 在 `P²` 中，以超平面类 H 为基准，构造直线与光滑二次曲线并验证类分别为 H 和 2H；超过次数预算时返回“未找到”，不得判定目标类不可代数化。将定义域从有理类改为整数类时，原有论证不得直接沿用。

**指标：** 在明确受限模型中的构造成功率、精确计算成本、错误等价和错误否定结论的检出率。此模块是具体簇的实验工具，不是一般 Hodge 猜想的判定程序。
