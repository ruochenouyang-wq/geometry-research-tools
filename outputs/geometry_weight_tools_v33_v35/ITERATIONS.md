# 新增三个版本

| 版本 | 实质改动 | 验证方式 |
| --- | --- | --- |
| V33 | 对连续矩阵包络问题构造全局对偶下界，与可行上界形成误差证书 | 精确检查每个对偶矩阵及总和余量的半正定性；覆盖原始连续区间的上界；伪造证书拒绝测试 |
| V34 | 自动搜索矩阵权重，添加最差位置约束，修复有理对偶 | 一到四方向、非对角代价、耦合方向实验；预算不足与候选失败时保留开放误差 |
| V35 | 根据原题二次代价选择权重，并解释固定构造的失效 | 与 V32 在同目标下对照；核验原始全空间结论；不将构造失败混同于原题否证 |

本轮为 54 项新增测试加原有 168 项回归测试。逐版论证见 `PROOF_V33_V35.md`；所有速度、系数和误差数字以 `results/benchmark.json` 为准。完成三个版本不意味着所有输入都能证明，也不表示进行了模型能力对照。
