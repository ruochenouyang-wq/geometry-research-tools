# 几何研究工具包

本工具包以“从难题获得工具”为目标。先读 [几何问题与工具对照](GEOMETRY_TOOLKIT.md)，其中区分了开放问题、已解决案例、未确认的证明宣称、现有软件和待开发方向。

各工具的输入、输出、正确性条件与验收基准见 [工具合同](TOOL_CONTRACTS.md)。

目前真正可运行的工具是**带无限维尾部估计的谱上下界认证器**。它处理单位二球面上算子 `-Δ+q(cos θ)` 的轴对称子空间，q 为有理系数多项式。所有关键计算使用精确分数；无需 API 密钥或额外 Python 包。

## 运行

需要 Python 3.9+，在本文件所在目录执行：

```sh
python3 spectral_certifier.py demo
python3 -m unittest -v
```

演示生成五个证书，保存在 `results/`。本次 19 项测试全部通过。

计算自己的势函数，例如 `q(t)=1-2t+3t²`：

```sh
python3 spectral_certifier.py bound --q "1,-2,3" --k 1 --modes 10 \
  --out results/my_bound.json
python3 spectral_certifier.py verify results/my_bound.json
```

负数开头的参数使用等号写法，如 `--q="-2,1"`。系数按常数项、一次项、二次项递增排列，可用 `"1/3,-2,3/5"`，不能用浮点近似冒充精确输入。

`--k` 从 1 开始，包含最低模态；`q=0,k=2` 才对应此模型的第一非零特征值。`--modes` 控制有限空间维数，最多 32；`--bits` 控制二分轮数，范围 8–64。程序给出的区间始终以实际证书为准，不保证达到某个用户期望宽度。

## 可以得到什么

对于 `q(t)=t` 的最低特征值，已得到包含整个无限维尾部的认证区间：

```text
[-0.157663483142, -0.157663483114]
```

两模态近似与八模态认证的区别见 [实验报告](EXPERIMENTS.md)。数学依据见 [证明与限制](PROOF.md)。

这个工具不求解 Yau 猜想，也不处理任意曲面的 Laplace–Beltrami 算子。它取得的可复用能力是：**把有限计算的结论与遗漏方向的解析控制连接起来，并拒绝不合法的推广。**

## 给 GPT 使用

[研究协议](RESEARCH_PROTOCOL.md)可直接交给 GPT。GPT 可建议势函数、谱编号、试探阶数和待验证命题，调用本工具生成证书，再请求复核。工具不依赖 GPT 的自评，也不会执行模型生成的代码。

其他几何工具目前是设计与软件选型，未伪装成已实现功能。此前的动力系统原型保留在相邻的 `math_research/` 文件夹；本包完全独立运行。
