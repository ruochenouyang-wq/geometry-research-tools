# 原创性检查报告

检查日期：2026-09-18。范围：当前精度研究及项目此前主要算法。检查方式：阅读实现和证明记录，将核心步骤与作者论文、作者书稿及官方技术文档对照；两条独立文献核对分别覆盖分数幂谱法和其余核心算法。

**结论：当前证据支持“基于已有数学方法的专用可认证计算工具”，不支持“发明了全新的通用数学研究算法”。具体实现、问题推导和认证流程有可展示的贡献；学术原创性仍未证明。** 这不是对项目价值的否定，也不是代码抄袭的结论。

## 项目实际做出了什么

现有实现把已有方法用于单位球面上的具体谱问题，并保存可重新计算核验的有理证据。较有价值的部分包括：原函数 q 和 q² 的精确积分；零均值空间及全部方位角分量的覆盖；将完整算子残差与单一实分量的间隙界结合；对不达标案例保留有效区间与 open 状态；以紧凑接口调用较大的数学证书。

最新固定算例是 `q(z)=-|z|^(-1/4)`。实现从奇异项平衡得到首个非光滑幂 7/4，并构造分数幂试探空间。10 项试探的证书宽度约为 `1.0084e-10`；16 项约为 `1.1456e-18`。这些是 [已保存计算结果](../geometry_precision_followup/ENRICHED_RESULTS.json)，说明这一具体适配及认证流程有效。

**精度结果不能单独证明原创性。** 与项目自身普通多项式流程相比的约 1.35 亿倍宽度改善，限定于当前 10 项基、同一来源证书、同一候选求解设置和 Temple 认证流程。它不是对成熟 Müntz、广义 Jacobi、hp 或其他验证谱法的最强结果比较，也不是运行速度、token 或模型能力改善的倍数。

目前尚未找到与“球面赤道奇异势 + 当前分数幂集合 + 完整强残差 + 全分量有理证书”逐项完全相同的公开成果。这个检索结果只保留了进一步研究的空间，不能证明组合首创。特定方程中算出新的系数或更多小数位，也不会自动形成新算法。

## 可以公开与尚不能公开的主张

可以表述为：

> 本项目实现面向球面谱与相关不等式的可复核计算原型，结合精确积分、奇点适配谱逼近和经典谱误差界，提供完整有理证书及供模型调用的接口。数学基础引用已有文献，当前贡献主要是具体实现、认证流程与可复现实例。

现阶段没有依据宣称：核心数学原理首创；通用求解开放问题；普遍达到全局最优；领先现有最强数值方法；真实推理 token 降低到某比例；已实现“5.6 半小时超过 Astra 八小时”。版本数量和内部案例上的改善均不能替代这些评测。

## 若要继续追求原创性

最有判别力的下一步，是把固定势的手选分数幂推广成**有明确适用条件的自动基选择方法**。例如在赤道幂奇异势的参数族中，从算子自动生成局部幂或对数项，检查共振、定义域及可积性，给出可证明的残差收敛与停止条件。这个方向也存在 Frobenius、Müntz 等已有理论，仍需要对照，不能预先命名为原创算法。

然后用未参与开发的同类问题，与成熟适配谱空间及验证谱法比较。应固定目标精度与认证标准，记录自由度、矩阵成本、有理数位长、时间和证书体积；避免只比较原本不适合奇点的普通多项式基。若要证明对模型的帮助，还需单独做真实模型的同题盲测。

方法有先例不等于复制代码；代码由本项目编写也不等于方法首创。本次没有进行全网逐行代码相似度审计，因此不能给出“完全原创代码”或“完全没有抄袭”的鉴定。内部扫描覆盖 319 个 Python 文件、204 种不同文件内容、38 组重复文件；这些重复主要用于梳理历史版本复用，不能换算为原创率。详见 [内部复用扫描](INTERNAL_REUSE_SCAN.json)。

可选 tokenizer 的已有来源说明和许可记录见 [THIRD_PARTY_NOTICES.md](../geometry_v36_v90/THIRD_PARTY_NOTICES.md)。项目尚无 Git 历史可用于创作时间线审查。公开仓库前还应确定项目自身许可证并保留第三方通知；本次没有代选许可证或执行发布。

检索使用奇点适配谱基、Müntz、分数幂势、Temple 残差、Feshbach–Schur、低正则势、相对二次型、半无限 SDP、精确有理重构等关键词，并查询了赤道奇异势与本题指数的组合。只读摘要的来源已在分报告标明；没有对全部付费文献、所有软件仓库或数学优先权作穷尽判断。本报告应作为方法来源核对与后续研究依据，不是原创性保证书。
