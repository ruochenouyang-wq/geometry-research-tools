# 一般有理负幂的分段多项式 L² 证书

general_approx.py 修复了旧 H11–H13 因指数不等于 −1/4 而被拒绝的支持缺口。它直接逼近原函数，输出有限分段多项式及全域概率 L² 误差证书；没有把原奇异函数放入输出基中，也不作谱结论。

## 数学范围与精确积分

源函数为

\[
f(t)=A|t|^\alpha+b,\qquad \alpha=-m/d,\quad 0<m<d/2,
\]

其中 \(m,d\) 互素，参数均为有理数。\(t\) 是单位球面的指定坐标。球面概率测度下，对偶误差有

\[
\|e\|_{L^2(S^2,d\sigma/(4\pi))}^2=\int_0^1 |e(t)|^2\,dt.
\]

区间端点采用有理数的 \(d\) 次幂。所需矩均为精确有理数：

\[
\int_{L^d}^{R^d}t^{k+\ell\alpha}\,dt
=\frac{d}{d(k+1)-\ell m}
\left(R^{d(k+1)-\ell m}-L^{d(k+1)-\ell m}\right),
\quad \ell=0,1,2.
\]

取根比 \(0<r<1\)，边界为 \(t_j=r^{dj}\)。第 \(j\) 个环片做替换 \(t=r^{dj}x\)，源函数的奇异项按 \(r^{-mj}\) 缩放，平方误差按 \(r^{(d-2m)j}\) 缩放。根比默认取 \(r=(2d-1)/(2d)\)，随分母调整相对环片宽度。

核心 \([0,t_L]\) 使用最佳常数，且精确计入其误差：

\[
p_{\rm core}=b+\frac{A}{1+\alpha}r^{-mL},
\qquad
E_{\rm core}^2
=A^2\left(\frac1{1+2\alpha}-\frac1{(1+\alpha)^2}\right)
r^{(d-2m)L}.
\]

积分、平方源项、核心、缩放和总误差全部使用真实指数，没有沿用固定 −1/4 的系数。

## 输出仍是分段多项式

在标准环片上生成普通多项式 \(P_n(s)\)。第 \(j\) 片的实际输出为

\[
b+A r^{-mj}P_{n_j}\!\left(
\frac{t/r^{dj}-r^d}{1-r^d}\right).
\]

这是 \(t\) 的有限次普通多项式。证书保存有限个有理系数模板、各模板覆盖的整数层号，以及确定的有理尺度规则，避免重复展开巨大系数。没有隐藏无限级数或源函数求值。evaluate 可直接计算此模型。内部环片接缝取外侧片，核心接缝与零点归核心，声明与实现一致。

外层通常需要较高次数，内层使用较低次数。块列表必须精确覆盖层号 0 至 \(L-1\)，核心覆盖剩余近零区。各片误差以有限几何级数精确合成，近零区域没有被丢弃。

## 规划与独立验证

规划器先给核心分配目标平方的四分之一，再给环片分配平方误差预算，并按层权重降低内层次数。可选 ShapeCache 的键包含完整指数、根比和次数。幅度、偏移和坐标轴通过明确的缩放与证书绑定处理。

verify 不调用规划器、投影生成器或规划缓存。它读取实际普通多项式系数，重算多项式平方积分和原函数交叉积分，检查模板误差、尺度、核心、覆盖、总误差与向外平方根。它允许其他有效多项式或非最优核心常数，只要真实误差得到证明；不要求结果等于搜索输出。

接受的数学量全部是精确有理数。较长分数采用分块十进制编解码，不改变 Python 全局整数安全设置。

## 开发验证与保留的失败

没有读取新 holdout 或私有种子。旧三题仅使用已公开诊断中的参数：

| 公开题 | 指数与幅度 | 原 L² 目标 | 认证误差上界，约 | 层数 / 最高次数 |
|---|---|---:|---:|---:|
| H11 | \(\alpha=-2/9,A=-1/3\) | \(10^{-6}\) | \(5.60826\times10^{-7}\) | 88 / 5 |
| H12 | \(\alpha=-2/11,A=-3/5\) | \(10^{-8}\) | \(5.66127\times10^{-9}\) | 107 / 8 |
| H13 | \(\alpha=-2/9,A=-3/5\) | \(10^{-10}\) | \(5.86375\times10^{-11}\) | 156 / 10 |

三题初测的计算、内部独立验证及一次额外外部验证均在 0.01 秒内。这是本地开发观察，不是独立评测成绩；统一性能与通过率由根任务在冻结后顺序测量。

四个额外公开开发参数也全部达到目标：

- \(\alpha=-1/3,A=-2/5,b=7/3,\mathrm{axis}=1\)，目标 \(10^{-8}\)；
- \(\alpha=-3/8,A=3/7,b=-1,\mathrm{axis}=0\)，目标 \(10^{-10}\)；
- \(\alpha=-5/13,A=-1/2,b=0\)，目标 \(10^{-8}\)；
- \(\alpha=-1/10,A=1,b=0\)，目标 \(10^{-6}\)。

近可积边界的压力题 \(\alpha=-49/100,A=-1/10,b=0\)、目标 \(10^{-6}\) 保留了失败：

- 默认 2048 层预算：有效证书，误差约 \(2.36494\times10^{-5}\)，状态 certified_open。
- max_levels=8192：实际使用 2818 层，误差约 \(5.98857\times10^{-7}\)，状态 target_met；含额外外部验证的初测约 0.26 秒。

这些参数已参与开发，不能再当作独立留出题。预算不足、未达精度的有效证书仍应计为任务失败。

19 项本地测试覆盖原三题、新参数、独立逐片展开积分、核心校准、全域覆盖、非均匀次数、缩放、原函数与目标绑定、缓存污染、长分数、接缝及篡改。独立代理的检查另行报告，不与本地测试混报。

## 接口

~~~python
import general_approx as g

function = {
    "kind": "axis_profile", "profile": "abs_power", "axis": 2,
    "exponent": "-2/9", "amplitude": "-3/5", "offset": "0",
}
certificate = g.solve(function, "1/10000000000")
assert g.verify(certificate, function, "1/10000000000")
assert g.rational(certificate["error_upper"]) <= g.rational("1/10000000000")
~~~

solve 直接返回 JSON 可序列化证书，含 format/function/tolerance/error_squared/error_upper/status。默认 max_degree=24、max_levels=2048；还可指定 root_ratio、sqrt_bits、shape_cache。

**verify 返回 True 只表示误差证书有效，不一定达标。** 还须检查 error_upper≤tolerance，或检查经过验证的 status 是否为 target_met。certified_open 表示有效但未达标。

当前实现预算为指数分母不超过 4096、最高次数 32、最多 16384 层、目标在 \(10^{-60}\) 至 1 之间。接口拒绝浮点数学输入、未知字段及不可积指数。这些资源限制不是不可逼近定理；当前证书没有形式化证明助手背书。
