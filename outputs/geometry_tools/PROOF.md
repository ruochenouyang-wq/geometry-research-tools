# 谱工具的数学依据与适用范围

工具给出的是某个无限维算子的特征值区间，不仅是截断矩阵的区间。证明只适用于本文件定义的模型。

## 1. 固定问题与定义域

令 `t=cos θ`。单位二球面上轴对称函数可视为 `L²([-1,1],dt)` 中的函数；面积积分额外的常数 `2π` 在 Rayleigh 商中消去。研究

\[
H_q u=-\frac{d}{dt}\big((1-t^2)u'\big)+q(t)u.
\]

采用由光滑球面轴对称函数的能量型闭包确定的自伴算子；等价地，以 Legendre 谱定义基准算子，再加入有界实乘法算子 q。不是在区间端点人为施加 Dirichlet 条件。

Legendre 多项式满足

\[
\langle P_i,P_j\rangle=\frac{2}{2i+1}\delta_{ij},\qquad
H_0P_i=i(i+1)P_i.
\]

递推式为

\[
tP_j=\frac{j+1}{2j+1}P_{j+1}+\frac{j}{2j+1}P_{j-1}.
\]

这些标准关系提供精确有理矩阵装配，不需要数值积分。[NIST 递推式](https://dlmf.nist.gov/18.9)、[正交多项式定义](https://dlmf.nist.gov/18.3)

q 是有界实多项式，所以该自伴算子有离散谱。编号 `k=1,2,...` 包含最低模态；`q=0` 时谱为 `0,2,6,12,...`。因此只有 `q=0,k=2` 才是在这个基准中取第一非零特征值。改变势函数后不能自动排除第一个特征值。

## 2. 有限部分与整个尾部

设有限空间 `V_N=span(P_0,...,P_(N-1))`。其质量矩阵 M 为对角矩阵，`M_ii=2/(2i+1)`；能量矩阵 A 逐项精确积分得到。

写 `q(t)=Σ q_j t^j`，取保守下界

\[
q_{\min}=q_0-\sum_{j\ge1}|q_j|.
\]

所有尾部函数均与前 N 个 Legendre 模态正交，因此尾部能量满足

\[
T\ge\beta M_T,\qquad \beta=N(N+1)+q_{\min}.
\]

这个不等式涵盖**全部**未计算的模态。q 的次数为 d 时，有限空间与尾部仅能通过 `P_N,...,P_(N+d-1)` 耦合，因为乘法矩阵的带宽为 d。设这个精确耦合矩阵为 C，则

\[
G=C M_T^{-1}C^T
\]

可用有限个有理数精确计算。这里 M_T 只需在 C 有非零列的位置取相应对角元；并非将剩余尾部设为零。

## 3. 下界的证书

对候选下界 `ℓ<β` 定义

\[
S_\ell=A-\ell M-\frac{G}{\beta-\ell}.
\]

将函数写成有限部分 u 与尾部 v。使用尾部估计并配方，`H_q-ℓ` 的二次型下界为

\[
u^TS_\ell u+(\beta-\ell)
\left\|v+\frac{M_T^{-1}C^Tu}{\beta-\ell}\right\|_{M_T}^2.
\]

因此 `H_q-ℓ` 的负方向数量不超过 `S_ℓ` 的负特征值数量。如果后者小于 k，便得到 `λ_k(H_q)≥ℓ`。这是二次型比较与 min–max 原理的应用。有限部分与尾部的配方变换可逆，且耦合只涉及有限多个模态。

## 4. 上界的证书

如果 `A-U M` 至少有 k 个非正特征值，就存在 k 维试探空间，使其所有非零向量的 Rayleigh 商不超过 U。由 min–max 原理得 `λ_k(H_q)≤U`。

注意方向：有限空间直接给上界；给下界时必须加上第 3 节的尾部证明。二者不能互换。

## 5. 精确检查与搜索

代码以有理数运算做对称矩阵惯性分解，允许 1×1 和 2×2 主元，并单独处理零块。2×2 块 `[[0,b],[b,0]]`（b≠0）贡献一个正方向和一个负方向。没有通过浮点特征值的正负判断接受证书。

上下界通过二分搜索生成。开始下界二分前先检查初始端点；如果耦合很强，就向下扩大搜索区间直到 Schur 条件成立。即使某个数由其他论证已知是算子下界，也不能假定它满足这个较保守的充分条件。搜索质量只影响区间宽度；复核器重新装配 A、M、G 和 β，从原始势函数重算所有条件。还会检查展示小数是有理区间的向外舍入，防止报告比真实证书更窄的区间。

这是标准 Schur 补、惯性和变分原则的一个透明实现；不是对 2026 年投影下界论文的完整复现，也不声称算法新颖。其他谱认证路线可参考[双边界方法比较](https://arxiv.org/abs/1602.08961)和[投影框架预印本](https://arxiv.org/abs/2607.04247)。

## 6. 信任范围

检查器依赖本文的解析尾部估计、自伴模型及 min–max 原理，以及 Python 有理数和本地代码的正确性。尚未导出为 Lean/Isabelle 内核证明。矩阵装配与复核共享代码，独立实现交叉验证仍有价值。

它不接受任意声称正确的尾部常数：β 必须按势函数和模态数重新计算。本版本也不会把轴对称子空间的结论改写为任意曲面、任意子空间或任意几何的结论。

q 的次数最多六，系数绝对值最多 1000、分母最多 `10^9`；模态数最多 32。增加精度未必能消除小 N 时保守尾部界产生的间隙，需要增加 N 或改进解析估计。
