# 第五轮：从参数点计算到全区间的最优值认证（V135–V144）

这一轮解决的弱点是：固定几个参数求得的精确特征值，仍不能证明整个参数区间上没有更优解。

研究对象为

\[
\min_{s\in[a,b]}F(s),\qquad F(s)=C(q_0+s d)+p(s),
\]

其中 \(C(q)\) 是单位球面上**全部零均值 \(H^1\) 函数**的投影算子第一特征值；\(q_0,d\) 为次数不超过 6 的轴对称有理系数多项式，\(p\) 为次数不超过 4 的有理系数惩罚，\([a,b]\) 为闭有理区间。轴对称的是势，函数空间包含非轴对称函数。

## 先做题目，确认缺口

一个可精确核对的反例是 \(q_s=0\)、\(p(s)=s^4-s^2\)、\(s\in[-1,1]\)。在 \(-1,0,1\) 三个点得到的目标值全部为 2，但真正的最小值为 \(7/4\)，在 \(\pm1/\sqrt2\) 取得。仅增加每个采样点的特征值小数位，仍然漏掉整整 \(1/4\)。采样结果被保存为启发式基线，未标记为全局证明。

真实球面算例是 \(q_s(t)=2t^2+s t\)、\(p(s)=s^2/10\)、\(s\in[-2,2]\)。只看三个参数点，无法排除它们之间的更小值。

## 数学依据与结果

V135 先提供一个便宜但有效的原题全局证书：对 \(q_0+s d\) 的每个系数以及 \(t^j\in[-1,1]^j\) 做有理区间运算，得到统一势下界 \(q_{\rm low}\)；对惩罚的每一项同样得到 \(p_{\rm low}\)。零均值球面的 Poincaré 常数为 2，故整个问题的下界为 \(2+q_{\rm low}+p_{\rm low}\)。上界在真实区间中点取零均值球谐 \(u=x_1\) 或 \(u=x_3\)，用精确球面矩计算 Rayleigh 商，选择较小者。这个步骤不需要矩阵、谱或多项式极值求解器。真实算例立刻得到 \([0,12/5]\) 的原题上下界。

`verify_cheap_objective` 从绑定的原题独立重算各个区间；试函数上界通过直接积分 \(q t^2\) 和 \(q(1-t^2)/2\) 复核，不调用生成器使用的闭式计算。测试通过禁止谱及极值求解器调用、禁止验证器调用生成器，确认这些独立性。

因为约束空间不随参数变化，Rayleigh 商在 \(s\) 上仿射，故其下确界 \(C(q_s)\) 为凹函数。对 \(s\in[a,b]\)，

\[
C(q_s)\ge\frac{b-s}{b-a}L_a+\frac{s-a}{b-a}L_b,
\]

其中 \(L_a,L_b\) 是端点的认证谱下界。加上 \(p(s)\) 后，使用原有有理多项式极值工具证明整段下界。另一路下界使用

\[
|C(q_s)-C(q_r)|\le \|d\|_\infty|s-r|
\le \left(\sum_j|d_j|\right)|s-r|.
\]

点谱上界加上精确的 \(p(r)\) 则给出全局最小值的上界。每个未排除区间都保留证据；仅在区间下界**严格大于**当前可行上界时排除。回放会拒绝缺区间、重叠区间、错误点证书、错误约束空间和错误检查点。

下列十进制端点向外舍入；JSON 中的有理数才是证书原值。

| 算例 | 全局最小值的认证区间 | 说明 |
|---|---|---|
| \(q=0,\ p=s^4-s^2\) | \([1.75,1.750000011409]\) | 捕获采样遗漏；保留正负两个最优点区域 |
| \(q=2t^2+s t,\ p=s^2/10\) | \([2.382589559880,2.382655406371]\) | 全部最优点均在 \([-1/8,1/8]\)；未声称唯一 |
| \(q=s,\ p=0\) | \([1,1]\) | 精确处理边界最优点 \(s=-1\) |
| \(q=s t,\ p=s^2/100\) | \([1.783332821529,1.783332822808]\) | 最好可行点在边界；最优点位置证书仍较宽 |
| \(q=s t,\ p=s^2/10\) | \([1.999956600690,2]\) | 全部最优点在 \([-1/16,1/16]\) |

真实球面算例整个 \([-2,2]\) 区间的初始 Lipschitz 下界约为 0.382655；凹性弦把它提升至 2.221159；最多 16 个叶区间的搜索进一步提升至 2.382589。最终上下界差约 \(6.585\times10^{-5}\)。

同时保存了只允许一个叶区间的失败预算：它诚实返回约 0.161496 的剩余间隙和整个 \([-2,2]\) 的活跃区间，状态为 `certified_bound_open_gap`。没有把预算结束写成最优性证明。

需要区分**最优值已经足够精确**与**全部最优点位置已经足够精确**。例如四次惩罚有两个相等的最优值，确定一个很好的可行值后，另一侧仍可保留较宽区间；证书完整保留了这一事实。

## 验收与使用

26 项测试通过，包含无谱求解器的粗界、独立积分回放、三点采样反例、非凸惩罚、边界最优、对称多个最优点、缺失/重叠覆盖、错误种子、错误阈值、缓存污染、JSON 回放与预算不足。7 个单独保存的全局搜索证书均通过回放，另有 V135 粗界证书、阶段证据中的重复证书及三个阈值结果。

这次机器运行全部例题约 3 秒，26 项测试约 1.1 秒；不是与其他求解器或模型的速度比较。

在本项目目录运行：

```sh
python3 -B global_parameter.py
python3 -B -m unittest test_global_parameter -v
```

继续求解时可将先前的完整证书交给 `resume(objective, checkpoint, max_leaves=32)`。当前最多 128 个叶区间、8 层检查点续算。证书需要本项目相邻的 V91–V94 和 V90 只读核心；不是独立安装包。

本轮仍只处理一个有界实参数及指定的多项式势族，未证明任意势的 GN 最佳常数，也未覆盖非紧参数域。数学基础是明确列出的变分原理、凹性及有界乘子扰动估计；证书是有理软件回放，不是形式化证明助手认证。
