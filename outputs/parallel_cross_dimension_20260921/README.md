# 三种研究路线：同题、跨维度的成本比较

本轮用冻结的基线与 A/B/C 解同一份原题，分别比较成功、精度、速度、处理器时间、内存和证书体积。这里的“维度”指评测因素；现有数学实现仍限于单位球面，不代表已经支持任意维数或一般曲面。

完整对照已完成，见 [比较报告](REPORT.md)。C在双方都达标的15道谱题上累计节省28.3%壁钟时间和28.5%CPU；B在两个16题参数流中含准备约快5.20倍、3.64倍，逐题完整冷重放后约快1.81倍、1.51倍（均相对基线）。所有批量查询通过；单题中A的精度不足和B的不支持范围如实保留。

## 本轮如何使用三种算法

- **A** 原生计算全部负谱。评测适配器在完整负谱证书有效且至少存在一个负谱值时，从各负谱分量的首个区间取最小下端与最小上端，得到同一原题的最低谱值区间。没有负谱、计数未确定或缺少逐值区间时，明确报告无法用这条路线回答；不会把最低谱值设为零，也不会回退基线。
- **B** 使用原生参数区间证明。单题也先准备一份预先指定的幅度区间，完整计入准备费用；批量时只准备一次。超出其函数族或空间的题记为不支持，不偷偷调用基线。
- **C** 直接使用上一轮冻结的算法，保留它已经实现的条件检查与明确回退，并记录实际路线。
- **基线** 直接使用同一份冻结旧算法。

适配器只改变接口，不改变原求解器。A 的来源证书即使没有达到“所有负谱之和”的精度，也可以包含有效的最低谱值区间；评测只按外部同题要求的最低谱宽度独立判定。A 同时计算其他负谱的额外工作仍计入成本。

因此，本轮比较的是用现有整条路线完成这个共同请求的成本。A 同时产生更多谱信息，B 同时证明一个连续参数区间；它们的额外成果不会给单点最低谱任务加分，也不能据单点耗时就判定这些扩展能力没有价值。

## 固定题单

[cases.json](cases.json) 包含 16 道最低谱问题和 2 道函数逼近控制题。所有方法收到相同函数、空间、容差及总期限。数学目标不同的组分别统计，不混成一个“正确率”。

| 题号 | 变化因素 | 固定内容或作用 |
|---|---|---|
| S01–S03 | 精度：10⁻⁴、10⁻⁶、10⁻⁸ | 同一个负幂势和全空间 |
| S04–S06 | 奇异指数：−1/6、−2/5、−13/27 | 幅度与目标精度不变，逐步接近适用边界 |
| S07–S08 | 幅度：−1/10、−3/2 | 指数与目标精度不变 |
| S09 | 强势压力题 | 保留上一轮已知的失败问题，不视为未见题 |
| S10–S11 | 全空间改平均零、再加偏移 | 检查空间绑定及负谱范围 |
| S12–S13 | 阶跃势 | 检查函数形状与回退适用范围 |
| S14–S16 | 常势与零点两侧 | 检查零谱不能冒充负谱或已知最低谱 |
| S17–S18 | 函数 L² 逼近 | 不同数学目标的控制组；A/B 原生路线不支持 |

单题的 B 幅度区间按固定公式 `a±|a|/100` 生成，其余数学参数完全一致，查询在区间中点。此规则与题单都在性能实验前写入文件，没有按测得结果缩小或更换区间。

[families.json](families.json) 包含相同指数、空间和目标精度的两个幅度区间：窄区间 `[-101/200,-99/200]` 和宽区间 `[-3/5,-2/5]`。每个区间使用预定的 16 个内部点，按同一顺序提供给四个系统，记录第 1、4、16 题完成时的累计成本。

## 如何读消耗

**壁钟时间**是实际等待时间；**CPU 时间**是进程使用处理器的时间。**峰值 RSS**是操作系统记录的被测进程最高驻留内存，以字节保存；串行进程的峰值不能相加当成同时内存。长会话的内存峰值也不能做差来假装得到每道题的峰值。

输出与证书体积按规范 JSON 的 UTF-8 字节数计量。它们反映保存与传输成本，不等于语言模型 token。测量中的数学求解器不调用模型 API，真实模型 token、代理研发 token 与对应费用没有测量。

单题成本覆盖新进程启动、导入、准备、求解、完整证书核验及落盘。批量成本包含准备与会话内检查；每张返回的证书另在新进程完整重放，费用单列并提供附加总账。失败、超时、不支持的实际开销也保留，不把快速拒绝算作提速。

## 固定条件与证据

每个设置重复五次。运行顺序轮换，性能实验始终串行；自测与其他代理的数值工作需在冻结前结束。单题及单次查询期限 10 秒，参数准备阶段最多 30 秒，会话总期限 200 秒；独立冷重放单独最多 10 秒。细节以 [protocol.json](protocol.json) 为准。

原数学源码保持不变，新接口、评估器及题单冻结后才运行正式对照。所有输入、输出、失败、超时和资源计量保留在各次结果目录。旧基线与新的源码快照共同绑定；本轮不读取历史留出题种子，不声称这些公开开发题具有未见性。

单题和批量的精简资源表分别为 [single_case_summary.csv](results/single_case_summary.csv)、[batch_resource_summary.csv](results/batch_resource_summary.csv)；[summary.json](results/summary.json)保存主要机器汇总。[完整结果](evaluation/final_20260922T021353930250Z/report.json)保留360次单题、40会话、640查询与640次完整冷重放。复现命令及预算、费用字段见 [BENCHMARK_USAGE.md](notes/BENCHMARK_USAGE.md)。
