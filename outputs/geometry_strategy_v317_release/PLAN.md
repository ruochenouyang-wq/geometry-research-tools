# 80 轮完成后的验收修订

上一目标轮属于有进展：80 轮实现、冻结检查和独立评测完成，结果同时暴露自动调度相对简单递增策略的额外耗时。本轮不修改那些证据、不增加虚构版本号，也不把原留出题继续称为陌生题。

先定位开销并修复真实弱点。保留原函数、空间、精度和完整证据；不能靠删去数学检查、只计算子问题、放宽容差或排除失败样例制造速度收益。相同输入精确结果检查与独立错误证据攻击须通过。

新的评测协议要保留旧默认、固定递增、验证选择固定配置和冻结 v317 四种参照。以新的未用种子，在新实现冻结后才生成新留出题。开发题、原留出回归和新留出分开；不根据新留出结果再改同一次验收的代码。

评测同时报告容易任务与高精度任务、初始化/在线/检查/补读成本及冷暖条件。最终按原目标逐条审计，80 轮数字本身不构成验收通过。实际模型用量或跨模型实验未测量时仍记未知；当前本地程序的零模型调用不能当作研发成本为零。
