# V88–V90 的证明接受与展示边界

V88 使用新的格式登记精确范围证书。`ExactRangeBackend` 对局部能量的负多项式求最大值，并在核验时重新检查多项式和整个 `[-1,1]`；最小值区间为最大值区间的反向相反数。Poisson 矩阵桥重建旧 Poisson 恒等式、正定权重和范围目标，不把新格式塞进旧验证器。矩阵的下界继承已验证的原对偶；上界在旧有效值与新候选值之间取较小者。即使新候选预算太小而变差，也保留负收益记录。[V88 推导](PROOF_PRECISION_BRIDGE.md)

V89 将全实线性势引理传回原目标：若 `q=q0+Σa_i(b_i+d_i*t)`，写 `q0=r+c*t`，则

\[
\lambda_1(-\Delta+q)+Q(a)\ge \min_{[-1,1]}r+b\cdot a-C(c+d\cdot a)^2+Q(a).
\]

右边是精确的参数二次式；全实域要求存在有限二次下界，盒域通过已有完整候选枚举求最小值。松弛无界只表示这条下界无效，不表示原谱目标无界。真实上界通过原势、原域的有理参数和试探函数 `u=1` 计算。`proved`、`refuted`、`unresolved` 始终比较原 threshold。[V89 推导](PROOF_ORIGINAL_GOAL.md)

V90 的 `research_registry` 只分派到程序内登记的格式/后端。`verified` 包括有效的未解决记录，因而数学接受还需检查状态。原题结构通过内容引用绑定，完整证书独立重放后才生成摘要；摘要的每个下界向下舍入、每个上界和间隙向上舍入。参考区间的坐标语义不转写成无依据的原坐标见证。

固定势正函数结果同时区分 `ansatz_*` 和 `spectral_*`：优化对偶上界通常不是原谱上界，原谱上界只能来自独立 Rayleigh 证据。统一 log-Sobolev 路径在摘要中保留经典定理依赖，不会因为压缩而隐藏其核验强度。[独立正函数审查](REVIEW_POSITIVE_SEARCH.md)

token 预算核算整个已知返回对象，包含内层文本、编码器名称、计数及 `fits` 元数据。预算不足的错误控制回复本身不保证在极小预算内，但不会给出被截断的数学结论；报告能够容纳完整必需信息的最小已试编码需求。非法 JSONL 请求返回无数学结论的错误，后续请求仍继续处理。

这些核验共享已审查的精确算术基础，并非两个完全独立实现或形式化证明内核。经典变分原理、正函数形式恒等式和明示的 log-Sobolev 定理仍是数学信任基础。支持的几何和输入族不会因为接口统一而扩大。
