# 完整径向谱分离与奇异势均值零证书

2026-09-21。只新增本目录实现；历史源码、结论和评测没有改写。H05、H07、H09 是已经揭示的开发回归，下面的通过不能记作新的独立留出成绩。

## 完整第二特征值下界

`spectral_gap.certified_gap(function, m=1, mean_zero=True, modes=8, near_tail=8, bits=24, sqrt_bits=40)` 返回 `beta=lower`，证明单个**实** Fourier 径向分块的第二特征值满足 λ₂≥beta。m≥1 的正弦和余弦块等价；不能先把二者合并再把其第二个特征值用于这里的 Temple 不等式。m=0 支持含常数或去常数两种空间。

令 P 为前 n 个该径向空间的球谐基，Q=I−P。投影后的 H−x 分块为

\[
\begin{pmatrix}A-xM&B^*\\B&D-x\end{pmatrix}.
\]

冻结实现的已验证形式界为 H≥a(−Δ)+b，a>0；Q 上的最低球谐阶为 L，故 x<aL(L+1)+b 保证 D−x 严格正。每个近尾部球谐列 B_j 的耦合积分完全精确；远尾部 Gram 矩阵

\[
C=B^*B-\sum_{j\in\mathrm{near}}B_jB_j^*/M_j
\]

由原函数 q 和 q² 的精确矩构造，而非把远尾部扔掉。均值零 m=0 情形也精确扣除常数投影。Q 形式界是正对角比较，逆序关系及远尾部最小对角元 γ 给出

\[
S(x)=A-xM-B^*(D-x)^{-1}B\ \ge\ K(x)
=A-xM-\sum_j\frac{B_jB_j^*}{M_j[a\ell_j(\ell_j+1)+b-x]}
-\frac{C}{\gamma-x}.
\]

此 K(x) 正是冻结 `direct_moments.Kernel.matrix(x,'lower')`。有限维 P、正的 D−x 和有界耦合 B 允许 Schur 形式分解；H−x 的负方向数等于 S(x) 的负方向数，而 S(x)≥K(x) 意味着负方向不多于 K(x)。因此，**K(x) 的负惯性≤1 就证明 λ₂(H)≥x**。零惯性允许存在，是包含端点的下界，不要求虚假的严格谱隙。原 ground-state 检查使用同一个比较、条件为负惯性=0；这里扩展的是被认证的谱序号。

全部矩阵、尾部下界、比较矩阵与精确有理惯性进入证书。生成时逐次有理二分，最终重新调用独立的 `direct.base.inertia`。二分右端只是正尾部屏障，**不是 λ₂ 上界**；证书不作这种上界声明。

`verify_gap(cert, expected_function=None, expected_m=None, expected_mean_zero=None, form_verifier=None)` 重建原函数矩、远尾部 Gram、比较矩阵和负惯性，严格比较完整证书。精确 JSON 类型检查拒绝用 1 冒充 True、元组冒充数组；递归/过深对象也拒绝。原函数、轴坐标、空间、谱序号和所有数学布尔声明均受绑定。

自定义合法形式界通过 `form_certificate={function: normalized_function, form: {energy_factor, mass_offset, ...}, ...}` 及 `form_verifier(cert, expected_function=q)` 注入。回调必须严格返回 True，且 a>0；验证时必须再次提供同一数学验证器，缺少它时拒绝。回调是可信验证代码的一部分，并非证书自行宣称合法的依据。这个接口供 `fullspace_singular.verify_form` 的截断奇异势形式界使用；不会因默认中心化形式界 η≥1 而提前拒绝一个已经独立认证的替代界。

## 均值零奇异势的全局证书

`singular_solver.solve(task)` 接收 `kind=spectrum, mean_zero=True, function, tolerance`。采用冻结 `adaptive_singular` 的原函数强定义域试函数与精确统计量；不改写旧模块或其全局对象。试函数在单个实 m=1 径向块中，幂次为 0 或严格大于 3/2，势指数要求 −1/2<α<0。质量、Rayleigh 值 μ、完整 Hu 范数都精确重建，残差为 σ²=||Hu||²/||u||²−μ²，包含试验空间外的部分。

新证书验证 μ<beta，再用完整径向 Temple 下界

\[
L_1=\max\{\mu-\sigma^2/(\beta-\mu),\ L_{1,\mathrm{source}}\}.
\]

此 beta 约束**整个** m=1 实径向空间的 λ₂，所以不再依赖旧的“偶分量 Temple 与粗奇分量下界取最小”的限制。另独立重放冻结 `direct.verify_sector` 的 m=0 均值零源和 m=1 源证书。

轴对称势下，m≥2 的径向形式域嵌入 m=1 域，能量差为

\[
(m^2-1)\int\frac{|u(z)|^2}{1-z^2}\,dz\ \ge\ (m^2-1)\|u\|^2.
\]

所以所有 m≥2 块都满足 λ₁(m)≥L₁+3，负 m/实正弦块由等距对应覆盖。全局下端取 m=0 下端、L₁ 和 L₁+3 的最小值；上端取完整试函数 Rayleigh 值和源证书上端的最小值。这个覆盖保留 m=0 的均值约束，未把“无约束全局 ground 等于 m=0”误用到均值零问题。

`verify(cert, expected_function=None, expected_mean_zero=None, expected_tolerance=None)` 全部重建并精确比较。接口参数名与根整合层约定一致。顶层证书包含 `format/function/mean_zero/lower/upper/exact_width/tolerance/status`；生成结果保留每个 3、6、10、16 项候选的失败或成功状态。政策不读取 case id，也不按已知振幅查表。

## R03：经过独立验证的强势形式界

R02 已在 `iterations/02_math_routes/source` 留存快照。本节新增能力针对后续明确公开的强势开发实例；不把这些公开实例称为新留出。没有按实例编号或幅值特例分支：能否使用默认中心化 L² 形式界决定路线。

`spectral_gap.certified_ground(...)` 和 `verify_ground(...)` 新增完整径向最低谱区间。参数及 `form_certificate/form_verifier` 契约与 gap 相同，证书格式为 `complete_radial_ground_form_v1`。其下端要求 K(x) 的负惯性=0，上端要求有限 Rayleigh 矩阵 A−xM 有至少一个非正方向。独立重建使用认证过的自定义形式界，而不让冻结 `direct.verify_sector` 再次强制默认 η<1 政策。默认形式路径与冻结 sector 证书完全相同，仅新格式及显式 `form_certificate=None` 字段不同。

均值零 solver 的原默认路线保持不变。默认 η≥1 时，从 `power_forms.select_form` 取得完整认证的截断 L^(3/2) 残余形式界。12、16 个源模式分阶段尝试，每阶段 m=0 均值零和 m=1 都从首尾阶 `L=modes+1` 开始，所以共享该阶段选择的形式界。gap、m0 源和 m1 源分别完整重放 `power_forms.verify_form`，不能仅靠证书中的 a、b 两个标量。

## 当前限制

形式界、有限阶数、候选上限都是显式预算。η≥1 且未提供独立替代形式界时共享默认 gap 拒绝；均值零 solver 的替代界当前限于 `power_forms` 支持的负幅度幂势（指数分母≤64等检查由其验证器约束）。m=0 若仍比 m=1 候选低，或 μ≥beta，或 16 项完整残差仍太大，返回失败/开放而不宣称精度达到。实现只解决指定原函数及精度的可验证谱子任务，不解决任一一般开放几何问题。
