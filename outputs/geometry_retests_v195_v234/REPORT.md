# 未达标题复测与 V195–V234 迭代

**四个未达标原题现已全部完成。** 本轮按每题十项可调用能力，完成四轮、40 项增量。它们是校准题和构造压力题；这里的完成指达到冻结题库的要求，不表示解决了四个公开难题。

原题库不改，原函数、算子空间、精度目标不改。主任务在独立子进程中重测四题，每题外层限时仍为 90 秒；其余 16 题复核原有证明。新实现、独立审查及统一入口共 **214 项测试通过**，旧题 **56 份保存证书复核通过**。旧版 440 个文件逐一比较无变化。

## 结果与败因

| 原题 | 旧版实际缺口 | 本轮改进 | 原题验收 |
|---|---|---|---|
| C12：函数同时正交于 1、z | 一般矩约束只覆盖单个方位角分量，不能表示完整球面问题 | 完整实球谐基、质量加权约束零空间、全部耦合与无限尾部 | 完整球面谱底精确为 **2**，x、y 均为等号试探函数；单独轴对称空间仍为 **6** |
| C14：q=-7 的负谱计数与负部迹 | 未投影接口缺失；不能把常数模态简单补到非恒定势的已投影谱里 | 分别构造两个实际算子，完整计重数与遗漏尾部，按负部迹而非仅最低特征值调度 | 零均值：**8 个、迹 20**；未投影：**9 个、迹 27** |
| C16：原集中函数 n=4、16、64 | 稠密多项式接口最多 36 次，原 n=64 被拒绝 | y=(1+t)/2 下的稀疏表示，精确双线性矩核与指数卷积，逐项绑定原系数和尺度 | 三个 n 的均值、质量、四次矩、能量及 GN 商全部精确复核 |
| C18：q=x²+2y²+3z² | 从 L=3 加到 4 没增加获胜奇数块的基函数；增加位数几乎不缩小尾部误差 | 全局势界 [1,3]、八个完整反射块、按竞争块自适应增加相关次数 | 原 10⁻⁸ 目标达成，区间宽 **6.187936668747×10⁻¹¹** |

C18 的精确端点为

\[
\frac{1082670971198065026650489}{302231454903657293676544}
\leq\lambda_1\leq
\frac{984683512085}{274877906944}.
\]

约为 [3.582257748595987, 3.582257748657867]。相对旧 L=4、48 位结果，区间宽缩小约 **38,166 倍**。最大实际计算矩阵为 6 维；其余块通过已验证的下界继续参与全空间比较，没有丢弃未获胜的块。

C16 保持原函数 \(u_n=(1+t)^n-2^n/(n+1)\)。n=64 的概率测度 GN 商为

\[
Q=\frac{402777216}{209564225},\qquad
\pi K_{\rm area}=Q/4.
\]

原 t 多项式的 65 个系数全部核对；其原质量和能量含 2¹²⁸ 尺度，四次矩含 2²⁵⁶ 尺度。未用归一化函数的矩代替原函数的矩。

## 这轮获得的工具

四组工具都支持保存精确有理数证据和独立重放。统一入口见 [使用说明](TOOL_GUIDE.md)，逐版调用与证据见 [40 项增量](ITERATIONS.md)。版本号表示能力增量，并非四十个独立发行包。

1. **完整球面有限约束工具**：可处理跨方位角、跨正弦余弦分量的矩约束，给出全空间谱界，也能输出明确违反不等式的试探函数。
2. **两种空间的完整谱工具**：区分未投影与零均值算子，合并特征值和重数，认证负谱个数与完整负部迹；排序收敛后仍会继续补齐负谱所需的信息。
3. **集中函数的精确计算工具**：稀疏矩、完整 Euler–Lagrange 残差、改进方向、指定二维试探空间的全局最优界，以及这个显式函数族的闭式规律。
4. **反射对称势的误差诊断工具**：证明对称分块有效，区分数值舍入与尾部截断瓶颈，只精化可能决定全局答案的块。

这些方法建立在球谐分析、变分原理、Schur 补和精确多项式积分之上。本轮成果是实现、范围扩展、误差调度和可复核的组合，未作算法理论首创声明。

## 审查实际发现并处理的问题

- C18 首稿在极小 `max_L` 下会在初始化时超出指定次数。现只计算预算内的块，保留其余块的解析下界；独立边界回归通过。
- C16 原 u₄、u₆₄ 尺度差异过大，最初无法认证指定平面上界。现用显式正尺度变换平衡基函数，并核验回到原坐标的试探函数。
- C16 两个各自合法的 33 项输入可能合成 65 项见证，首次生成的证书无法复核。现检查联合项数上限，并在返回平面证书前强制复核；超出 64 项明确拒绝。该拒绝不影响本轮原题的两项表示。
- 对函数族“所有实数 n≥1 连续单调”的更强猜测是错的，导数在 n=1 为负。保留并证明的是**整数 n≥1 严格递增**，且该族 πK 趋于 1/2。这不是所有函数的 GN 上界或最优常数证明。
- 主任务验收脚本首次把带调用参数的功能名称误当成符号名，阶段索引解析失败。修正解析后通过；首次日志保留。四题数学验收在该解析失败前已经通过。

各题开发失败、预算不足和未决输出保留在对应目录，未用成功记录覆盖。

## 性能证据与目前的边界

C18 三次本地运行（包含最终证书复核）中位约 0.099 秒；计时来自同一 Python 进程，基础积分缓存可能已热，不能据此推导模型速度倍数。主任务另以每题独立进程重测，完整记录在 [总验收](ROOT_ACCEPTANCE.json)。

C16 原 n=16 的五次矩调用中位用时从约 3.127 毫秒到 0.069 毫秒，均不包含输入构造和外部复核，两版证书内容也不同。原 n=64 的旧路径拒绝，不能给它编造新旧速度比。两项表示将 n=64 原输入从 1084 字节缩为 60 字节，但完整证明带有更多中间证据，低 n 的证书反而更大。字节和卷积操作数均不等于模型 token。

本轮没有调用模型 API 做对照实验，因此**尚未证明 5.6 在半小时内胜过 astra 八小时，或获得任何真实模型 token 降幅**。本轮确认的是四个具体能力缺口已补齐，以及一个原精度未达标案例获得显著更窄的可验证界。

新算法仍有明确的次数、项数和搜索预算，预算内可能返回未决或拒绝。C16 的平面全局最优仅覆盖声明的二维空间；C18 的八块方法只适用于经检查满足各坐标反射对称性的势。证明由 Python 精确有理数验证器复核，尚未导入形式化证明助手。
