# 自动 L² 函数逼近：v258–267

本组件把旧版分段函数模型的参数选择交给程序。它只认证单位球面概率面积测度下的原函数 L² 逼近误差，不给出特征值结论，不扩大旧后端支持的函数范围。

## 可调用接口

```python
from adaptive_approx import solve, ShapeCache

function = {"kind": "axis_profile", "profile": "abs_power",
            "exponent": "-1/4", "amplitude": "-1"}
result = solve(function, tolerance="1/100000000",
               max_degree=24, max_levels=64)
certificate = result["certificate"]
```

`solve(function, tolerance='1/100000000', max_degree=24, max_levels=64, **budget)` 接受与旧版一致的精确有理数字符串。`step` 与指数恰为 `-1/4` 的 `abs_power` 可用；其他幂、任意势或一般几何均未实现。`axis`、`offset`、`amplitude` 保留在返回证书中。

额外预算参数：

| 参数 | 默认值 | 含义 |
|---|---|---|
| `root_ratios` | `['1/2','2/3','3/4']` | 最多 8 个精确有理比例；不连续优化所有比例 |
| `root_ratio` | 未设置 | 只考虑一个比例；不能与 `root_ratios` 同时给出 |
| `sqrt_bits` | 40 | 开平方向上取整的起始位数 |
| `max_sqrt_bits` | 256 | 位数上限，不能小于起始位数 |
| `max_shape_evaluations` | 264 | 本次计划阶段最多新计算多少个形状；可为 0 |
| `max_certificate_slots` | 2113 | 最终展开的多项式系数槽上限，最小 2 |
| `shape_cache` | `None` | 可选显式 `ShapeCache(capacity=256)`；不提供即冷计划 |

`max_degree` 范围 0–32，`max_levels` 范围 1–64。比例须在 `(0,1)`，分母不超过 4096。未知字段、浮点精度目标、布尔型整数预算均拒绝。

返回含 `status`、`certificate`、`attempts`、`diagnostics` 与 `cost`。`status='met'` 仅在最终证书经旧验证器重放、原函数绑定正确、`error_upper <= tolerance` 时给出。其他正常未达标结果为 `open`。零搜索预算且无缓存时可能 `certificate=None`，不生成假证书；精确阶跃或零幅度仍能直接返回证书。输入非法抛出 `ValueError`，内部恒等式不符抛出 `ArithmeticError`。

证书格式保持 `sphere_structured_piecewise_L2_v1`，可独立调用 `backend.pieces.verify_piecewise(certificate, expected_function=function)`。新计划器不修改、替换或 monkeypatch 旧实现。返回的尝试记录是选型依据，不是额外数学证书。

## 数学与选择机制

对 (f(t)=b+a|t|^{-1/4})，令根比例为 (r)、层数为 (J)、每个环带多项式次数为 (d)。旧后端在标准区间 ([r^4,1]) 精确计算单位幅度的投影平方误差 (e_d^2)。完整平方误差为

\[
 E^2=a^2\left[\frac29r^{2J}+e_d^2\frac{1-r^{2J}}{1-r^2}\right].
\]

第一项是未省略的核心区域误差；第二项是全部环带误差。展开的系数槽数为 (1+J(d+1))，只是一项存储规模指标，不等于独立优化参数个数，也不等于实际字节数。

计划器利用该精确式判断固定次数的无限层数误差下限，二分寻找最少层数，并把幅度转换成单位形状的目标。偏置与轴不影响这一误差选择，但始终参与最终证书。缓存只存 `(degree, root_ratio)` 的标准形状误差，采用有界 LRU 淘汰，供幅度、偏置与轴不同的相关请求复用。

最终阶段按已配置的比例、次数和层数范围，选择达到**可报告目标**所需的最少展开槽数。位数上限为 (B) 时，可报告目标取为 `floor(tolerance*2**B)/2**B`；这样不会把尚需更高舍入位数的模型误计为可达。

核心误差非负且不能被环带项抵消，故核心项单独达标所需的层数给出每个次数的成本下界。下界不可能改进当前可达证书的槽数时，跳过该次数及之后次数。预算未耗尽且找到可达证书时，`minimum_slots_within_configured_family=True` 表示这一**有限且受限模型族内**的最少槽数；不意味着所有比例、非均匀次数分区、任意函数表示中的全局最优。预算耗尽不作该声明。

如果没有任何已查模型达标，保留已查模型中精确平方误差最小者；预算耗尽不是“不可能达到目标”的证明。最终证书的平方误差还必须与计划值一致，缓存和计划值不能绕过旧验证器。

## 十步真实迭代

每行对应当时保存的不同源码、针对检查和对照，不是对同一源码作十次参数扫描。

| 版本 | 本次增加的选择能力 |
|---|---|
| 258 | 精确区分核心误差与环带误差，绑定原函数和旧证书 |
| 259 | 用精确二分反推最小层数，替代固定层数 |
| 260 | 识别无限层数误差下限，停止无效层数搜索 |
| 261 | 由误差下限触发次数增加；只展开最终候选证书 |
| 262 | 比较有限个比例，逃离单比例的精度限制 |
| 263 | 区分舍入瓶颈并自动增加最少开平方位数 |
| 264 | 幅度归一与零幅度直接求解；保留偏置和轴 |
| 265 | 显式有界标准形状复用，区分冷计划与缓存计划 |
| 266 | 形状计算和系数槽预算；耗尽时保留最好已查候选 |
| 267 | 最少可达槽数选择、核心成本下界剪枝及舍入可达性 |

记录在 `iterations/v258` 至 `iterations/v267`。十个快照分别复跑自己的测试套件，全数通过；十个算法源文件 SHA-256 全部不同。最新版本 20 项检查通过，其中一项用 **336 个旧后端完整证书**穷举一个小配置族，核对最少槽数选择。

## 已测改进与成本

同一默认奇异函数、次数上限 24、层数上限 64，v266 与 v267 比较：

| L² 目标 | v266 槽数 | v267 槽数 | v266 新形状计算 | v267 新形状计算 |
|---|---:|---:|---:|---:|
| `1/100` | 41 | 37 | 13 | 11 |
| `1/10000` | 177 | 177 | 28 | 27 |
| `1/100000000` | 807 | 749 | 55 | 54 |

三个目标均经旧验证器确认。`1e-4` 的证书槽数没有改善，保留此结果。`1e-8` 最终选择 `degree=16, levels=44, root_ratio=2/3`，误差上界为 `2731/274877906944`，约 `9.94e-9`。这是满足精度目标的较小证书，并不追求超出目标的最高精度。

旧手工高精度设置 `degree=20, levels=48, root_ratio=2/3` 使用 1009 槽，误差约 `1.67e-9`；新计划器使用 749 槽，证书的规范 JSON 从 1,669,967 字节降到 1,005,479 字节。旧设置由调用者直接提供，因此该对照**不能**证明新计划器冷启动更快。单次本地观察中新冷计划约 0.324 秒，旧仅构造一次约 0.096 秒；前者还包含完整重放，二者工作量不同。

`iterations/v267/FINAL_COST_CHECK.json` 分别记录旧设置构造、旧设置构造加重放、新冷计划、缓存准备和新缓存执行。时间只是并发研发期间的单次观察，不是受控速度评测。缓存后新形状计算可为 0，但完整证书仍重新构造和重放，各 1 次；不能说整个请求零计算。

`cost.shape_evaluations` 仅计计划阶段新形状积分；`shape_cache_hits` 记录复用；`level_comparisons` 与 `core_bound_comparisons` 分开计数。构造与验证器自身的形状积分包含在 `certificate_builds`、`certificate_replays` 两项操作中，不计入计划预算。这些均不是模型实际 token 或跨模型效率数据。

## 复现

在项目根目录运行：

```sh
python3 -B -m unittest discover -s outputs/geometry_strategy_v238_v317 -p test_adaptive_approx.py -v
```

本组件没有网络调用、模型调用、磁盘缓存或外部发布。尚未证明对未支持的函数族有效。自动选择的数学依据来自既有精确分段投影模型，不作为新数学定理的原创性声明。
