# C2 的原创性与成熟度定位

日期：2026-09-22。结论是：**C2 可称为用于数学研究的专用可认证计算原型；现有证据不足以称为新的数学理论、通用数学研究算法或外部最优算法。** 它的具体价值在于将成熟谱估计接成完整证书，并改进何时停止、先改候选还是先改证明条件的调度。工程贡献是真实的，学术新颖性与外部领先性尚未证明。

本次只读审阅 `controller.py`、`fullspace_extension.py`、`step_extension.py`、最新报告及旧原创性记录，联网核对下列四项作者/官方来源；没有运行数学测试、迭代算法或复算性能。内部成绩引用已保存的[最新报告](../../c_demand_extension_20260922/REPORT.md)和[结果独立复核](../../c_demand_extension_20260922/notes/FINAL_RESULT_REVIEW.md)，不冒充本次新增实验。

## 已有方法：证据与对应关系

| C2 的核心步骤 | 外部原始/官方证据 | 可以得出的判断 |
|---|---|---|
| 用完整强残差 v、Rayleigh 值 μ 和第二谱下界 β，获得下界 μ−v/(β−μ) | Teschl 作者书稿的 Theorem 4.13 明确给出 Temple 不等式及地面态用法；已核对定理、假设和式(4.38)。[作者书稿，印刷页120](https://www.mat.univie.ac.at/~gerald/ftp/book-schroe/schroe.pdf#page=132) | 该公式是成熟数学。由宽度≤ε改写为 β≥μ+v/ε，是直接代数变形，不构成新不等式；严格 μ<β、强算子定义域、完整空间覆盖仍不可省略。 |
| 达到目标误差就停止，残差不足时继续迭代；采用移位逆迭代寻找候选 | SLEPc 官方 EPS 手册给出基于残差与用户容差的收敛检查、自定义停止，以及 shift-and-invert 与逆迭代的关系。它还提供 Krylov–Schur、Lanczos、Jacobi–Davidson 等成熟候选方法。[官方手册](https://slepc.upv.es/release/documentation/manual/eps.html) | “需要多少精度就算多少”及移位逆迭代并非 C 首创。区别在 C 的停止量由原算子完整认证形成；SLEPc 的默认矩阵残差不会自动证明连续球面的无限尾部。不能据此直接说谁更快或谁更严格。 |
| 结合谱间隔、后验误差界与迭代停止，而不把代数求解一律做得很精确 | Cancès、Dusson、Maday、Stamm、Vohralík（2017）研究 Dirichlet Laplace 特征值的可计算保证界，并明确纳入非精确代数求解，误差估计可在每轮迭代用于设计自适应停止条件。本次核对出版方摘要。[SIAM 原论文](https://epubs.siam.org/doi/10.1137/15M1038633) | “可认证特征值计算＋误差驱动停止”已有直接研究先例。其边界条件、势与离散化不同，不能声称论文已实现 C 的同一球面算法；同样不能把组合思想包装为本项目新发现。 |
| 在近似空间精度与代数求解精度之间分配工作，避免过度求解 | Daniel–Vohralík（2023）研究带非精确求解器的自适应 hp 细化，其中 h 指网格大小、p 指多项式次数；在明确附加条件下证明收缩，并讨论无需把代数误差压到远小于总误差的停止条件。[原刊论文](https://www.esaim-m2an.org/articles/m2an/pdf/2023/01/m2an200040.pdf) | 合理分配误差和计算量属于已有自适应数值分析。该文是椭圆边值问题，不能把它的收缩定理移植给 C2。其理论保证反而说明，C2 若要主张同等级算法成果，还需补自己的证明。 |

阅读深度：Teschl 阅读定理文本，SLEPc 阅读相关手册章节，2017论文阅读正式摘要；2023论文获得原刊索引中的完整摘要，但直接打开全文失败，因此不对其全部证明或软件实现作判断。上述文献只用于对应明确机制，未做穷尽优先权检索。

更早核心如奇点适配分数幂基、精确矩、Schur 补与无限尾部组合，已有[分数幂方法核对](../../geometry_originality_audit/FRACTIONAL_PRIOR_ART.md)和[核心方法核对](../../geometry_originality_audit/CORE_PRIOR_ART.md)。C2 继续使用这些实现，没有因更换搜索顺序而改变其原创性归属。方法有先例并不等于代码抄袭；本次没有逐行代码溯源结论。

## C2 实际新增的是什么

**源码证据。** [强完整空间扩展](../../c_demand_extension_20260922/fullspace_extension.py)先取得可验证的粗第二谱下界及粗地面谱下界，后者减去1/1024作为逆迭代移位。候选每四轮检查一次完整残差，最多24轮。若12模比较系统的首个6项候选仍有 μ≥β，便优先换到16模证明系统；源码明确将其标成启发式，未宣称其它候选不可能成功。[阶跃扩展](../../c_demand_extension_20260922/step_extension.py)按2、4、6、8、10次尝试，以完整全局区间达标停止。[控制器](../../c_demand_extension_20260922/controller.py)保留旧格式、旧验证器、回退及未认证候选的区别。

**定位推断。** 这些属于本项目的搜索策略、认证流程与执行控制组合，具有可复用的软件价值。尚未见新收敛阶、复杂度定理、最优路线选择或全局最优误差分配证明。尤其要区分两种“预算”：15ε/16是数学停止余量，七成时间分配及候选超时是执行策略；后者并不证明前者已最优。固定次数表和条件分支实现了有限适配，尚不等同于自动发现新中间引理或新研究方法。

## 新证据支持到哪里

冻结评测为24题×3系统×3次，共216条公开开发记录；数学主分母22题，另外两题是方法边界控制。根据[正式结果及口径](../../c_demand_extension_20260922/REPORT.md)：

| 观测证据 | 支持的结论 | 不支持的外推 |
|---|---|---|
| C2稳定成功21/22，C1及基线20/22；20道新公开题三者均19/20 | 新增覆盖来自旧失败回归 E19 | 不能称新题覆盖率或未知题泛化已提高 |
| E19为 q=−3|z|^(−2/5)、完整空间、宽度目标10⁻⁸；C2三次成功，中位总时间约6.68秒 | 新调度确实使该公开旧题从失败变成功 | 没有外部算法成绩，不能称此题达到外部最优；对方失败时间不能作加速比 |
| 共同稳定成功20题上，C2比C1总时间增加5.65%，比最旧基线减少18.93% | 存在覆盖与成本的取舍，C1原有收益仍占重要部分 | 不能将相对最旧基线的全部收益归因于C2新增方法，或称全面提速 |
| E03最后采用8次而非固定10次，却因前级重复尝试慢约10%；阶跃组总时间仅少约3.50% | 较低最终次数不等于较低总成本 | 三次重复及小差异不足以证明稳定优势 |
| E18的 m=1 残差显著下降，全局区间却始终由 m=0 限制而不达标 | 控制器尚未可靠识别并细化真正限制精度的分量 | 不能称已经拥有通用的失败诊断与资源分配能力 |

C2的21道成功题中，13题走新增路线，6题复用C1，2题复用函数逼近基线。这些来源必须分开。完整响应比C1增加8.04%，而本轮没有模型 API 或开发代理 token 对照；证书更小不能证明模型总 token 更少。[消耗及适用边界](../../c_demand_extension_20260922/REPORT.md)

## 成熟度与可公开名称

**有证据的成熟度：** 当前限定问题中，已经具备原题绑定、完整有理证书、独立重放、外部硬期限评测、失败留痕及冻结结果；这是能参与真实研究流程的专用工具。它仍依赖单位球面、特定轴对称势、既有强残差适用域和人工设计的候选空间。对非轴对称势、一般几何、多特征值、主导分量变化的广泛可靠调度，以及真实模型端到端收益，当前没有相应证据。

**建议名称：** “面向单位球面特定谱问题的精度驱动认证求解原型”。可以称“数学研究工具中的求解算法”，因为它确实计算有研究用途的严格谱区间；若“数学研究算法”意指自动选择研究问题、提出并证明新引理、跨领域迁移，则当前称呼会夸大能力。

**外部最优水平（SOTA）判断：目前不能认定。** 现有比较只有项目内部三版，没有与成熟候选求解器或独立验证谱法在同题、同原算子、同精度和同认证标准下比较。下一次有判别力的对照应分两层：用成熟矩阵求解器替换候选阶段，复用同一完整证书检查器，隔离搜索效率；再选数学适用域匹配的外部保证界路线，比较完整认证成本。SLEPc矩阵计算和连续球面认证不能直接互换计分，Dirichlet Laplace论文的适用条件也不能跳过。该对照是建议，尚未执行。

因此，本轮新增证据足以支持“一条旧困难任务的可靠求解流程得到改进”，不足以支持“发明新的谱理论”或“已领先其他人的算法”。最有希望的贡献方向是把现有启发调度提升为可证明或经外部盲测支持的分量选择与误差成本控制；这仍是待研究目标。
