# 基准口径与负收益

## 文本接口

采用 tiktoken 0.11.0 的两套公开真实编码器。未知具体模型映射、API framing 和隐藏推理不作估算。旧语料是随包保存的 26 份 V35 结果，新语料是 14 个实际调用。前者用于展示同一证据的不同读取方式；新接口语料另外运行实际操作并重新取回证据，二者不是未见过问题的模型评测。

以下为每题对应格式的中位数，不是先算一个平均压缩率再乘回去：

| V35 的 26 例 | o200k_base | cl100k_base |
|---|---:|---:|
| 完整旧结果、原始排版 | 2760 | 2754.5 |
| 完整旧结果、紧凑 JSON | 2059.5 | 2034 |
| 旧 CLI 简报，信息不完整 | 59 | 59 |
| 必需信息＋完整原题＋精确界＋短文件引用基线 | 212 | 203 |
| 新的内部决策回执 | 142 | 138.5 |
| 新的完整已知返回包装 | 172.5 | 173 |
| 原题请求＋新完整返回 | 219.5 | 216 |
| 另行取回完整受检证据的响应 | 1796.5 | 1773 |

按每题配对再取中位数，新完整返回相对旧完整排版文件节省 93.62%/93.59%，相对完整紧凑 JSON 节省 91.26%/91.08%，相对必需信息精简基线节省18.36%/15.43%。26 个请求及响应加首次能力说明和操作表的文本会话总量为 5998/5914。逐题原始数据、输入表示的负收益与取回开销见 `results/token_benchmark.json`。

14 个新接口案例的内部回执中位数146/142，完整包装177/178，请求＋返回213/212。相对于同批完整紧凑证据，中位节省85.70%/85.25%；相对于同批必需信息精简基线，反而增加11.15%/18.87%。一次性说明与全部请求/返回合计3253/3240。`results/service_benchmark.json` 保存每个真实请求、回执、对应完整证据文件及耗时；这些界面耗时仅单次运行，不能用于可靠速度排名。

V36–V55 的20项逐功能实测在 `results/version_token_experiments.json`。不同功能使用不同工作负载，不能串成一条累计加速曲线。批量、分页和引用在重复或选择性查询中有优势；短表达式改成稠密系数输入可能更长，完整分页取回也会增加开销。

## 数学算子

本机 macOS arm64、Python3.9.6；每个方法3次顺序执行。计时包括生成、内部检查、额外证书重放及读出，排除模块导入与输出文件I/O。预算绑定同一原始输入和细分/轮数上限，但每一轮内部工作不同；同时展示实际耗时。毫秒尺度的数据受系统负载影响。

| 全区间最大值案例 | 旧/新细分数 | 旧/新中位耗时 | 结果 |
|---|---:|---:|---|
| `t-t³` | 20 / 8 | 4.306 / 3.572 ms | 都达到1e-12，新界更紧 |
| `-(t-1/3)^8` | 6 / 0 | 5.025 / 1.704 ms | 新最大值精确为0 |
| 非对称双峰 | 19 / 11 | 5.794 / 7.768 ms | 新误差更小、耗时更长 |
| `-(t²-1/3)^4` | 10 / 0 | 2.927 / 0.815 ms | 新最大值精确为0 |

| 同题五轮矩阵比较 | V34间隙 | 新间隙 | 旧/新中位耗时 |
|---|---:|---:|---:|
| 标准成本 | 4.35565e-6 | 5.51228e-6 | 71.616 / 106.476 ms |
| 非对角成本 | 3.89356e-5 | 2.72804e-5 | 150.011 / 295.058 ms |
| 严重缩放、保持原目标等价 | 0.1690606 | 5.41713e-6 | 105.904 / 101.856 ms |

上述矩阵间隙是 Poisson 包络的全局原始/对偶差。标准例两个方法均达到1e-5；非对角例两个都未达到；缩放例只有新方法达到。不得把病态例的误差改善当成速度倍数，也不得把包络最优当成所有谱不等式的最优。

固定势 `q=6t²` 的旧Poisson下界1、新二次对数下界约1.43808957、新六次偶对数下界约1.56743838；三者绑定同一势。真实Rayleigh上界约1.57115584。`q=20t²` 的下界从−40/9提高到约3.63986074，Rayleigh上界约3.65673075。增加函数族提高了质量，也增加计算工作，不能当成同精度加速比较。

统一不等式的1/4、全实Barta1/5、经典LS1/6与1/7反例分别保存独立证书。将失败候选“要求1/6”与旧1/4作比较时，基准的 `verified_metric_improvement` 为null；只列目标系数不能算改进。

完整数据在 `results/math_benchmark.json`：28组合×3=84次运行，105份证书工件含重复；11个对照有负速度收益，1个有负精度收益。每份证书除了数学重放，还检查势、方向、成本、区间、系数等与基准输入一致。运行记录包含所有预算与检查，不靠成功筛选形成漂亮表格。

V88 的固定权重精度桥另有精确回归：粗旧上界约0.31247372降至0.27193749；新后端零预算得到更差候选时自动保留旧界。V89/90的原题与服务集成由专项测试及14个实际调用验证，不把新接口包装当作额外数学突破。
