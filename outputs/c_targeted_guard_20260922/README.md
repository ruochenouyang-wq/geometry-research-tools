# C3.1：有效结果保护

这是冻结 C3 的小修正版，评测代号 C3G。完整改造、第一轮成绩和本次补充回归记录在 [总报告](../c_targeted_iteration_20260922/REPORT.md)。

C3 在一道新参数题上返回了比旧算法更宽的有效区间，却仍有剩余预算。C3.1 因此增加一项通用规则：对于正幅度、平均零负幂势，若已有证书有效但尚未满足原精度，剩余时间足够时尝试一次旧基线。只有通过原题验证、且区间严格更窄的结果才会替换旧结果。后备失败、超时或没有改善时，保留已有结果。

这没有放宽原容差，也不意味着未达标题已经解决。后备必须从同一原函数和空间开始，其导入、失败尝试、核验及输出都计入总费用。已经成功或不符合条件的请求继续使用冻结 C3 的结果。

需要保留相邻 C3 与原有 `outputs` 依赖目录，Python 3.12，NumPy 可选。入口使用 Unix 进程与定时机制，须在主线程顺序调用，不承诺同进程多线程并发。在项目根目录执行：

```sh
python3 -B outputs/c_targeted_guard_20260922/controller.py
```

每行输入一份原格式 JSON；示例：

```json
{"kind":"spectrum","function":{"kind":"axis_profile","profile":"abs_power","axis":0,"amplitude":"2/3","exponent":"-2/7","offset":"0"},"mean_zero":true,"tolerance":"1/1000000","budget":{"wall_seconds":10}}
```

`certificate_valid` 表示原题证书有效，`target_met` 还要求达到原精度和预算。`guard` 记录是否尝试后备、为什么替换或保留、实际选择的来源。请通过外部评估器实施严格的整个进程时间限制。

补充评测只覆盖预先固定的 8 道定向回归题、两版各三次，共 48 次。原 C3 的 180 次全题比较另行保留，二者不能合并成一次新的盲测成绩。

48 次已完成：两版均稳定达标 5/7 道数学题，另一个方法边界控制按预期拒绝。N29 三次均恢复原 C2 的有效宽度约 0.0005088，仍未达到 0.000001；完整用时中位数由 3.75 秒增加至 7.07 秒。其余题没有丢失有效证书、成功或精度。所有数学证书仍经过原题完整重放。
