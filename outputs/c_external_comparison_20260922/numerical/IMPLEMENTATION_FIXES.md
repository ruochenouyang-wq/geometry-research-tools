# 运行前实现修正

以下修正发生在第一次公开数值候选运行前，未查看任何比较结果，未改动算法、题单或协议。

- 静态审查发现新目录层级使 C2 源码路径少了 `outputs` 层；改为从 `ROOT.parents[1]` 解析。
- 公共上下文或矩阵准备失败时保留对应 18 或 6 行未启动失败，72 固定分母不变；每步公共成本即时写入 PREPARATION.json。
- 使用子进程原子结果文件与父进程绝对截止，不再使用可能无界的 Pipe.recv/join。进程退出、响应读取及解析均受同一 10 秒验收界约束；超时后终止/回收最多另需 0.5 秒，此类行不能计达标。原始完整响应及部分文件保留。
- child_total 明示不含末尾 JSON 写入；process_pipeline 包括工作进程序列化、通信文件读取、父进程解析和进程管理。残差细化时间是 candidate 的子集，不能重复相加。

只运行小型解析变换/失败控制及一次公开 6 项原 C2 等值控制；后者包含在正式 runner 启动检查中，独立计时。首次完整 72 行输出后不再修改候选算法择优重跑。
