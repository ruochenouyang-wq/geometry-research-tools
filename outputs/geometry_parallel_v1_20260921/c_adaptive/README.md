# 并列版本 C：按证明需求认证谱间隔

入口为 `variant.solve(task)`，沿用旧统一任务格式；`variant.verify(certificate, task)` 返回旧 `baseline.assess` 的原题绑定检查结果。当前实现版本为 `c-proof-demand-threshold-v1.1`。未修改历史数学文件或共享模块绑定，没有新增隐藏缓存，也没有模型调用或模型token收益数据。

## 实际改变

完整残差平方记为 `v`、候选Rayleigh值为 `mu`、目标宽度为 `tol`。Temple界只需要一个已认证的第二谱值下界 `beta>mu`，并满足 `v/(beta-mu)<=tol`。C先尝试给最终宽度分配 `15/16*tol`，以 `mu+max(v/epsilon,2^-24)` 为充分阈值，向上取20位二进有理数，再做精确惯性检查。余量阈值失败时允许试完整 `tol`，不会放宽用户精度。

阈值达到径向尾屏障时直接拒绝，记录失败时间但不虚增惯性次数；其余失败同样保留。向上取整可能让某些本可认证的边界案例失败，因此保留旧路线回退。`v=0` 仍显式保证 `beta>mu`。

完整空间候选搜索暂用尾屏障作为搜索启发参数，它不是第二谱值证明；只有通过旧 `_certificate` 的阈值证书可进入最终旧数学证书。平均零路线另生成m1的粗源证书供移位搜索，m0必须通过 `mu-15/16*tol` 的排除阈值，保留原角向覆盖。不同空间不会互换。

完整空间仅在原 centered L2 型界可用时启用C；型界不可用时立即使用剩余预算调用旧求解器。mean-zero强势路线仍保留独立阈值策略。step与函数逼近保持旧路线。所有结果使用旧证书格式；C生成的证书经过JSON往返及旧 `baseline.assess` 完整重放。回退结果保留旧 `baseline.solve` 已完成的原题绑定重放，避免重复添加一次检查。

## 预算与计数

总预算从统一入口开始，含导入、准备、失败、证书转换和最终重放；协作检查不能中断正在运行的同步计算，外部硬期限仍必要。零预算不启动任何数学路线。回退只获得剩余预算，超过总预算绝不记为达标。

`total_elapsed_seconds` 是唯一完整调用成本，不能累加可能嵌套、可能缺少准备工作的action时间。`search_inertia_checks` 只记录C显式搜索的惯性检查，不包括矩阵构造的Gram正定性检查、旧验证内部操作或baseline回退操作。`final_frozen_replays` 同样只计C显式发起的重放，不包括回退内的旧重放。跨方法总计数应由独立评估器统一采样，不能直接拿这些局部计数比较旧版总操作。

## 测试与保留的失败

`test_variant.py` 的9项检查通过：两种谱空间的最终旧重放、完整残差阈值、m0排除、原题绑定与篡改、零预算、协作超时、剩余预算回退、零残差严格间隔、step/approx回退，以及强势完整空间的适用性门控。

`PUBLIC_PROBE.json` 是门控修复前源码 `3b50f348356590c8663e5299e211fab93d75fd3ab29d39c34a44f0d8acd1e2e7` 的六个公开题开发记录，同进程、交错顺序、每法三次，共享历史缓存，计入JSON和额外外部重放。该版六题两法均成功；计时和剖析结果全部保留。它不是冷启动或冻结后独立测试，也不能代表最终门控版本在强势完整空间的表现。

独审随后发现公开 `q=-3|z|^(-2/5)` 全空间、5秒预算下，旧C的20次阈值都被尾屏障拒绝，最终5.328秒超时。完整已报告字段保存在 `DEVELOPMENT_LIMITS.json`。因此加入按完整型界适用范围的回退门控，主动放弃部分曾获益的强势完整空间案例；未为这一个幅度设置查表条件，未删除该失败或改动题目。最终共同冷启动比较须在全部开发和审查停止后串行运行，当前未预填结果。
