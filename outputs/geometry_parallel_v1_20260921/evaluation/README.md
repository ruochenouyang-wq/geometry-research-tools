# 三路公开开发对照评估器

本目录只包含公开开发题与本机数值实验。它不是留出集，不检验跨模型能力，不以运行时或 JSON 字节代替真实模型 token。开发阶段未读取种子、未抽取正式题。开发完成后，根代理已冻结代码并运行最终串行比较，结果见 [最终 report.json](final_20260922T013006751900Z/report.json) 与 [中文报告](../REPORT.md)。

## 固定任务与分母

- 共同集：`common_cases.json`，8 题、4 系统、2 次全新进程，共 64 次。6 道最低谱与 2 道函数 L2 逼近各自标明目标量；均为 1e-8。成功要求两次分别完整重放通过、原函数/空间绑定正确且达到原精度。回退单列。
- 参数流：`stream_cases.json`，16 个预定内部幅度点；4 系统各做 2 次新会话，共 128 个查询。每会话按同一顺序，不用结果调整点。B 的准备、完整家族验证、建立已验证上下文都计费；每个返回的查询证书另做全新进程完整重放，共最多 128 次。无证书时保留失败记录，注明未执行重放。
- 扩展集：`extension_cases.json`，6 题，4 系统各运行一次；只有 A 支持新增任务语言，其余明确记录不支持。认证负谱个数与有符号负特征值和宽度分别统计，绝不加到共同任务胜率。常势用于穿零和重数校准，阶跃/负幂另列。
- 可靠性：直接调用各版验证器，检查状态字符串伪证、错误函数/空间、区间或计数篡改、A 尾界篡改，以及真正 B 家族查询证书的统一宽度与区间覆盖篡改。B 两会话各有盒外查询；超时不是“已拒绝”。缺少可用证书而未能执行某组攻击时，明确报告覆盖不足。

## 时间边界与费用

共同题和独立冷重放的 5 秒覆盖整个子进程：启动、导入、求解/重放、完整 JSON 编解码和原始输出落盘。扩展题同样为整进程 10 秒。父进程单独执行硬截止并杀死进程组；求解器吞掉普通异常或 `BaseException` 不会取消父进程截止。

参数会话的启动最多 5 秒，准备阶段最多 30 秒，每次查询最多 5 秒。启动、B 准备和初次验证全部累积计入 N=1/4/16 的实测费用，因此不能把 B 温态查询与基线冷启动直接比较。报告同时给出含准备的主会话累计费用、额外完整冷重放费用、两者之和；首题与后续查询另列。某前缀未完成时将已发生的整个会话费用计入该失败前缀，不用空值或零成本藏掉准备失败。

壁钟由父进程测量，进程 CPU 由系统资源计量，流内细分 CPU 由子进程单调累计计量。父进程准备请求文件与整理汇总属于评估管理开销，不计入被测进程预算。原始日志、返回、独立判断和失败均保存。多代理机器背景活动仍可能影响壁钟；只有两次重复，速度差只能视为初步结果。同成功题的配对费用才可比较；下降至少 20% 也只称值得继续验证。各实现自报惯性检查计数的口径不同，不作跨版对比。

## 运行方式

使用同一 Python：

```sh
/PYTHON/bin/python3 -B outputs/geometry_parallel_v1_20260921/evaluation/compare.py selftest
/PYTHON/bin/python3 -B outputs/geometry_parallel_v1_20260921/evaluation/compare.py smoke
```

开发者全部停写源码后，由根代理依次运行以下命令；评估器作者不同时运行比较：

```sh
/PYTHON/bin/python3 -B outputs/geometry_parallel_v1_20260921/evaluation/compare.py freeze
/PYTHON/bin/python3 -B outputs/geometry_parallel_v1_20260921/evaluation/compare.py run
```

`freeze` 保全所有 `outputs/geometry_*` 的 Python 文件（含历史依赖、四个入口、共享适配器、统一 CLI、评估器）、公开协议/题单及旧 v1 题单、计划和 BASELINE 身份清单，并生成带逐文件索引的源快照压缩包。本次 ZIP 含 572 份源码及 12 份资料；BASELINE 的 567 个只读文件均做哈希核对，其中 `outputs/math_research/` 下 5 份只通过 BASELINE 身份绑定，不在 ZIP 内，复现须保留完整项目。文档和结果可继续新增，Python、任务、协议或计划变化会拒绝最终比较。`run` 在开始与结束再次核验所有身份；变化时保存结果但拒绝标记为有效冻结比较。

所有运行都写新目录。`report.json` 是汇总，逐题 `spec.json`、`output.json`、`result.json` 和 `worker.log` 是证据；运行中共同题与参数流另有 checkpoint。`valid_frozen_comparison` 仅说明冻结身份稳定，不代表算法达到所有目标或可靠性覆盖完整。应同时看 `reliability_complete_pass`、各固定分母成功数、扩展计数/谱和分项和实际费用。
