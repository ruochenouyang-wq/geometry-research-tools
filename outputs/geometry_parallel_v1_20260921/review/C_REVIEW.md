## 数学推导与空间覆盖

令 μ 为归一化 Rayleigh 商，v=‖Hu‖²/‖u‖²−μ² 为完整强残差平方，β 为同一完整实径向分量第二谱值的下界。Temple 给出

\[
\mu-\frac{v}{\beta-\mu}\le\lambda_1\le\mu,
\qquad \mu<\beta\le\lambda_2.
\]

因此，对于 ε>0，认证 β≥μ+v/ε 且 μ<β，足以保证区间宽度≤ε。代码先尝试 ε=15tol/16，再尝试 tol；用精确有理数计算阈值并向上取二进制有理数，不以浮点数决定接受。v=0 时额外要求 β≥μ+2⁻²⁴，因此没有出现零除或用 μ=β 偷换严格条件。独立零残差测试得到 β=1572865/1048576>3/2，旧 `verify_gap` 接受。

这里的 λ₂ 是单个实径向分量的第二谱值，不能替换为整个球面按重数排列的第二值。`_gap_at` 仍调用旧 `_certificate`，要求被消去尾部严格正，并精确检查 Schur 比较矩阵负惯性至多为一。把 β 设为径向尾屏障本身会拒绝。比较矩阵允许零方向，因为输出是非严格的 λ₂ 下界；μ<β 另行保证。

全空间路径使用原 m=0 完整试函数、完整强残差、形式下界及方位角能量支配关系，沿用旧证书将全局最低谱归约到 m=0。候选优化使用的 `kernel.beta` 仅是启发值，实际接受前必须取得独立的第二谱阈值证明，未把尾屏障直接当作谱隙。

平均零路径没有使用上述全空间归约。它对 m=1 做 Temple，同时独立认证 m=0 的下界不低于向上取整的 μ−15tol/16。旧完整证书再以 m=1 下界加三覆盖 m≥2，并与 m=0 合并。如果 m=0 排除失败，该候选不会成功。最终上界≤μ，最终下界≥μ−tol 的要求由原证书重新计算；不是只看 m=1 宽度。自定义形式证明与强算子定义域也由旧验证路径重放。

固定的向上取整精度和 2⁻²⁴ 严格余量可能使本来可用的极窄谱隙认证失败。这是保守性和效率限制，不会扩大有效谱界。

## 原题绑定、攻击与最终重放

C 新路径先把证书转换为 JSON，再调用冻结的 `baseline.assess`。原函数、均值约束、容差、证书格式及数学数据均重新检查。回退路径调用冻结 `baseline.solve`，后者内部已做同样的 JSON 与原题绑定重放，C 复用该结果；回退仅改变剩余时间预算，不改变原函数、空间或容差。独立的 `C.verify` 也直接调用原 `assess`。

最终冻结版公开题为 q(z)=−(2/3)|z|⁻¹⁄⁵+1/7，axis=1，目标10⁻⁸，两个空间各给5秒：

| 空间 | 旧验证器重放 | 区间宽度（展示用近似） |
|---|---|---:|
| 完整空间 | 达标 | 9.0498758001×10⁻⁹ |
| 平均零完整空间 | 达标 | 9.3685333863×10⁻⁹ |

针对这两张证书独立做24次篡改/错题重放，全部拒绝：伪造上下界、残差、gap、形式能量因子、空间、容差；替换预期原函数/空间/容差；只留下 bounds 和成功状态；平均零模式另删除或提高 m0 下界、改写角向覆盖和强定义域。不是看到 `bounds` 或 `target_met` 字段便接受。

另外六种非法容差（零、负数、大于一、小于10⁻³⁰、布尔值、浮点输入）均拒绝。修改原题参数有时仍对应等谱问题，例如坐标轴置换，也不能免除证书绑定。早期同数学路径的常数阶跃校准 q=3/2 分别精确返回3/2与7/2；它验证回退接口，不算 C 的新能力。

## 时间预算、失败成本与计数

最终版的零预算和10⁻⁶秒预算均不产生成功。独立注入约0.01秒失败工作后，原1秒预算回退实际收到约0.98745秒；失败动作和回退内部失败记录保留，完整耗时含这次失败。再注入超过0.001秒期限才返回的候选，结果为 `budget_exceeded`、`target_met=false`，未进入最终重放。

`total_elapsed_seconds` 是求解调用内部完整成本；动作记录可能嵌套，也可能没有单列准备工作，不能相加充当总成本。预算属于协作式检查，一次精确计算或旧回退可跨过期限，之后必须报失败；外部进程硬期限仍必需，且应覆盖模块加载、输出编码和独立外部重放。一次调用结束前的本地计时不是冷启动总成本。

`CountedKernel` 只包装本次对象，没有替换共享后端函数。最终测试前后，已加载共享直接矩模块的可调用对象身份不变。计数器值不参与谱界推导或接受条件；它们不是数学证据。计数仅包括 C 显式搜索比较，不含旧验证器内部检查、Gram 半正定检查和回退工作。尾屏障直接拒绝时惯性计数为零，但该次失败的准备时间依然有成本；`final_frozen_replays=0` 的回退也不表示未验证。跨路线成本比较应使用外部总时间，不能只比这些计数。

## 保留的失败及最终适用性门控

审查者公开压力例：q(z)=−3|z|⁻²⁄⁵，axis=0，完整空间，tol=10⁻⁸，预算5秒。门控前源码 `3b50f348356590c8663e5299e211fab93d75fd3ab29d39c34a44f0d8acd1e2e7` 先做10次候选、20次尾屏障失败，再回退，总计5.328秒，正确报超时且没有证书。不能删掉这次失败来报告速度。相同输入的平均零路径当时达标，其额外覆盖攻击全部拒绝。

最终版对完整空间先检查 centered form；不可用就直接回退，平均零策略不变。在同一压力例上，最终实测 C kernel=0、candidate=0、skip=1、fallback=1；约3.331秒后返回 `no_verified_certificate`、无证书、未达标。门控消除了这类重复启发尝试，**没有解决该例**。门控依赖形式下界适用域，没有按题号或单个参数查询选择结果，但也是本轮公开开发反馈产生的策略，不能因此宣称未知题表现。

这些时间只用于确认失败与预算路径，不是重复、公平成对的加速基准。审查没有发现当前范围的假数学成功；仍不构成形式化证明、一般几何适用性或模型 token 收益的认证。
