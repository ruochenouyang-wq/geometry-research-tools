# C 与可靠数值软件：比较的是哪一层

核对日期：2026-09-22。本笔记实际查阅官方项目和技术文档；未安装软件，未运行数学测试。

**结论：INTLAB、Arb/FLINT 和 VSDP 都是值得借用或设置对照的软件，但此次没有找到它们直接接收本项目球面奇异势（具有局部无界系数的势函数）、输出原题最低谱值认证区间的现成入口。** 这表示尚未核实同题实现，不表示依靠这些工具不能开发出更好的算法。不能把软件库的通用能力，当作已经运行过的完整竞争算法；也不能因其未提供专用入口，就宣布 C 优于这些项目。

这里的 C 包括原按需计算路线 C1 及扩展 C2：按最终精度要求选择试函数（近似最优解的候选函数）和辅助谱界，在单位球面 S² 上认证最低谱值，即所有允许函数中可达到的最低能量。其范围和现有结果以 [C2 报告](../../c_demand_extension_20260922/REPORT.md) 为准。

## 1. 先区分三个层级

**可靠数值计算**是同时计算近似答案和具有数学保证的误差范围。**区间算术**用一段范围表示数值，每步运算把可能的精确结果全部包住；**向外舍入**指下端向下、上端向上调整，以覆盖机器只能保留有限位数造成的误差。Arb 的**球算术**采用“中心 ± 半径”表示同类范围。[Arb 算术契约](https://flintlib.org/doc/arb.html)

| 层级 | 实际证明什么 | 本次软件的位置 |
|---|---|---|
| 算术与函数计算 | 输入在指定范围内，运算结果落在输出范围内 | INTLAB、Arb/FLINT |
| 有限维问题 | 给定有限矩阵的特征值，或有限个变量的优化目标受到严格约束 | INTLAB、Arb/FLINT 的矩阵例程；VSDP |
| 原始无限维问题 | 对球面上全部允许函数成立，并覆盖有限计算没有保留的方向 | C 的专用数学论证；不能由前两层自动推出 |

**特征值**描述矩阵或算子在特殊方向上的伸缩；**算子**在本题中是把函数映射成另一函数的规则。把函数问题改用有限个系数计算，称为**离散化**。即使离散矩阵的最低特征值已经算得非常精确，它与原问题的差距仍需另行证明。

## 2. INTLAB：最接近现成验证工作台

INTLAB 是 MATLAB/Octave 中的可靠计算工具箱。官方示例先产生普通近似特征值与特征向量，再调用 `verifyeig` 验证；还能处理相近或重复的特征值，以及整个有限矩阵的特征值。因而它明显超出基本区间加减乘除，适合对 C 的有限矩阵及近似候选做独立数值核验。[官方矩阵示例](https://www.tuhh.de/ti3/intlab/demos/html/dintval.html)

工程成熟度较高是基于其长期维护、完整示例和现有功能的判断，不是此次速度实测。官网当前为 14.1，列出矩阵分解、积分、非线性方程和全局优化等工具，并说明在 Windows、Linux、macOS 测试，支持 MATLAB 和大部分 Octave 使用。移植到现有 Python 项目仍需另接运行环境和数据交换。许可也不同于通常的宽松开源库：依赖 INTLAB 的商业产品需要专门许可。[官方能力与许可](https://www.tuhh.de/ti3/intlab/)

**与 C 的关系：** 可作为有限计算层的替换或对照；其“全局优化”功能不能直接解释为对本题无限维函数空间（全部允许函数组成的集合）完成全局证明。仅把 C 的离散矩阵交给 `verifyeig`，无法补上奇异项和被省略方向的误差。此判断来自输入对象和证明目标的差别，非软件能力上限测试。

## 3. Arb/FLINT：最适合优先考察的可移植算术底座

Arb 提供可提高位数的实数、复数球算术，现已并入 FLINT 3；FLINT 是公开的 C 语言数学库，涵盖整数、有理数、多项式和线性代数，采用 LGPL 3 或更新版本许可。源码、构建说明和检查程序公开，适合嵌入工具服务；仍须支付编译依赖、接口封装和部署验证的成本。[官方仓库](https://github.com/flintlib/flint)

它也有有限矩阵的可靠特征值例程，包括整体包围及相近特征值的分组处理。一个重要边界是：名称含 `approx` 的矩阵例程只产生近似结果；数值迭代收敛不能当作认证成功。另外，“所有特征值都落在若干圆盘的并集内”不保证每个圆盘各有一个特征值，排序和计数必须使用对应保证。[矩阵接口及明确限制](https://github.com/flintlib/flint/blob/main/doc/source/acb_mat.rst)

**与 C 的关系：** 可用于计算积分表达式、残差（试函数代入方程后剩下的误差）和有限矩阵界限，或降低现有大量有理数运算的成本，但是否更快尚未测量。区间中同一变量的多次出现可能造成不必要的放宽；增加精度也不必然解决全部问题。官方教程特别指出：计算无限级数时，用户仍须给出未计算部分的界。这与本项目必须控制无限维余项（有限表示未覆盖的部分）的区别直接相关。[官方误差说明](https://flintlib.org/doc/using.html)

## 4. VSDP：有限维优化结果的验证层

VSDP 用严格误差界验证锥规划结果。这里**锥规划**是一类带特定形状约束的优化；其中**半正定规划**允许以矩阵为变量，并要求相应二次表达式始终非负。它接收已有求解器给出的近似解，计算真实最优目标的上下界，并在条件允许时验证可行解或无解证据；这不是把普通求解器的成功状态直接照抄。[官方仓库与能力](https://github.com/vsdp/vsdp-2020)

VSDP 在层级上高于基础算术，但目标仍是已经写好的有限维优化问题。官方例子会检查有限矩阵的最低特征值，用于验证优化约束。[官方半正定规划例子](https://vsdp.github.io/vsdp-2020/s05_semidefinite_programming.html) 如果将本题改造成这种优化，必须另外证明所得界与原球面问题之间的关系；若只得到原问题的一个下界，也不能冒充具有指定宽度的双侧认证。

其优势是现成验证流程；接入负担则包括 MATLAB/Octave、INTLAB 和至少一个近似优化求解器。官方安装说明提供各项依赖和自测，仓库当前列出的最新发布为 2020.1（2022 年）；这只能说明已核对到的发布记录，不能直接推断停止维护或当前环境无法运行。本轮没有测试与 INTLAB 14.1 的兼容性。[安装要求](https://vsdp.github.io/vsdp-2020/s01_installation.html)、[发布记录](https://github.com/vsdp/vsdp-2020)

## 5. 对本项目还缺什么，以及如何公平比较

以现有 E19 的 `q(z)=−3|z|^(−2/5)` 为例，系数在赤道附近无界。仅有可靠算术还不够：需要证明相关积分存在、试函数满足算子要求、残差包括全部方向，并取得同一函数空间内正确的第二谱值下界。**Temple 不等式**是把这些条件下的残差转成最低谱值误差界的定理。还须覆盖所有角向分量；平均零约束和完整空间不能混用。这些桥梁已在项目中接受人工数学审查与程序重放，但尚不是完整形式化证明。[R03 证明审核](../../geometry_accuracy80_20260921/R03_PROOF_REVIEW.md)

**形式化证明**要求把命题及推导写入严格逻辑语言，由证明检查核心验证。上述可靠数值库提供的是算法和实现层的严格包围保证；本次未查到它们已经替本项目完成从公理到无限维结论的形式化证明。使用者仍须正确输入问题、遵守函数前提和检查返回状态；INTLAB 官网也明确承认程序和处理器并非保证无缺陷。C 的共用验证代码同样不能获得更高的免检地位。

建议先做“相同数学路线、更换有限计算底座”的对照：保持原题、试函数、余项定理和目标宽度一致，比较现有有理数计算与 Arb/FLINT；需要另一套有限矩阵验证时考虑 INTLAB。若探索 VSDP，应另列为“新建有限维优化路线”，把改写原题的数学工作与实现费用计入。整题速度须覆盖组装、候选、算术验证、无限维认证和输出；准备成本单列。任何只算完矩阵、尚无原题严格下界的结果，均标为部分完成，不进入整题成功率或加速排名。
