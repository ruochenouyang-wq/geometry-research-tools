# 第十轮：把单位球工具推广到几何尺度与半径区间（V185–V194）

实际试题是“半径 2 的球面上，零均值 Laplace 基态是多少？”旧 JSON 接口直接拒绝 radius 字段，因此诊断是几何尺度能力缺失，而非旧算法计算错误。新工具得到精确值 1/2。

本轮十个编号对应十项可调用的计算能力；测试、文档和输入检查不单独计版。所有谱结果针对圆球 S²_R 上全部实值零均值 H¹ 函数，且使用自然面积。

核心关系来自 x=Rω：质量积分乘 R²，Dirichlet 能量保持不变。若势写成 q(x3)，单位算子势是 R²q(Rt)；若势写成 q(t)，单位算子势是 R²q(t)。特征值与完整负谱迹再除以 R²，重数与严格负谱计数不变。

半径区间求解使用锚点、势系数变化的统一范数界以及 min–max 扰动界。把单位谱区间乘以 [1/b²,1/a²] 时计算四个端点积，保证负特征值不会因符号处理错误产生错误上下界。全局最小值上界只取具体可行半径的谱上界；整个区间的最大值上界单独记录。所有叶区间都保留，因此重放能够检查完整覆盖，不信任未记录的裁剪步骤。

独立审查发现并修复一项续算缺陷：同一个半径的两个合法谱包围可能互不包含，按区间宽度替换证书会丢掉较好的旧上界。现在续算保留旧可行点证明与新缓存证明，并把子区间包围与父区间包围相交；数学全局上下界保持单调。另修复了 ambient pullback 和点型研究请求的外部输入绑定。

精度不足的结果保留为 open。上面的 normalized q=t² 全局最小值包围宽约 2.6966×10⁻⁴，仍未达到要求的 10⁻⁴；ambient x3² 的八次分割试验也仍 open。1906 倍仅指该固定算例的数学包围宽度缩减，不是模型速度或 token 节约。缓存计数仅统计本地谱锚点计算；没有调用模型 API，没有获得任何模型 token 用量测量。

已保存 24 份顶层数学证书并逐份重放。自测 35 项覆盖正负特征值、面积与势能尺度、错误坐标、非零均值、错误半径、区间覆盖缺口和重叠、缓存与原问题不匹配、阈值篡改、有限预算 open，以及明确的可行点上界。独立审查结果另见 `INDEPENDENT_REVIEW.md`。

实现位于 `sphere_scale.py`；运行 `python3 -B outputs/geometry_cycles_v95_v194/round10/run.py` 可重建十版证据。`STAGES.json` 保存每版 callable 与验收文件；`RESULTS.json` 保存 24 份证书清单。接口接受精确有理数，半径范围 0<R≤32、势次数至多 24；变换后的系数须满足后端资源上限。它是依赖球面缩放和 min–max 分析定理的软件有理证明，尚未由形式化证明助手检查，也没有把有限半径试验推广成任意流形或普适 GN 常数结论。
