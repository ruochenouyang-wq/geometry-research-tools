# 给 GPT 的几何工具研究协议

任务目标是获得能迁移到一类问题的数学工具，不以宣称解决一个未解猜想为目标。

对每个研究对象，请提交以下六项：

1. **精确对象。** 维数、基域、光滑性、紧性、边界、嵌入/浸入、对称性和等价关系。谱问题需写明是否剔除零模态与特征值编号。
2. **问题状态。** 已解决、特殊情形已解决、仍开放或有未确认证明宣称；附原始来源及核查日期。不能仅因预印本摘要声称解决就升级状态。
3. **缺失步骤。** 当前方法到底缺少构造、下界、紧性、全局拓扑控制、可积性、精确性还是表示能力？给出一条具体的尚未成立的数学蕴含。
4. **工具合同。** 输入、输出、依赖的定理、可检查条件、失败的含义与适用范围。
5. **三类基准。** 已知结论的正例；违反一个关键假设的负例；结论为真但超出工具当前范围的漏解例。工具拒绝最后一类不代表命题为假。
6. **证据与下一步。** 给出简洁、可核查的推导或证书。区分数值观察、已认证界、条件性推论和未完成证明。然后提出一次能够区分两种解释的实验。

优先从已解决证明中抽取可复用的中间机制：非塌缩、单调量、对偶证书、拓扑障碍、补空间估计、精确构造。不要只模仿最终定理的表面形式。

## 调用当前谱工具

当前模型固定为单位 S² 上 `H=-Δ+q(cos θ)` 的轴对称子空间。q 为次数不超过六的有理多项式。可调用：

```sh
python3 spectral_certifier.py bound --q "0,1" --k 1 --modes 8 \
  --out results/candidate.json
python3 spectral_certifier.py verify results/candidate.json
```

若目标不属于该模型，先列出需要新增的几何表示、误差项和尾部估计，不能自行宣布已有工具适用。

## 不允许的推理跳跃

- 找到一个 Rayleigh 商等于 n 的函数，不等于证明第一非零特征值至少为 n。
- 局部临界点或正二阶变分，不等于全局最优。
- 某个对称子类的结论，不等于一般几何对象的结论。
- 点态曲率张量满足约束，不等于存在全局度量实现它。
- 同胚，不等于微分同胚；同伦等价更不能自动升级。
- 计算到的周期近似满足关系，不等于已构造代数循环。
- 某个搜索空间中未找到证书，不等于目标命题为假。

该协议是人工与模型协作规范，尚不是自动判断自然语言证明正确性的程序。
